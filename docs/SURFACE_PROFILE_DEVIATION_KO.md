# 형상 편차 계산과 연동

`fabrication.surface_profile_deviation`은 같은 좌표계에서 대응이 확인된 기준점과 측정점을 받아 측정점 방향의 법선 편차를 계산한다. 각 점에 단위 외향 법선을 직접 제공해야 한다. 양수는 그 법선 방향이다. 좌표는 m, 확장 불확실성과 편차 경계도 m다. 정규화 값은 사용자가 정한 양의 기준 길이로 나눈다.

요청에는 자산·위치·좌표계·기준 형상 식별자, 측정 및 기준 형상 해시, 점별 근거, 경계의 권한과 적용 근거를 넣는다. 대응점·좌표계·법선 또는 불확실성·경계 검토가 없으면 `needs_data`다. 자산·위치는 실행 문맥과 일치해야 한다. 입력 계약은 `SurfaceProfileDeviation`, 점 계약은 `SurfaceProfilePoint`이며 둘 다 `matintegrity.models.fabrication_surface`에 있다.

점별 출력은 부호 있는 법선 편차, 정규화 편차, 편차±확장 불확실성 구간, 사용자 경계와의 관계다. 구간 전체가 경계 안이면 `within_bounds`, 완전히 밖이면 `outside_bounds`, 경계와 겹치면 `overlaps_boundary`다. 경계와 정확히 일치하는 닫힌 구간은 안에 포함한다. 계산 상태 `computed`는 어느 비교 결과에서도 나올 수 있으며 합격이나 허용 판정을 뜻하지 않는다.

자동 정합, 최근접점 탐색, 법선 추정, 측정점 사이 보간, 전체 표면의 관측 완전성은 제공하지 않는다. 점에서의 법선 투영이므로 접선 방향 이동을 형상 오차로 합산하지 않는다. 측정 대응의 타당성과 누락 영역은 호출자가 관리한다. 표현 가능한 수치 범위를 벗어나면 `out_of_scope`다.

검증에는 양·음 편차, 비대칭 경계, 불확실성 구간의 경계 교차, 비축방향 법선, 강체 회전 불변성, 잘못된 법선·중복점·역전 경계 거부, 좌표 차의 범위 초과와 Python/JSON 동일성을 사용했다. 이는 기하 산술 검증이며 측정 장비나 제품의 물리 qualification은 아니다.

관련 변경: 성형 지지영역 API 1.0.2는 같은 지표 정의·방향의 복수 레코드를 거부한다. 기존 사전 생성 시 마지막 레코드만 남을 수 있었기 때문이다. 반복 측정은 호출자가 근거를 갖고 집계한 뒤 단일 지표로 전달해야 한다.
