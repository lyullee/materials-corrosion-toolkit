# 결정립 평면 계수 집계

현재 계산 버전은 1.0.1이다. 번호의 보정항과 기준값은 계산된 로그값을 바탕으로 정확 유리수 결합한 뒤 변환한다. 큰 보정항과 기준값의 상쇄를 보존하고, 비영 번호의 수치 소실은 결과로 반환하지 않는다. 로그 자체는 부동소수점 근사다.

`testing.grain_planimetry_summary`는 같은 물리 시편·재료 상태·관측 상에 속한 시야들의 유효 입자 수와 시편 평면 면적을 집계한다. 입력 면적 단위는 m²이며 출력 밀도는 m⁻²다. 영상상 면적이나 배율을 시편 면적으로 자동 해석하지 않는다. 경계에 걸친 입자의 가중 방식은 시험 절차에 따라 사용자가 적용한 유효 계수로 제공한다.

시야별 밀도를 단순 평균하지 않고 전체 계수를 전체 면적으로 나눈다. 같은 영상 해시와 계수 영역 식별자를 가진 자료는 시야 이름을 바꿔도 중복 집계할 수 없다. 다른 영역들의 실제 비중첩 여부와 시편 면적·경계 처리·모집단은 검토 플래그와 입력 근거로 남긴다. 단일 영상의 다른 영역 이름이 실제로 다른 영역임을 코드가 영상 분석으로 입증하지는 않는다.

번호 보정에는 기준 번호, 기준 면적 밀도, 밀도가 두 배 증가할 때 번호 증가량, 보정 식별자를 모두 지정한다. 계산은 `기준 번호 + 증가량 × log2(측정 밀도 / 기준 밀도)`다. 특정 규격의 보정값·입도 비교 도판·수락 기준은 제공하지 않는다. 같은 스케일을 사용할 때에는 해당 절차·판본에 맞는 보정 근거를 사용자가 확보해야 한다.

입자 수와 면적의 합·비율은 정확 유리수로 결합하고, 기준 근처의 작은 밀도 차이는 `log1p`로 계산한다. 필수 출력의 넘침·비영 값 소실은 `out_of_scope`다. 계수가 모두 0이면 입도 번호를 정하지 않고 `needs_data`로 남긴다. 면적과 계수가 같으면 평균 면적이 같다는 산술만 제공하며, 혼합 입도 분포·최대 결정립·3차원 크기·강도·인성·내식성·규격 적합성을 뜻하지 않는다.

입력은 `CorrelationBasis`의 사용 권한·적용성·단위 검토와 전체 요청 해시에 묶인다. 영상 자체나 상용 도판을 패키지에 포함할 필요가 없다. 수치 검증의 합성 계수 자료는 실제 현미경 시험의 적합성 검증을 대신하지 않는다.
