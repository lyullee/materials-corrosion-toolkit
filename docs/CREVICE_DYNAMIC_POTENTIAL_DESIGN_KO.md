# 공간 화학과 동적 이중층 전위의 결합 설계

## 현재 구현 경계

현재 `integration.crevice_component_state_bdf`는 매 BDF trial에서 그 시점의 성분 농도로 Davies 화학·전도도·Nernst 평형전위를 다시 구성하고, 공간 Ohmic/BV 혼합전위를 준정상 비선형 해로 계산합니다. 해당 trial의 Faradaic 속도, face current 및 전하 연속성을 성분 유속에 연결합니다.

별도 `integration.crevice_dynamic_double_layer_faradaic_history`는 사용자 전류 이력, 분극 곡선과 미분 정전용량 곡선으로 전위를 시간 적분합니다. 이 경로는 세포 간 이온 이동과 trial 농도에 의한 전위·평형전위 피드백을 풀지 않습니다. `integration.crevice_dynamic_double_layer_to_component_bdf_binding`는 계산을 순차 연결해 스케줄로 넘기므로 동시 결합이 아닙니다.

## 필요한 동시 결합 관계

결합 solver는 매 시각의 국부 화학 상태로 활동도, 전도도와 Nernst 평형전위를 갱신해야 합니다. 분극 법칙으로 얻은 각 반응 가지의 Faradaic 전류는 성분 source extent 및 외부 저장고의 원소·전하 장부로 투영합니다. 전해질 face current는 국부 Faradaic 전하원과 이중층 전하 변화에 맞춰야 합니다.

기존 부호 규약에서 성분 solver의 capacitive source는 수용액 방향 전류입니다. 계면 저장 전하를 `Q_i`라 하면 전극 방향 계면 전류와 수용액 방향 capacitive source는 부호가 반대입니다. 전기 연속성 잔차는 각 셀에서 다음 구조를 가져야 합니다.

`I_face,right - I_face,left = F × (aqueous Faradaic charge rate) + (aqueous capacitive current)`

계면 전하가 사용자 정의 미분 정전용량 `C_d(η)`에서 오면 단위 면적 전하는 `q(η)=∫C_d(ξ)dξ`이고, 전체 전하는 `Q_i=A_i q(η_i)`입니다. 활성 면적이 시간에 따라 변하면 `dQ_i/dt`에는 전위 변화와 면적 변화가 모두 들어갑니다. 면적이 고정된 경우에도 전류-전위 미분식을 사용하려면 곡선 지원구간과 양의 정전용량을 확인해야 합니다.

## 미결정 회로 경계

공통 금속 전위와 공간 전해질 전위를 사용하는 경우 각 셀의 계면 전위는 서로 독립 상태가 아닙니다. solver는 공통 금속 전위, 공간 Ohmic 전위·face current, 계면 전하 및 전류 입력을 서로 일관되게 닫아야 합니다. 따라서 다음 사항을 계약 입력으로 분명히 해야 합니다.

1. 적용 전류 이력 또는 다른 전기 회로 경계조건, 전류 부호와 금속의 전기적 연결 범위
2. 초기 계면 전하 또는 이에 대응하는 초기 전위의 기준 및 면적
3. `C_d(η)`의 출처·단위·지원구간·사용 권한과 면적 변화 기준
4. Nernst 활동도 기준, 반응 가지의 전자 수·전류 부호·성분/원소/전하 투영
5. 셀 face Ohmic 법칙, 외부 단자 전류 조건과 전체 전류 잔차 허용치
6. BDF trial에서 화학 평형을 재계산할 때의 총 solver-work 한도와 실패 시 결과 폐기 규칙

계약은 회로 경계를 하나의 물리적 구성으로 선택하도록 해야 합니다. 독립 셀별 전류·전위 모델과 전기적으로 연속된 공간 금속 모델을 같은 인터페이스에서 암묵적으로 혼합하지 않습니다.

## 구현 완료 판정 기준

코드 구현은 공개 요청 계약, 같은 trial 상태 안의 전위·화학·수송·계면 전하 계산, 성분/원소/전하 장부, 명시적 회로 경계, 결과 lineage와 카탈로그 등록이 모두 연결됐을 때 완료로 기록합니다. 현재 코드는 화학-준정상 혼합전위 경로, 독립 동적 이중층 적분기, 스케줄 바인더라는 **3개 분리 경로**가 있으며 이 동시 결합 계약은 미완성입니다. 숫자 수렴성·보존성 검증은 이 구현 연결 뒤 별도 배치로 수행해야 합니다.
