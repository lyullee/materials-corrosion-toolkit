# 상위 항목에 포함된 독립 요구의 대응

하위 방법을 검토했다고 해서 상위 항목에 있는 독립 본문·표·절차까지 완료된 것은 아니다. 다음 요구를 별도로 추적한다.

| 요구 | 현재 지원 | 남은 대응 |
|---|---|---|
| 저온 인성과 파괴 저항 | 충격·파괴인성 시험 전용 API | 서로 다른 물성을 대체하지 않고 실제 적용성·시편 근거를 보존한다. |
| 고온 손상 | 열 노출·크리프 상관식 | 금속 손실과 물성 변화를 구분한다. 열 노출 지수와 단조 가공경화 식의 이름이 비슷하더라도 다른 모델이다. |
| 세정·오염·피깅 | 세정 적합성·청정도 관측 | 오염에 의한 압력손실·열전달 변화, 실제 배관에서의 피그 통과와 별도로 대응해야 한다. |
| 체결 도구·검증 | 체결 계산·관측 구조 | 서비스 분류, 도구·하중 검증, 면제 권한은 승인된 절차 근거가 필요하다. |
| 제어 침착 | 층별 기하·템퍼 비드 관측 비교 | 조직 개선과 PWHT 대체 여부는 계산된 두께만으로 판단하지 않는다. |
| 지시 누적 길이 | 개별·그룹 지시 비교와 `inspection.indication_window_accumulation` | 공통 좌표의 합산·합집합 연산을 지원한다. 실제 투영·검사 범위·불확도·규격 기준은 별도 근거가 필요하다. |
| 검사·압력시험 개요 | 기록·일부 부하·적용성 계산 | 전체 QA 이행, 안전성·승인·위험 감소는 별도 근거가 필요하다. |

지시 구간 연산에는 규격 창 길이·허용값을 내장하지 않는다. 이 문서는 범위 분류이며 새 물리 검증 실적을 추가하지 않는다.
