# 질량·무게중심과 두 지지점 정적 반력

`fabrication.equipment_mass_properties`는 `EquipmentMassProperties`를 받는다. `matintegrity.models.transport_erection`에서 타입을 가져올 수 있다. 구성 부품마다 고유 ID, 양의 질량(kg), 공통 좌표계의 무게중심 좌표(m), 기록 해시와 근거를 넣는다. 보온재·내부품·부착 배관 등 실제 설치 구성의 포함 여부와 좌표계 대응은 호출자가 검토한다. 검토하지 않은 목록은 `needs_data`다. 동일 부품 ID를 두 번 넣을 수 없다.

출력은 총질량, 질량 비율로 가중한 3차원 무게중심, 부품 ID 목록, 조립체·좌표계 ID와 입력 목록 해시다. 외부 부품 질량을 추정하거나 좌표 변환을 수행하지 않는다. 입력 순서나 부품 수만으로 목록 완전성을 추론하지 않는다.

`fabrication.equipment_two_support_lift`는 위 질량 목록을 `inventory`로 직접 받아 같은 함수를 실행한다. 따라서 별도로 복사한 총질량·무게중심과 원래 목록이 달라질 위험을 줄인다. 두 지지점은 목록의 본체 좌표계에서 XY 좌표로 입력한다. 회전각(rad)은 본체 XY 좌표를 세계 XY로 바꾸는 Z축 회전이며, 세계 Y축 양의 방향을 지지반력 방향으로 사용한다. 중력 가속도(m/s²), 사용자 하중 배율, 적용 가능한 최소 수평 지지점 간격(m)을 명시한다. XY 평면 투영과 두 평행 수직 반력의 타당성은 별도 검토 항목이다.

계산은 총질량×중력×배율의 하중과 회전된 상대 수평 지레팔로 정적 힘·모멘트 평형을 푼다. 출력은 각 지지점의 수직 반력(N), 부호 있는 수평 간격과 무게중심 지레팔(m), 목록 해시를 보존한다. 지지점 순서를 바꾸면 반력의 대응도 바뀐다. 음의 반력이 필요한 경우 `uplift_required=true`와 후보 부호 반력을 남기고 `out_of_scope`로 반환한다. 최소 투영 간격 미만과 수치 범위 초과도 적용 범위 밖이다. 검토 누락이나 질량 목록 미완성은 `needs_data`다.

사용자 배율은 명시된 정적 하중 시나리오다. 충격·동역학 해석, 경사 슬링 장력, 크레인 성능표, 다중 지지점의 부정정 분배, 국부 러그 응력·좌굴, 접촉 재분배나 양중 승인은 계산하지 않는다. 결과 반력을 이후 구조 모델에 넘길 때 지지점 ID·좌표계·하중 방향·회전각·하중 시나리오를 함께 관리해야 한다. 기존 운송 캠페인 API가 받는 관측값과 계산 결과의 출처도 구분한다.

검증은 알려진 질량·무게중심, 비대칭 지지반력, 회전각에 따른 모멘트 평형, 좌표 평행 이동, 지지점 순서 반전, 하중 배율, 음의 반력·특이 투영, 누락 검토·중복 부품, 수치 범위와 Python/JSON 동일성을 포함한다. 입력과 실행 문맥의 자산·위치가 다르면 거부한다.
