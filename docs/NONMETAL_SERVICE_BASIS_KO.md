# 비금속 서비스 근거와 수지 HDT 여유

## 재료와 사용 조건

재료명이나 브랜드만으로 수지·경화 상태·보강재·충전재·적층 구조가 동일하다고 판단하지 않는다. 재료 상태와 제조 조건을 식별하고 온도·압력·노출 시간·접촉 화학물질·농도·잔류 및 운전 응력의 조합을 보존해야 한다. 세정액과 일시적으로 접촉하는 유체도 적용 범위에 포함해야 한다.

`materials.composite_compatibility_assessment`와 `materials.polymer_compatibility_envelope_match`의 사용자 근거 대조는 공급된 적용 범위와 관측에 한정된다. 상자 형태의 범위에 각 변수가 들어온다고 해서 모든 조합의 장기 성능을 독립 검증한 것은 아니다. 투과·팽윤·환경응력균열·잔류응력 완화·점탄성 크리프·적층 접착 손상 및 이들의 연성 예측은 별도의 방법·데이터 대응이 필요하다.

전형적인 물성 범위는 보증 설계값과 구분한다. 빈 항목은 미확인으로 남기고 범위의 중간값을 자동 선택하지 않는다. 화학 저항성의 서열 표기를 수명·손실률·고장확률로 변환하지 않는다. 자료마다 다른 경도 척도와 인장 강도·항복 강도·파단 강도·열변형 시험값을 구분해야 한다. 이 배포물에는 재료별 상용 물성표나 호환성 등급표를 포함하지 않는다.

## HDT 여유 API

`materials.resin_hdt_headroom`은 `ResinHdtHeadroom`을 받는다. 필수 입력은 다음과 같다.

| 입력 | 의미 |
|---|---|
| `material_condition_id` | 평가할 수지의 상태 식별자 |
| `hdt_record_id`, `test_method_id` | HDT 근거 기록과 시험 방법·판본 식별자 |
| `test_flexural_stress_Pa` | 해당 시험의 양의 굽힘 응력 |
| `heat_deflection_temperature_K` | 공급된 양의 HDT 절대온도 |
| `design_temperature_K` | 평가할 양의 설계 절대온도 |
| `required_headroom_K` | 사용자가 정한 비음의 온도 차 요구 |
| `basis` | 전체 입력 해시, 출처·권한·단위·적용성 검토 |

`hdt_headroom_K = HDT - design_temperature`와 `headroom_surplus_K = hdt_headroom - required_headroom`을 계산한다. 요구 여유 이상인 경우에만 `declared_headroom_satisfied=true`를 반환한다. 요구 경계와 같은 경우도 만족이다. 요구를 만족하지 않아도 산술 계산은 `computed`일 수 있으며, 이는 승인 상태와 다르다. 음의 여유를 절댓값이나 0으로 바꾸지 않는다. 수치 범위를 넘는 결과는 `out_of_scope`다.

기본 레지스트리의 `run`과 `run_json`으로 사용할 수 있다. 시험 하중·방법·온도·요구 여유를 바꾸면 입력 해시를 다시 검토해야 한다. 기본 하중이나 요구 여유 값은 제공하지 않는다.

[ASTM D648의 공개 용도 설명](https://store.astm.org/standards/d648)은 시험값의 사용 조건을 하중·시간·온도 등과 연결한다. 따라서 이 API의 온도 차 만족만으로 장기 사용온도·크리프 저항·화학 적합성·접착 성능을 보증하지 않는다. 유리전이온도나 다른 하중에서 얻은 시험값을 동일한 HDT 기록으로 자동 대체하지 않는다. 규격 시험 절차·상용 계수·도표를 구현하거나 배포한 API가 아니다.

## 남은 대응

라이닝 두께의 투과 억제와 성형 잔류응력 사이의 절충, 여러 접촉 유체와 운전/이상 상태의 조합, 공급자별 보강·수지 시스템 및 시간 의존 물성의 연결은 아직 미완료다. 기존 적용 범위 계약이 있다는 이유로 해당 기구의 예측이 구현됐다고 보지 않는다.

## 검증 기록

자체 작성한 양·영·음의 여유, 요구 경계의 포함, 요구 여유 0, 공통 온도 이동, 수치 범위 이탈, 잘못된 시험 하중·온도·요구 차이, 시험 조건 해시 변경과 기본 레지스트리의 Python/JSON 일치를 포함한 관련 12개 테스트 및 정적 검사가 통과했다. 실험적 수지 선정·장기 크리프·접착 성능 검증을 수행한 결과는 아니다.
