# 압력–온도 운전경계 계약

## 목적과 경계

`structural.pressure_temperature_envelope`는 사용자가 검토한 온도별 허용압력 곡선과 식별된 운전점을
비교한다. 공개 패키지는 설계규격 표, 재료별 허용값, 안전계수 또는 서비스 분류 규칙을 포함하지
않는다. 따라서 결과는 공급된 경계에 대한 산술 비교이며 설계 적합성이나 규격 합격 판정이 아니다.

입력은 경계 ID, 적용성 근거, 경계 내용 SHA-256, 절대온도 순으로 정렬된 두 개 이상의 knot,
운전점 ID·절대온도·압력 및 두 검토 gate를 보존한다. CoolProp이나 공정 이력 모듈에서 얻은 상태도
단위와 압력 기준을 검토한 뒤 운전점으로 전달할 수 있다. 이 계산기는 gauge/absolute 압력 변환이나
유체상태 계산을 대신하지 않는다.

## 계산

온도 `T`가 인접 knot `(T0, P0)`, `(T1, P1)` 사이에 있을 때 공급 경계를
`Pallow = P0 + (T-T0)(P1-P0)/(T1-T0)`로 선형 보간한다. 각 운전점에 대해 다음을 반환한다.

- 보간된 허용압력과 `Pallow - Poperating` 압력여유
- `Poperating/Pallow` 이용률
- 공급 경계 내부 여부
- 최소 압력여유점과 최대 이용률점

정확히 경계 위인 점은 공급 경계 내부로 표시한다. 온도 지원범위 밖의 점은 외삽하지 않고 전체
계산을 `out_of_scope`로 남긴다. 적용성 또는 운전점 검토가 없으면 `needs_data`다. 경계 압력은 양수,
운전압력은 0 이상이어야 하고 knot 온도와 운전점 ID는 각각 엄격한 순서와 유일성을 만족해야 한다.

## 검증과 연동

`tests/test_pressure_temperature_envelope.py`는 두 선형 구간, 정확한 knot, 경계 초과, 외삽 금지,
검토 gate와 잘못된 계약을 검사한다. `scripts/validate_pressure_temperature_envelope.py`는 별도로 작성한
두 내부점의 닫힌 산술값과 구현을 대조하고 결과를
`validation/pressure_temperature_envelope_math.json`에 기록한다.

상류 모듈은 시간·운전상태별 점을 생성할 수 있고 하류 위험성 모듈은 사용자가 별도로 정의한
초과 사건을 받을 수 있다. 이 모듈 자체는 과도 중간점, 불확실성, 하중조합, 열응력, 손상진전,
초과확률 또는 FTA 기초사건 확률을 생성하지 않는다.
