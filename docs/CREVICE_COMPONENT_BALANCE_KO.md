# 결합 상태의 성분 수지

내부 `CoupledPhaseStateLayout.component_balance`는 초기·최종 상태와 셀별 순유입 누적량을 비교한다. 입력 배열은 상태 레이아웃의 성분·셀 순서를 그대로 따른다. 누적량 단위는 mol이며 셀 경계를 지나는 수송과 외부 공급·제거를 모두 포함한다. 고체 생성·용해는 내부 이동이므로 순유입에 다시 넣지 않는다.

잔차는 최종 총량에서 초기 총량과 순유입 누적량을 뺀 값이다. 허용치는 절대 허용량과 상대 허용치에 초기량·최종량·순유입 절댓값 중 최댓값을 곱한 값의 합이다. 비교는 이진 입력의 정확 유리수로 수행하며 출력할 수 없는 비영 값은 오류로 처리한다. 반환값은 셀별 용존 변화, 고체 성분 변화, 순유입, 잔차, 허용량과 통과 여부를 포함한다. 전체 셀의 잔차가 서로 상쇄되어 셀별 불균형을 감추지 않는다.

성분 수지 함수에는 별도로 적분한 순유입을 제공해야 한다. 내부 `integrate_coupled_seed_bdf`에서 `integrate_component_sources=True`를 지정하면 성분별·셀별 누적 순유입을 추가 BDF 상태로 적분한다. 물리 상태의 총 성분 미분과 동일한 계산 단계의 미분값을 사용하며, 핵생성 이벤트 재시작 때도 누적량을 유지한다. 출력의 `integrated_net_sources_by_time`은 성분·셀 순서의 mol 누적량이고 `component_balance_by_time`은 각 요청 시각의 수지다. 기존 `state_by_time`에는 누적 상태를 섞지 않는다.

수지 비교에는 지정한 BDF 절대·상대 허용치를 사용한다. 요청 시각 중 하나라도 수지가 허용치를 벗어나면 궤적과 누적량을 확정 결과로 반환하지 않는다. 이는 끝점 유량을 이용한 근사가 아니지만 같은 미분값의 두 상태가 일치하는지 확인하는 내부 수치 일관성 검사다. 잘못 구현된 경계 유량 자체를 독립적으로 입증하지 않는다. 수송 이산화의 독립 검증과 원소·전하 수지, 소진·재생성 처리는 여전히 남아 있다. 공개 결합 솔버의 완료를 의미하지 않는다.
