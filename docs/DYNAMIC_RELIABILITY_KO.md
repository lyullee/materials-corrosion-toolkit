# 유한상태 동적 신뢰성

## 목적과 입력 계약

`reliability.continuous_time_markov_chain`은 하나의 자산·부위·물리 범위에서 상태가 시간에 따라
변하는 시간 불변 유한상태 연속시간 Markov 모델을 실행한다.
`reliability.piecewise_continuous_time_markov_chain`은 같은 상태공간에 대해 연속된 운전 구간마다
다른 초당 생성행렬을 받는다. 사용자가 상태 ID·정의, 초기확률과 전이율을 공급한다. 고장,
수리, 교체, 대기 또는 운전 상태의 의미와 전이율은 이 모듈이 추정하지 않는다.

생성행렬의 비대각 원소는 음수가 아니고 대각 원소는 양수가 아니며, 각 행의 합은 선언한
초당 생성행렬 행합 허용오차 안에서 0이어야 한다. 초기확률 합은 별도 무차원 정규화 허용오차
안에서 1이어야 한다. 시간 불변 모델은 상태·전이율 검토와 평가기간 동안 동일 생성행렬이라는
선언이 없으면 `needs_data`로 중지한다. 자산·부위·시계,
공급자·판본·원본 SHA-256과 공통원인 그룹을 보존한다.

구간형 모델은 공급된 순서를 그대로 사용한다. 첫 구간은 평가 시작시각, 마지막 구간은 평가
종료시각에 맞고, 인접 구간은 선언한 시간 허용오차 안에서 정확히 이어져야 한다. 공백·중첩·
역순을 자동 정렬하거나 채우지 않는다. 각 구간은 고유 ID, 전이율 근거 ID, 공급자 리비전,
원본 SHA-256과 검토 상태를 별도로 가진다. 상태 의미·구간 순서 또는 어느 한 구간 전이율이
미검토이면 전체 계산을 `needs_data`로 중지한다.

## 서로 다른 결과 의미

원 생성행렬의 행렬지수로 종료시각의 상태 점유확률을 계산한다. 이 경로는 실패상태에서 수리나
교체 상태로 나가는 전이를 그대로 유지하므로, 종료시각의 실패 점유확률은 기간 중 최초고장
확률과 다를 수 있다.

기간 중 선언한 상위사건 상태에 처음 진입할 확률은 해당 상태들을 흡수상태로 바꾼 복사본에서
별도로 계산한다. 시작 시 상위사건 상태의 확률질량은 0이어야 한다. 이 값만
`conditional_first_failure_in_period` 의미를 가지며 `probability_event`로 전달할 수 있다.
원 생성행렬의 종료 점유확률은 `unscoped_event_probability`로 유지한다.

블록 행렬지수로 각 상태의 기대 점유시간을 적분하고, 점유시간과 비대각 전이율의 곱으로 기대
전이 횟수를 계산한다. 기대 횟수는 모델 내부 기대값이며 관측된 반복사건 빈도가 아니다.
구간형 모델은 원 상태분포와 상위사건 흡수 복사본을 각 구간 경계에서 순서대로 전파한다.
경계별 상태점유·누적 최초진입확률, 구간별 점유시간·전이횟수와 전체 합을 모두 반환한다.

## 수치 검증과 한계

상태 `operational → failed` 전이율을 λ, 수리 전이율을 μ라 하면, operational에서 시작한
두 상태 모델의 시간 t 실패 점유확률은 다음과 같다.

```text
P_failed(t) = λ/(λ+μ) × [1 - exp(-(λ+μ)t)]
P_first_entry(t) = 1 - exp(-λt)
```

실패 기대 점유시간도 이 식의 0부터 t까지 적분과 대조한다. 수리율 0의 흡수상태 한계,
생성행렬 부호·행합·크기, 초기확률, 시작 실패질량, 미검토 입력, context 및 사건 전달 의미를
검사한다. 동일 생성행렬을 둘로 나눈 구간형 결과가 단일구간 결과 및 폐형식과 일치하는지,
서로 교환되지 않는 행렬의 순서 효과, 구간 공백·중첩·역순·경계 불일치와 구간별 검토 상태도
검사한다. 재현 기록은 `scripts/validate_dynamic_reliability.py`,
`scripts/validate_piecewise_dynamic_reliability.py`, `validation/dynamic_reliability_math.json`과
`validation/piecewise_dynamic_reliability_math.json`이다.

현재 모델은 시간 불변 또는 사용자가 구분한 구간별 상수, 기억 없음 전이, 고정 상태공간과
점추정 전이율에 한정한다. 구간형 지원은 연속 시간함수, 열화 나이, 비지수 대기시간,
semi-Markov 전이, 숨은 상태, 전이율 불확실성 또는 데이터 기반 보정을 뜻하지 않는다. 다중
설비 상관과 정책 최적화도 포함하지 않는다. 실제 위험성 평가에는 공급자 모델의 적용성·
중복계상과 별도 독립 검증이 필요하다.

`reliability.ctmc_generator_calibration`은 별도 관측계약이다. Calibration state exposure와 directed transition count로 generator rate를 추정하고 holdout Poisson score를 계산한다. 추정 generator를 자동 전파하지 않으며, 실제 적용 전에 상태정의·시계·exposure unit·stationarity와 독립 자료의 적합성을 검토해야 한다.
