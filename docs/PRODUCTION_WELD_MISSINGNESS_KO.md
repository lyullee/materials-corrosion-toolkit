# 생산 용접시험의 누락·무효 기록

`welding.production_weld_test_campaign_evidence` 1.0.2에서 측정 상태가 `missing` 또는 `invalid`이면 값·표준불확도·결과 해시를 모두 비워야 한다. 누락 또는 무효의 사유와 입력·제공자·시험편 출처는 보존한다. 사용 가능한 측정에는 값·표준불확도·결과 해시가 필요하다.

기존 결과의 해시를 보존해야 하는 경우 원본 자료 보관 체계에서 별도 기록으로 관리한다. 사용할 수 없는 측정에 유효 정량 결과처럼 연결하지 않는다. 이 API의 판정은 사용자가 제공한 기준에 한정되며 규격의 합격기준 표나 자동 기준 선택 기능을 제공하지 않는다.
