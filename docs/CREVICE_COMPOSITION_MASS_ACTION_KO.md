# Crevice composition to aqueous mass-action history

`integration.crevice_composition_to_aqueous_mass_action_history` maps the exact-knot, caller-volume composition history into the existing strict aqueous mass-action solver. At every knot, the caller supplies a fully specified `AqueousMassActionSystem` with the applicable temperature, species, fixed activity coefficients, reaction constants, conservation/analytical constraints, evidence and applicability reviews. Network species IDs and topology must remain identical across knots, while caller-owned temperature-specific numeric parameters may change.

The composition output is in mol/m³. With the solver's explicit 1 mol/L activity standard state, the adapter converts concentration using 1 mol/m³ = 0.001 mol/L and seeds dimensionless initial activity as `gamma * c / (1 mol/L)`. Only constraint IDs explicitly listed in `composition_derived_constraint_ids` have their targets rebuilt by applying the exact caller coefficient vector to current molar concentrations. Every unselected target, including a fixed zero-charge target when declared that way, is preserved exactly. The IDs and their interpretation require a separate review flag; residual scales and all reaction/constraint definitions remain caller data.

Zero inventory cannot be used as a strictly positive Newton starting activity. The caller must supply a positive numerical seed and review that it is solely an initial guess; the seed does not replace or alter the zero inventory used to construct conservation targets. A result that fails the existing mass-action solver's square-system, balance, conditioning, scope, evidence or convergence requirements is returned as a non-computed knot status and later knots are not silently evaluated.

This is a composition-to-equilibrium adapter, not a source of chemistry data. It does not select or discover reactions, derive equilibrium constants, change activity coefficients, interpolate parameters in temperature, add gas/solid phases, precipitate scale, integrate transport, update electrochemical currents or translate dissolved metal into wall loss. Each knot's original supplied system is digest-recorded after binding composition-derived guesses and constraint targets. The run context must match the upstream asset, location and clock.

Python inputs are `CreviceCompositionToMassActionHistory` and the tuple `mass_action_systems_by_knot`; each entry is the full caller-owned `AqueousMassActionSystem` for that exact composition temperature. A synthetic chain is shown in `examples/crevice_electrochemical_composition.py`. The example has not been run and is not validation evidence.
