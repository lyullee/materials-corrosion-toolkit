# 재료 분류·저온 시험·손상 기구의 대응

## 주조·HIP 및 품질계수

주철·주강은 재료 상태, 흑연 형상, 기지 조직, 평가 위치와 시험 근거를 구분해야 한다. `materials.casting_forging_quality_record`와 `materials.casting_forging_quality`는 관측·검사 범위·사용자 기준을 연결한다. 응고·흑연화·용접 균열이나 HIP의 기공 폐쇄·치밀화·확산 계산이 구현된 것은 아니다. HIP 적용만으로 완전 치밀화·무기공·물성 향상을 부여하지 않는다. 재료군 이름만으로 강도·인성·용접성을 고정 순위로 정하지 않는다.

`fabrication.joint_efficiency_declaration`는 선언된 이음·공정·재료·검사 방법과 검사 범위를 정확히 대조한다. 용기 이음효율, 배관 이음계수, 주조 품질계수와 고온 용접강도계수는 서로 바꾸어 사용할 수 없다. 검사 범위 부족을 더 작은 임의 계수로 대체하지 않는다. 계수표·예외·검사 대체·이음 간 영향 및 재료별 사용 제한의 판본별 연결은 남은 과제다. 검사 실시율은 강도비나 검출확률을 의미하지 않는다.

| 요구 | 현재 지원 | 남은 대응 |
|---|---|---|
| 재료 그룹·복수 규격 | 재료 증명서와 관측의 식별·대조 | 정확한 판본·제품·열처리·강도·조성 기준으로 그룹을 지정하는 권한과 규칙이 필요하다. |
| 저온 충격시험 | 충격 관측 캠페인, 지배두께 계산, `inspection.declared_impact_subsize_requirements` | 소형 시편 계산은 승인된 폭 비례·온도표 규칙에 한정하며 관측 에너지를 정규화하지 않는다. 면제·시편 수·캠페인 기준은 별도 근거가 필요하다. |
| 극저온 재료 | 제공된 극저온 물성 근거 연결 | 액화 온도와 재료 추천 목록은 실제 압력·상태 및 재료 적합성 검증이 아니다. |
| 열가공 | 성형 순서와 열 노출 계산 | 재결정·입자 성장·석출과 결과 물성의 전용 계산·근거 대응이 필요하다. |
| 응고·액화균열 | 조성 지표와 승인된 적용 범위 비교 | 용착 금속 응고와 인접 재료 액화의 기구를 구분한다. 일반 균열 개시 계산이 구현된 것은 아니다. |
| 재열균열 | 열 구간별 관측·적용성 비교 | 응력 완화·입계 손상·균열 개시의 실제 계산 또는 공급자 연결은 별도 검토 대상이다. |
| 크리프 | Norton, 이력 적분, 시간 분율, Larson–Miller 모델 | 변형률과 파단 수명은 다른 출력이며 물성·보정·적용 범위가 필요하다. |
| PMI와 재료 증명서 | 출처·실물·시편·기록의 대조 | 현장 화학 분석으로 모든 기계적 성질이나 증명서 항목을 복원하지 않는다. 장비별 검출 한계와 방법을 보존한다. |

규격 표·전형값·기구 설명을 보편적인 승인 기준이나 검증 실적으로 계산하지 않는다. 이번 문서는 요구 분류이며 새 수치 테스트 실적을 추가하지 않는다.
