# WPS 자격 범위 비교 API

`welding.wps_qualification_envelope`는 생산 절차와 사용자가 선언한 절차 자격 범위를 비교하는 결정론적 회계 API입니다. 특정 규격 판본의 변수 분류표, 허용 범위 또는 합격 규칙은 포함하지 않습니다. 적용 규칙과 그 근거는 사용자가 데이터로 제공하고 검토해야 합니다.

## 변수 분류와 설정

각 `QualifiedEssentialVariable`에는 `qualification_class`를 지정합니다.

- `essential`: 필수 변수
- `supplementary_essential`: 보충 필수 변수
- `nonessential`: 비필수 변수

생략 시 기존 입력과의 호환성을 위해 `essential`로 처리됩니다. 분류는 규격 판본, 공정, 적용조건 및 프로젝트 규칙을 검토한 호출자가 설정해야 합니다. API는 분류를 추론하지 않습니다.

변수마다 자료형(`numeric` 또는 `categorical`), 단위 토큰, 수치 하한·상한 또는 허용 토큰을 선언합니다. 수치와 범주는 서로 변환하지 않습니다. 단위 토큰도 정확히 일치해야 합니다. 지원 범위와 절차·재료·이음부·용접공정 식별정보는 해당 선언의 근거 및 출처와 함께 관리하십시오.

## 시험 근거와 판정 결과

유효한 시험 근거 연결을 변수별로 요구하는 대상은 `essential` 및 `supplementary_essential` 변수입니다. 비필수 변수도 선언된 범위와 생산값을 비교하지만, 이 API는 그 변수의 개별 시험 근거 연결을 자격 성립 요건으로 요구하지 않습니다. 다만 자격 범위 계약에는 하나 이상의 시험 근거 레코드가 필요합니다. 호출자가 범위 선언의 권위와 적용성을 확인해야 합니다.

범위를 벗어난 변수는 `outside_declared_envelope_variable_ids`에 표시되고, 분류별 목록에도 나뉘어 반환됩니다. 필수 또는 보충 필수 변수의 범위 이탈은 `requalification_required_variable_ids`에 표시됩니다. 비필수 변수의 범위 이탈은 절차 선언 범위에서 벗어났음을 나타내지만, 이 API만으로 재자격 요구를 뜻하지는 않습니다. 외부 규칙에 따라 후속 판단이 필요합니다.

`all_variables_within_declared_envelope`는 계산 가능한 자료와 검토 항목이 갖춰졌을 때 선언 범위 내 모든 변수의 일치 여부를 요약합니다. 이는 용접 품질, 건전성, 내식성, 현장 승인 또는 규격 적합 판정이 아닙니다. 누락되거나 상충하는 자료는 `needs_data` 또는 `out_of_scope` 상태로 다루며, 이를 자동으로 적합 처리하지 않습니다.

## Python 사용 흐름

프로젝트의 공개 모델 입력 계약을 사용해 다음 순서로 적용합니다.

1. 승인된 출처와 판본을 확인하고, 변수 분류·범위·단위를 호출자 데이터로 구성합니다.
2. 시험편 및 시험 결과의 출처, 식별자, 제공자 버전과 입력·결과 digest를 근거 레코드에 연결합니다.
3. 생산 절차, 재료 상태, 이음 구성 및 용접공정 식별정보를 자격 범위와 정확히 대응시킵니다.
4. 입력 계약을 검증한 뒤 `wps_qualification_envelope`를 호출하고 상태와 분류별 이탈 목록을 검토합니다.
5. 자격 권한 검토와 현장 승인 판단은 별도 절차로 수행하고, 원자료·사용 권한·검토 근거를 보존합니다.

구체적인 Python import 경로와 계약 예시는 공개 API 레퍼런스의 `welding.wps_qualification_envelope` 항목을 참조하십시오. 실제 실행 예제에는 승인되지 않은 규격 표나 시험 데이터를 넣지 않습니다.
