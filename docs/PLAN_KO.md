# MatIntegrity 개발 계획

목표는 재료·설계·손상·제작·용접·검사·신뢰성의 기술 영역을 조합 가능한 Python 구성요소로 제공하는 것이다. 사용자가 파라미터, 재료 데이터, 검사 결과, 자체 계산기를 교체하고 Python API 또는 버전이 있는 JSON 계약으로 다른 프로젝트와 연결할 수 있게 한다. FTA는 여러 소비자 중 하나다.

## 개발 원칙

- 기술 범위는 계산 모델, 재료·시험 데이터, 적용성 규칙, 작업 흐름으로 나눠 추적한다. 모든 항목을 동일한 종류의 계산식으로 바꾸지 않는다.
- 구현됨, 해석해로 검증됨, 독립 실험과 비교됨, 데이터 필요, 표준별 확장 필요를 구분한다. 미구현 항목은 계산 결과를 만들지 않는다.
- 공개 자료의 이용조건을 확인하고 독립적으로 코드를 작성한다. 공개 열람과 재배포 허용을 구분한다. 데이터 원본은 기본적으로 다운로드 캐시에 두고 배포물에는 출처·이용조건·해시·변환 기록을 넣는다.
- SI 단위, 절대압·온도, 측정·예측 구분, 결함 위치, 시간 기준, 적용 범위, 모델 및 데이터 버전을 보존한다.
- 열역학은 선택적 CoolProp 공급자를 사용한다. 유체 물성과 고체 강도·인성·손상 파라미터를 혼동하지 않는다.
- 연동은 이 프로젝트에서 정의한 공개 계약으로 먼저 제공한다. 기존 프로젝트 변경은 별도 확장 요청서로 명세한다.

## 단계와 완료 조건

| 단계 | 작업 | 완료 조건 |
|---|---|---|
| P0 | 공개 데이터 조사·확보·분류 | 직접 손상·재료 데이터와 운전 데이터를 구분하고 URL·라이선스 근거·파일 해시·규모·적용 한계 기록 |
| P1 | 공통 계약·단위·모델 레지스트리 | 사용자 모델·파라미터·테이블 교체, JSON/CSV 입출력, 실행 근거 기록 |
| P2 | 부식·구조·수명 기본 계산 | 손계산·해석해·경계조건·실험 비교를 구분한 검증 |
| P3 | 제작·용접·검사·재료 데이터 | 전문 입력 계약, 사용자 규칙과 파라미터 표, 검사 불확실성·POD 처리 |
| P4 | 신뢰성·다른 모듈 연동 | 기간별 PoF·강도·열화 결과의 의미 보존, 어댑터와 타 프로젝트 요청서 |
| P5 | 범위 확장·고급 기법 | 공개 1차 자료와 적절한 라이브러리 비교 후 추가, 능력 목록의 누락 항목 순차 해소 |
| P6 | 배포·연구 재개성 | 설치 가능한 배포물, 재현 명령, 매뉴얼·개발기록·검증기록·다음 작업·의존성 및 데이터 고지 |

이 세션에서는 P0를 우선 수행한 뒤 확보 데이터에 맞춰 P1~P4의 첫 실행 경로를 구축한다. 이후에도 전체 목표는 능력 목록과 미완료 작업을 기준으로 계속 추적한다. 기술 영역 전체를 구현한 것으로 간주하려면 미구현 항목과 표준·데이터 의존 항목 각각의 지원 방식 및 검증 상태가 명시돼야 한다.

현재 scope 감사에서 2개 capability가 code-incomplete로 분류되어 있다. 실행 순서와 잔여 계산 범위는 [잔여 구현 작업표](REMAINING_IMPLEMENTATION_KO.md)에 관리한다. 이 작업표는 전체 범위의 일부를 다음 구현 가능한 단위로 나눈 것이며, 도메인 완료율 산정에는 사용하지 않는다.

전체 목표의 증거 연결형 진행 상태는 `../data/catalogs/objective_progress.json`에서 관리한다. `implementation_scope_audit.json`의 `implementation_complete=true` 행 수를 101로 나눈 값(현재 47/101=46.5%)은 추적 목록에서 제한된 코드 경로가 작성됐다는 비율일 뿐, 전체 목표 완료율이나 검증률이 아니다. milestone을 완료로 바꾸려면 해당 증거 링크와 잔여 조건을 검토해 완료 조건이 충족됐음을 확인해야 한다.

## 우선 조사할 영역

재료 식별·화학성분·물성·온도 의존성, 균일·국부부식·환경균열·수소 손상·고온 손상, 응력·피로·파괴·크리프, 형상·제작·볼팅·코팅·보관, 용접 열입력·성분 지수·열처리·시공 기록, 파괴·비파괴검사·압력/누설 시험, 검사 갱신·신뢰성·위험성 연결을 포함한다.

상용 규격의 허용값·면제곡선·합격표는 라이선스가 있는 사용자 데이터 또는 별도 검토된 플러그인으로 받는다. 일반적인 물리 계산 결과에 규격 적합 판정을 자동으로 부여하지 않는다.
