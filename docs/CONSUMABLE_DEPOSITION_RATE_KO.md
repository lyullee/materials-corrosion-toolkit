# 연속 공급 소모재의 용착 질량률

`welding.declared_consumable_deposition_rate`는 균일한 재료 단면이 연속적으로
공급될 때 단면적×밀도×아크 가동 중 공급 속도로 공급 질량률을 계산한다.
이 값에 사용자가 제공한 포집 질량분율을 적용해 용착된 소모재의 질량률을,
다시 아크 가동 시간 비율을 적용해 전체 시간 평균을 계산한다.
입력은 m², kg/m³, m/s와 무차원 비율이며 출력 질량률은 kg/s다.

단면과 밀도는 같은 재료 체적의 정의여야 한다. 중공·플럭스 충전 단면에
외경 면적과 금속 밀도를 임의로 조합하면 안 된다. 단면·밀도·포집률의 근거,
공정과 소모재 상태·가동 시간의 정의를 사용자가 검토하고 전체 입력 해시와
사용 권한을 제공한다. 공정 이름으로 효율이나 전형적인 용착률을 선정하지 않는다.
단속적 수동 봉 소모·재료 단면 변화·회수 플럭스의 질량을 자동 모델링하지 않는다.

공급 질량률과 용착 질량률은 다르며 아크 가동 중 질량률과 달력 시간 평균도
구분한다. 공급 속도 0, 포집률 0, 가동 비율 0은 서로 다른 입력이다.
비영 결과의 소실이나 지원 불가능한 최종 질량률은 `out_of_scope`로 반환한다.

이 결과는 소모재에서 공급된 질량만 대상으로 한다. 모재·이전 층의 용융
질량, 전체 용융지 질량·희석·용입·비드 형상·변태·품질·원가·검사 승인을
추정하지 않는다. 실제 공정의 이행 모드·차폐·자세·두께·재료·절차 제한은
별도 근거가 필요하다. 비교표의 대표 수치나 고정 생산성 순위를 내장하지 않는다.
