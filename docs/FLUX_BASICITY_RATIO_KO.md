# 플럭스 조성의 가중 비율

`welding.declared_flux_basicity_ratio`는 사용자가 제공한 화합물별 질량 조성과
분자·분모 가중치로 염기도 기술값을 계산한다. 특정 이름의 계수·분류 경계나
상용 조성표는 내장하지 않는다. 화합물 조성, 지수 정의, 플럭스 상태와 전체
요청의 사용 권한·해시가 필요하다. 질량분율·질량백분율·질량 ppm 중 하나의
일관된 기준을 사용한다. 이 API는 원소 조성을 산화물 조성으로 바꾸지 않는다.

양의 가중치를 가진 화합물의 측정값이 없으면 `needs_data`, 측정된 분모가
0이면 `out_of_scope`다. 측정된 분자가 0이고 분모가 양수이면 비율 0은 유효하다.
비영 비율의 소실이나 최종 범위 초과는 거부한다. 가중합만 표현 불가능하고
비율은 계산 가능하면 가중합을 `null`로 보존한다. 가중합의 단위는 입력 질량
기준이며 비율은 무차원이다. 미보고 나머지 성분·별칭·화합물 전환은 추론하지 않는다.

이 값은 산소 퍼텐셜, 용접 금속 산소/수소 함량, 개재물, 충격인성·균열 저항,
플럭스 승인·범주의 자동 판정이 아니다.
[염기도 모델과 CALPHAD를 비교한 연구](https://www.mdpi.com/2075-4701/12/9/1530)는
이러한 경험 지수와 열역학적 모델을 구분해 검토한다. 실제 성분 이동과 산소
예측에는 상 모델·조건·데이터의 독립 적용성 확인이 필요하다.

검증 사례는 자체 작성한 조성 비율, 질량 기준 변경, 누락/0 구분, 수치 범위와
Python/JSON 교환을 사용한다. 상용 플럭스의 측정 데이터나 실측 인성 검증은 아니다.
