# 101개 확장 범위 구현 추적

이 카탈로그는 최초 scope 감사의 항목별 판단을 보존한다. 최초 13개 `code_incomplete` 중 현재 1개 capability가 코드 범위 미완성으로 남았다. bounded child 계산 코드가 추가되어도 parent 도메인 완료나 수치 검증으로 간주하지 않는다. `implementation_complete`는 제한된 코드 경로의 상태이며 전체 기술 구현이나 qualification을 뜻하지 않는다.

현재 분류: provider_dependent 48개, data_validation_pending 52개, code_incomplete 1개.

코드 범위 추적성: 101/101행 (100.0%)이 소스·근거 경로, 실제 파일, AST 파싱까지 연결됐다. 이는 코드 구현 완료율이 아니다. 별도 구현 상태에서는 `code_incomplete` capability 1개가 남아 있다.

최신 경로 감사: 101개 행 중 101개에 소스 경로가 연결되어 있다. 총 482개 파일 경로가 현재 존재하고 0개는 누락됐다. 파일 존재·SHA-256은 경로의 현행성만 기록하며 계산 구현의 완전성이나 정확성 증거가 아니다. 상세값은 `data/catalogs/implementation_scope_audit.json`의 `source_path_audit`에 있다.

카탈로그 연결 감사: 605개 구현 구성요소를 capability 자체 또는 다른 capability의 명시적 구성요소로 확인했으며, 현재 미연결 구성요소는 0개다. 연결 상태는 구현 완전성을 뜻하지 않는다.

AST 구조 감사: 482개 경로를 파싱했고, 기존의 명시 심볼 근거 92개 중 현재 선언이 없는 심볼은 0개다. 선언 위치 확인도 함수의 capability 동작 연결이나 실행 검증을 뜻하지 않는다.

`current_code_evidence`의 심볼·해시 추적이 없는 행은 ‘소스 경로 자체가 없음’과 다르다. 현재 심볼 수준 추적은 최초 코드 미완성 13개에만 있다. 나머지 88개도 코드 존재를 경로 수준으로 확인했을 뿐이며, 전체 도메인 완성 상태로 승격하지 않는다.

`provider_dependent`는 caller-owned provider/limits/qualification law가 필요한 경로다. `data_validation_pending`은 독립 자료, calibration applicability 또는 physical validation이 남았다는 뜻이다. 두 범주 모두 해당 field domain의 완전한 simulator를 뜻하지 않는다.

이 101개 항목은 분야별 규모와 완료 기준이 서로 달라 하나의 합산 구현률로 환산하지 않는다. 항목별 분류·잔여 범위와 실행 검증 상태를 함께 읽는다.
