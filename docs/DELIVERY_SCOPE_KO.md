# 완료 범위와 단계별 완료 기준

기준일: 2026-11-01. 이 문서는 사용자와 합의한 납품 범위의 우선 기준이다. 과거 개발 로그의 추가 연구 제안이나 상위 모델의 잔여 연성 설명이 자동으로 필수 구현 요구가 되지 않는다.

## 1. 범위 재정리와 실제 계산 공백 확인

기술별 기본 계산, 입력 파라미터, 데이터 입력 경로, 호출 API를 실제 코드와 대조한다. 파일 존재·AST 파싱·인터페이스 존재만으로 계산 구현을 완료 처리하지 않는다. 각 필수 항목에는 계산 함수, 지원 입력, 적용 가정과 미지원 조건을 연결한다. 근거가 부족한 항목은 검토 대기로 남긴다.

기존 101개 행은 탐색용 상위 분류다. 101행 추적률이나 100/101 구현 표시는 전체 납품 완료율로 사용하지 않는다. 필수 계산 목록을 확정한 다음 동일한 분모로 구현 완료 수를 집계한다.

## 2. 필수 계산과 API 연결

필수 계산을 구현하고 파라미터·사용자 데이터로 설정할 수 있도록 한다. 외부 모듈 연결은 입력·출력 형식, 단위, 식별자, 호출 방식, 오류와 상태 전달의 호환성을 확인한다. 연결된 전체 시스템의 새로운 연성 물리 구현·물리 검증은 필수 완료 조건에 포함하지 않는다.

이미 추가한 고급 연성 코드는 보존한다. 추가적인 공간 전위–이중층–반응수송 일체화, 이동 경계–석출–유압 일체화 등은 기술별 기본 계산 요구와 직접 대응하는 근거를 확인하기 전까지 확장 연구로 관리한다. 필수 계산의 오류 수정과 필요한 개별 모델 수치 검증은 계속 완료 조건이다.

## 3. 문서와 카탈로그 일괄 정리

필수 구현 묶음이 끝난 뒤 registry, 스키마, source/capability 카탈로그, 예제, 매뉴얼, 재개 지침을 한 번에 갱신한다. 독립 과제의 작은 변경마다 전체 생성기를 반복 실행하지 않는다. 제3자 근거·이용조건·데이터 출처는 정직하게 유지하고 제한 자료는 배포 경계 밖에 둔다.

## 4. 수치 검증

필수 개별 계산에 대해 독립 기준값, 해석해, 보존식, 극한 조건 또는 적절한 공개 관측자료를 사용한다. API 연결은 계약·단위·오류 전파를 확인한다. 계산 정확성, 실험 비교, 데이터 적합과 재료/절차 qualification을 구분하여 기록한다. 로컬과 승인된 계산 자원의 독립 작업을 병렬 배치한다.

## 진도 보고

필수 계산 구현, API 연결, 문서 정리, 수치 검증을 각각 보고한다. 각 지표에는 분모와 완료 증거를 붙인다. 목록 확정 전에는 전체 완료 백분율이나 확정 완료 시간을 제시하지 않는다.
