# 평면 scale 이동 경계의 확산·계면 반응 저항

`PlanarScaleDiffusionReactionHistory`와 `planar_scale_diffusion_reaction_history()`는 단일 치밀 고체층 두께를 계산한다. 고정 면적, 정상에 가까운 단일 종 확산, 일대일 수송종/고체 몰 수지, 무한 reservoir와 선형 계면 전달 저항을 사용한다. 모든 확산계수, 계면 전달계수, 몰부피와 부호 있는 농도차는 사용자가 근거와 함께 제공한다. 요청에 최소·최대 절대온도 적용 구간을 선언해야 하고 모든 시간 구간의 온도는 그 범위 안에 있어야 한다. 온도별 물성 보간은 수행하지 않는다.

각 구간에서 몰 flux는 `J = delta_c / (L/D + 1/k)`이고 `dL/dt = Vm*J`다. `a=D/k`, `b=Vm*D*delta_c`로 두면 `L²+2aL`의 변화율은 `2b`다. 이 수지를 직접 적분하고 양의 이차근을 유리화해 두께를 계산한다. 양의 농도차는 성장, 음의 농도차는 용해 방향이다. 이동한 고체 몰 수/면적은 `(L_end-L_start)/Vm`로 기록한다. 구간별 계수는 일정하며 구간 경계에서 두께를 연속 전달한다.

용해 중 두께가 0에 도달하면 그 시각에서 종료한다. `termination=scale_depleted`와 `full_requested_history_completed=false`를 확인한다. `computed`는 이 제한된 event까지 계산했다는 뜻이며 이후 요청 구간을 완료했다는 뜻이 아니다. Scale 소진 후 음의 두께를 만들거나 기판 부식을 대신 계산하지 않는다.

이 모델은 일반적인 이동 경계 수지를 독립적으로 코드화한 사용자 모델이다. 자동 상 발견, 활동도에서 농도차 생성, 핵생성, 비화학양론 수송, 전하/전기장, 유한 reservoir, 다공성 변화, 부착/박리, scale 보호효과, 전극과의 동시 연성을 제공하지 않는다. 입력 온도는 계수 적용 조건을 보존하며 온도 의존 계수를 추정하지 않는다. 실제 부식률 또는 설계 적합성을 뜻하지 않는다.

수치 실행·테스트·실험 검증은 수행하지 않았다. 후속 검증은 0 농도차의 일정 두께, 반응 저항 지배의 단시간 한계, 확산 저항 지배의 포물선 성장, 음의 농도차 소진 시각, 구간 분할 불변성과 수치 극한을 포함해야 한다. 이 문서는 검증 결과가 아니다.
