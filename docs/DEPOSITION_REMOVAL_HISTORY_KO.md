# 침착·표면 제거의 층별 기하 이력

`fabrication.deposition_removal_history`는 한 위치에서 공통 법선 방향을 따라 정의한 균일 두께의 층을 계산한다. 초기 층은 모재 쪽부터 바깥쪽 순서다. 침착은 새 층을 최상부에 추가하고, 제거는 최상층부터 아래로 진행한다. 층을 완전히 제거해도 식별자는 남으며 재사용할 수 없다.

## 입력

`DepositionRemovalHistory`에는 자산·위치·실제 영역·좌표계·바깥 법선 식별자, 초기 층과 실행 순서대로 정렬한 이벤트, 근거와 검토 상태가 필요하다. `DepositedLayerGeometry`는 층·재료 상태·두께·입력 출처·기록 해시를 가진다. `LayerGeometryEvent`는 침착 또는 표면 제거이며 양의 두께를 받는다. 침착에는 새 층과 재료 식별자가 필요하다.

각 두께의 `thickness_origin`은 `measured` 또는 `procedure_target`이다. 이는 공급된 두께의 출처이며 계산된 잔여 두께가 실측값이라는 뜻이 아니다. 제거량을 입력자가 지정하므로 고정된 연삭 비율은 내장하지 않는다. `history_digest`는 정규화한 초기 층과 순서 있는 이벤트를 해시한다. 검토되지 않은 형상·순서는 `needs_data`다.

## 출력과 범위

이벤트별 제거 대상 층·제거 두께·잔여 층 스냅샷과 최종 노출 층을 반환한다. 초기 두께에 누적 침착을 더하고 누적 제거를 뺀 값과 최종 합계의 수치 잔차를 제공한다. 선언한 층 전체보다 깊게 제거하면 모재 깊이를 추론하지 않고 `out_of_scope`로 반환한다. 수치 오버플로도 결과 보류 대상이다.

초기 층 4 mm에 2 mm를 침착하고 3 mm를 제거하면 새 층 2 mm와 초기 층 1 mm가 제거되어 초기 층 3 mm가 남는다. 순서를 바꾸면 총 두께가 같더라도 최상층 재료는 달라질 수 있다.

이 API는 국부 두께 장부다. 면적·질량·용입·희석·열이력·변형·조직 변화·균열·시공 승인을 계산하지 않는다. 실제 공간적으로 변하는 층에 적용하려면 위치별 검토된 입력이 필요하며 자동 공간 분할은 제공하지 않는다. 하프 비드·버터링 작업의 기하 일부를 지원하며 전체 절차를 검증한 것은 아니다.

## 검증 기록

`tests/test_deposition_removal_history.py`의 11개 사례가 통과했다. 층을 가로지르는 제거와 보존식, 빈 초기 상태, 전량 제거, 범위 초과 제거, 순서 효과, 식별자 재사용·중복 거부, 해시 변조, 검토 누락, 오버플로, 기본 레지스트리 Python/JSON 교환과 자산 일치를 확인했다. 입력은 직접 작성한 수학 사례이며 독립 실험 검증이 아니다.
