# 가스켓 접합부 계산·근거 검토

`fabrication.elastic_joint_load` 1.0.1은 선형 두 스프링의 접촉 유지 상태를 계산한다. 볼트·체결부 강성(N/m), 초기 볼트 힘(N), 외부 분리력(N), 체결부와 볼트의 자유 열팽창 차(m)를 받는다. 적용성 검토가 없으면 계산을 보류한다. 이는 기존 API의 수치 안정성 수정이며 입력 계약은 바뀌지 않았다.

강성 분담률은 최대 강성으로 정규화해 계산하며 직렬 등가 강성은 작은 강성에 기반한 비율식으로 구한다. 강성의 곱이나 합이 표현 범위를 넘더라도 최종 힘이 유한하면 계산할 수 있다. 최종 힘 자체가 범위를 넘으면 비유한 값을 내보내지 않고 `out_of_scope`로 반환한다. 선형 계산에서 접촉 유지가 불가능한 경우에는 부호 있는 후보 힘을 보존하고 적용 범위 밖으로 반환한다. 접촉이 열린 뒤의 비선형 분배를 선형식으로 이어 계산하지 않는다.

`fabrication.gasket_joint_evidence` 1.0.1은 단일 착좌 결과가 사용자 지지영역에서 요구하는 최소 결과 수를 충족하는지 확인한다. 현재 계약은 착좌 결과 하나를 받으므로 최소 기록 수가 2 이상인 요청은 `needs_data`다. 동일 결과를 복제해 개수를 채우지 않는다. 결과에는 실제 착좌 기록 수와 요구 수가 포함된다. 여러 결과를 요구하는 절차는 독립 기록을 집계하는 별도 계약으로 확장해야 한다.

두 모델은 서로 다른 범위다. 선형 계산은 재료 선택표·착좌 계수·최대 서비스 온도·산소 청정도·누설 기준을 제공하지 않는다. 근거 API는 사용자 지지영역을 비교하며 공급자의 계산이나 시험을 대체하지 않는다. 볼트 산포, 착좌·이완 근거, 재료·매질 식별자와 적용 범위를 유지하되 표면 경도 차이나 인증서·청정도 요구 충족까지 자동 추론하지 않는다.

검증은 강성 크기 1e-200·1·1e200에서 일정한 응답, 합이 표현 범위를 넘는 동등 강성, 힘·접촉 경계, 실제 수치 범위 초과, 착좌 기록 수 부족, 기존 근거 조건 및 두 API의 Python/JSON 동일성을 포함한다. 수학적 검증과 물리 시험 qualification은 구분한다.
