# 용접 에너지·제어·열처리의 구현 경계

열입력 API는 명시된 전력·이동 속도 또는 측정 에너지를 사용한다. 파형 제어 공정에서는 동기화된 순간 전력의 적분이나 실제 에너지 기록을 사용해야 하며, 평균 전압과 평균 전류의 곱을 같은 값으로 가정하지 않는다. 효율·범위·사용 권한은 호출자의 근거와 연결한다.

궤도 용접의 운동·위치·취득 동기화와 상용 단락 이행 제어는 일반 열입력 계산과 별개다. 공급자 공정명이나 생산성 설명으로 폐루프 제어기·성능 검증의 구현을 주장하지 않는다.

국부 열처리 API는 센서별 유지 온도대의 시간과 관측 위치의 구배를 평가한다. 측정하지 않은 체적의 온도나 최대 구배를 입증하지 않는다. 유지대·가열대·구배 제어대의 크기, 겹침과 형상 조건은 승인된 절차·기준과 별도로 대응해야 한다.

`thermal.thickness_soak_duration`는 단일 두께 비례 시간과 최소시간 중 큰 값을 계산한다. `thermal.piecewise_thickness_soak_duration`는 두께 구간마다 다른 계수를 누적하고 기준시간과 최소시간을 적용한다. 계수·구간·적용성은 사용자 근거로 입력한다. 시간 계산만으로 오스테나이트화·균질화·입자 성장을 예측하지 않는다.

이번 문서는 요구 분류 기록이며 새 수치 검증 실적을 추가하지 않는다.
