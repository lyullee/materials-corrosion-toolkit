# 설계 기준·단위와 강도 후보의 지배값

`materials.scaled_strength_minimum`은 사용자 입력 강도 후보 각각에 양의 계수를 곱한 뒤 최솟값과 모든 동률 후보 식별자를 반환한다. 후보마다 물성 정의·강도(Pa)·계수·물성 기록 해시가 필요하다. 전체 요청은 재료 상태·온도·후보·계수를 `CorrelationBasis`의 근거·권한·적용성 검토와 해시에 연결한다.

예를 들어 직접 작성한 강도 600 MPa에 0.25, 300 MPa에 0.6을 적용하면 후보값은 150 MPa와 180 MPa이며 전자가 지배한다. 이 예제의 계수는 규격 선택이나 실제 설계 권고가 아니다. API는 항복·인장·크리프 물성 또는 규격 계수를 생성하지 않으며, 최솟값이 규격상 허용응력이라는 승인도 제공하지 않는다. 기존 `materials.allowable_property_provider`는 제공된 표의 지원 범위 내 보간을 담당하며 별도 역할이다.

검증 파일 `tests/test_scaled_strength_minimum.py`의 7개 사례는 후보별 값·지배값·동률, 오버플로·언더플로, 중복 식별자, 해시 변조, 기본 레지스트리 Python/JSON 교환을 확인한다. 독립 실험 검증은 아니다.

## 단위 처리

`units.absolute_pressure`는 게이지압을 변환할 때 양의 유한 대기압을 명시적으로 요구한다. 음의 게이지압도 합산한 절대압이 양의 유한 값이면 허용한다. 대기압의 불리언 값과 합산 오버플로는 거부한다. 절대 온도는 `degF`·`degC`, 온도차는 `delta_degF`·`delta_degC`처럼 구분한다. 관련 경계 사례와 기존 공학 계산 17개가 통과했다.

정확한 차원 변환과 규격의 공칭 치수·반올림 표는 구분한다. 전압력·부분압·게이지압·차압은 의미가 다르며 기체 조성 및 상태 가정 없이 서로 바꾸지 않는다.

## 남은 설계 요구 대응

설계 수명은 입력 요구이며 장비 종류만으로 잔여수명이나 고장 분포를 만들지 않는다. 승인 도면, 복수 재료 표시, 준공·숨은 부품 이력, 문서 보존·담당 역할은 해당 권한과 실제 대상별 근거가 필요하다. 일반 기록 계약은 이 전체 의무의 이행을 증명하지 않는다.

탄성·소성 설계 구분과 평면응력·평면변형률 가정은 별개의 판단이다. 허용 금속 온도 경계와 실제 금속 표면 온도도 구분해야 한다. 문서 이름이나 표 참조가 있다는 이유로 연결된 물리 모델의 구현 완료를 선언하지 않는다.
