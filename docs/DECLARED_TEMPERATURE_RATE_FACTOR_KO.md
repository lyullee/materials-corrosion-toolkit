# 온도 간격에 따른 사용자 속도 배수

`degradation.declared_temperature_rate_factor`는 사용자가 지정한 온도 간격과 그 간격당 속도 비율로 기준 온도 대비 배수를 계산한다. 식은 `배수 = 간격당 비율 ** ((평가 온도 - 기준 온도) / 온도 간격)`이다. 온도는 K, 온도 간격은 K 차이, 비율과 배수는 무차원이다. 섭씨 온도값을 절대 온도 입력에 직접 넣지 않는다.

입력에는 재료 상태·기구 식별자, 평가·기준 온도, 양의 온도 간격, 양의 간격당 비율, 보정된 온도 하한·상한이 필요하다. 비율이 1보다 작으면 온도 상승에 따라 속도가 감소하는 사용자 식이다. 기준 온도는 적용 범위 안에 있어야 하며 평가 온도가 범위를 벗어나면 외삽하지 않는다. 계수·사용 권한·적용성은 전체 요청 해시와 `CorrelationBasis` 근거에 묶인다.

로그 공간에서 계산하고 온도 차이·간격·로그 계수의 결합에는 정확 유리수를 사용한다. 비율 1은 아주 작은 간격에서도 정확히 배수 1을 준다. 양의 배수가 0으로 소실되거나 필수 출력이 표현 불가능하면 `out_of_scope`이며 배수를 반환하지 않는다. 로그와 지수함수는 부동소수점 근사다.

결과의 `equivalent_time_rate_multiplier`를 `AgingExposureInterval`의 같은 이름 입력에 전달할 수 있다. 그때 재료 상태·기구·기준 온도·배수 제공자·적용 범위를 열화 노출 봉투와 일치시켜야 한다. 기존 노출 API의 구간 완전성·시간·근거 검토를 생략하지 않는다. 한 구간의 일정 온도에 적용한 배수를 제공하는 방식이며, 연속 온도 이력을 자동 적분하거나 전체 구간의 평균 온도와 동일하다고 가정하지 않는다.

특정 합금이나 반응의 기본 비율·간격·온도 한계를 제공하지 않는다. 이 식은 Arrhenius 법칙이나 반응 기구를 자동으로 선정하지 않으며, 속도 계수의 독립 보정과 검증이 필요하다. 배수나 등가 노출만으로 상분율·침투 깊이·물성 감소·잔여 수명·수락을 정하지 않는다.
