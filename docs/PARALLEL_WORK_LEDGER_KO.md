# 병행 작업 기록

2026-10-30 사용자 승인에 따라 독립 구현과 한강 검증 제출을 병행한다. 작업 범위는 이 matintegrity 디렉터리다. 다른 프로젝트의 파일과 원격 job은 변경하지 않는다.

| 작업 | 담당 | 현재 근거와 상태 | 다음 산출물 |
|---|---|---|---|
| 한강 검증 제출 | hangang_dispatch | 기존 cpu 공유 연결과 Slurm 사용 가능 확인. 다른 프로젝트 job 2개는 유지. 우리 stage 준비 중이며 아직 job ID 없음 | source snapshot 식별자, 제출 명령, job ID, 로그 위치 |

검증 job 완료를 구현의 선행조건으로 삼지 않는다. 결과가 도착하면 실제 로그와 종료 상태를 확인하고 실패 원인을 분석한 뒤 독립 후속 작업을 제출한다. 살아 있는 job은 관측 지연만으로 다시 제출하지 않는다. 제출 전 입력·코드 snapshot과 task 범위를 고정하고 기존 job과 중복을 확인한다.

현재 넓은 범위 추적 지표는 47/101(46.5%)다. 구현 중인 작업, 정적 연결, 소프트웨어 검증, 물리 검증을 각각 구분하며 이 기록만으로 진행률을 높이지 않는다.
