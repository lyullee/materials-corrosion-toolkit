# 용액 농도 기준과 세정 재료 연결

`chemistry.solution_concentration_conversion`은 `matintegrity.models.engineering_correlations.SolutionConcentrationConversion`을 받는다. 입력 기준은 질량분율, 질량농도(kg/m³), 물질량농도(mol/m³), 순수 성분 부피/최종 용액 부피 중 하나다. 입력 숫자에 퍼센트 의미를 자동 부여하지 않는다. 10% 질량분율은 0.1로 넣어야 하며 mol/L는 mol/m³로 단위를 명시적으로 바꿔 넣는다.

용액 밀도(kg/m³)와 용액 상태 ID를 제공한다. 물질량 변환에는 해당 성분의 몰질량(kg/mol)이 필요하다. 순수 성분 부피 기준에는 순수 성분 밀도와 그 상태 ID가 함께 필요하다. 필요한 물성이 없는 입력 기준은 거부한다. 다른 기준에서 선택적 물성을 주지 않은 경우 그 변환 출력은 `null`이다. 성분 ID를 바꾸어 상용 원액의 질량과 유효 용질 질량을 혼동하지 않는다.

질량농도는 질량분율×용액 밀도 또는 물질량농도×몰질량으로 계산한다. 순수 성분 부피 기준은 순수 성분 밀도로 질량농도에 연결한다. 순수 성분의 밀도로 환산한 부피와 실제 혼합 후 부분 몰부피는 다르다. 부피 가산성, 원액 순도, 혼합열, 반응, 활동도·pH를 추론하지 않는다. 총 용액 질량보다 성분 질량이 커지는 상태나 수치 범위를 벗어난 변환은 `out_of_scope`다.

모든 상태·물성·기준은 `CorrelationBasis`의 적용성·단위·권한 검토와 정규화된 전체 입력 해시에 묶인다. 밀도 공급자를 자동 선택하지 않는다. 검토된 외부 물성 또는 측정 밀도를 사용할 수 있으며 혼합 용액에 순수 유체 물성을 자동 대입하지 않는다. 기본 레지스트리의 Python·JSON 경로를 사용한다.

`fabrication.chemical_cleaning_envelope` 1.1.0은 각 사용 지지영역의 `material_condition_id`가 요청의 재료 상태와 정확히 일치해야 비교한다. 기존 입력은 새 필드를 생략해도 파싱되지만, 재료 연결이 없는 지지영역으로 적합성을 판정하지 않고 `needs_data`로 반환한다. 다른 재료이면 `out_of_scope`다. 단순히 요청의 `material_identity_reviewed=true`를 지정하는 것으로 지지영역의 재료 연결을 대신할 수 없다.

마이그레이션은 지지영역의 실제 적용 재료·상태를 확인한 뒤 해당 ID를 채우는 방식이다. 요청 ID를 검토 없이 복사해 넣어서는 안 된다. 자산·위치와 실행 문맥도 일치해야 한다. 새 스키마는 `ChemicalCleaningRecord.json`과 `CleaningCompatibilityEnvelope.json`이다. 용액 ID·농도·온도·pH·노출시간 비교는 기존과 같이 사용자 지지영역의 범위만 평가하며 반응 속도·피막 성능·세정 완료를 보장하지 않는다.

검증은 네 농도 기준의 일치, 서로 다른 질량·부피 비율, 미지 물성의 `null` 처리, 필요한 물성 누락·불가능한 질량비 거부, 0 농도·수치 범위, 재료 연결 누락·불일치, 기존 노출 비교 및 두 API의 Python/JSON·문맥 일치를 포함한다.
