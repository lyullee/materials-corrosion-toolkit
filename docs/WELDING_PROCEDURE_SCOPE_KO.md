# 용접 절차와 계산 모델의 대응

이 표는 구현된 계산과 아직 절차별 대응이 필요한 기능을 구분한다. 자료를 입력하거나 공급자 결과를 비교할 수 있다는 사실만으로 그 결과를 만드는 물리 계산이 구현된 것은 아니다.

| 요구 | 현재 지원 | 남은 작업·의존성 |
|---|---|---|
| 용접성 | 조성 지수, 재료·용가재 적합성 비교 | 형상·자세·순서·환경·인력·검사 조건의 절차별 대응. 단일 점수로 용접성을 승인하지 않는다. |
| 후열 수소 제거 | 명시한 확산계수 이력과 경계조건을 사용하는 판재 확산 | 재료·서비스별 후열 조건, 변태 상태 및 현장 적합성 근거. |
| 하프 비드 | 템퍼 비드 관측 비교와 `fabrication.deposition_removal_history`의 국부 잔여 두께 계산 | 공간적으로 변하는 연삭 형상과 절차·조직 적합성은 별도 근거가 필요하다. |
| 버터링 | 층별 식별자와 사용자 적합성 규칙 | 희석·가공 후 두께·열처리 순서·액화균열에 대한 전용 계산 또는 검증된 공급자 연동을 더 확인해야 한다. |
| 운전 중 용접 | `welding.hot_tap_applicability`의 공급자 결과·적용 범위 비교 | 열·용락 및 수소 균열 결과 자체는 이 API가 계산하지 않는다. 실제 계산기·입력·검증 근거 연결이 필요하다. |
| 운전 유체 냉각 | 공급자가 선언한 열 제거 조건의 식별·비교 | 유동 조건과 이동 열원의 정량 열전달 대응이 필요하다. 속도 설명자만으로 열전달계수를 추론하지 않는다. |
| 용가재 명칭 | 정확한 재료·용가재·서비스 식별 | 분류 기호, 미희석 용착부 시험값, 실제 이음부 성능을 구분한다. 기호를 측정값으로 변환하지 않는다. |

## 다음 구현 판단

하프 비드·버터링의 국부 침착·제거·잔여 두께는 전용 연산으로 지원한다. 측정 입력과 절차 목표 입력은 구분하며 계산된 잔여 형상은 관측값이 아니다. 열·수소 연동은 기존 공급자 계약만으로 완료 처리하지 않고, 실제 모델과 적용 범위의 연결을 확인한다. 경험계수·절차 제한·제품별 데이터가 필요한 경우 명시적 외부 의존성으로 남긴다.

층별 기하 연산의 수치 확인은 DEPOSITION_REMOVAL_HISTORY_KO.md에 기록했다. 그 밖의 요구 분류는 새 수치 검증 실적으로 계산하지 않는다. 독립 실험 검증 및 절차 승인과 구분한다.

## 재료별 용접과 열처리의 추가 대응 과제

니켈·티타늄·탄탈럼은 재료·공정·서비스 조건별 근거가 필요하다. 이동 아크 열입력 지표를 저항 용접 접촉 발열 계산으로 대체하지 않는다. 열처리 이력·시간당 두께 계산은 응력 완화·조직 변화·강도·인성의 실제 응답을 계산하지 않는다.

안정화 열처리는 재료별 석출 경쟁과 민감화 근거, 저온 처리는 가역적인 끼워맞춤 수축과 상변태의 구분, 피닝은 잔류응력 관측과 절차 순서·권한 확인이 남아 있다. 공급자 표의 존재나 이력 입력 기능만으로 이 물리 기능들을 완료 처리하지 않는다.
