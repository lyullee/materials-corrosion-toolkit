# 기본 재료 계산의 수치 범위

`materials.tensile_point`, `materials.ductility_retention`, `corrosion.charge_to_loss`의 계산 버전은 1.0.1이다. 입력 계약은 유지한다. 유한한 이진 입력을 정확 유리수로 결합한 뒤 필요한 출력별로 변환한다. 필수 비영 결과가 표현 범위를 벗어나거나 0으로 소실되면 `out_of_scope`이며 부분 수치를 반환하지 않는다. 명시적으로 주어진 영 하중·영 연신·영 전하는 계산 가능한 0이다.

인장 변환은 초기 단면적과 표점 길이에 대한 공칭 응력·변형률을 반환한다. 균일 변형을 선언한 경우에만 진응력과 로그 변형률을 추가한다. 네킹 이후의 실제 단면적·국부 변형률이나 시험 적합성은 추론하지 않는다.

연성 비교는 노출 후 연신율을 기준 연신율로 나눈 유지율과 그 보수를 반환한다. 노출 후 연신율이 더 크면 손실은 음수로 유지한다. 손실은 이미 반올림한 유지율에서 다시 빼지 않고 입력 비율에서 직접 계산한다. 시편·시험 조건의 동등성과 통계적 차이는 별도 근거가 필요하다.

전하 기반 손실은 양극 전하·용해 당량·전류 효율로 질량을 구하고 명시적 밀도로 체적을 구한다. 중간 곱이 넘쳐도 최종 출력이 표현 가능하면 계산할 수 있다. 부식 전류 분리, 선택 용해, 국부 침투 형상과 최대 깊이는 이 변환으로 정하지 않는다. 현재 효율 입력 범위는 기존 계약인 0 초과 1 이하를 유지한다.
