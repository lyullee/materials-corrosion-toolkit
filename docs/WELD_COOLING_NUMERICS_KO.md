# 용접 냉각시간 계산의 수치 범위

`welding.cooling_interval`은 주어진 이력의 온도 교차 시간을 구한다. `welding.cooling_time_correlation`은 사용자가 지정한 2D 또는 3D 상관식 계수로 냉각시간을 계산한다. 열유동 차원과 계수의 적용성은 사용자가 확인해야 한다.

상관식 계산은 정확 비율 산술로 온도차·역수 차·열입력 제곱과 계수를 결합한다. 중간 연산의 넘침이나 소실 때문에 표현 가능한 최종 결과를 잃지 않는다. 최종 시간 또는 유효 계수가 부동소수점 범위를 벗어나면 `out_of_scope`로 보류한다. 비양의 유효 계수도 계산 시간을 반환하지 않는다.

재료별 기본 계수·접합 형상 표·차원 선택 차트는 내장하지 않는다. 계산 시간은 경도·균열·절차 적격성이나 제품 합격 판정을 대신하지 않는다.

수치 범위 보완을 반영한 API 버전은 `welding.cooling_time_correlation` 0.1.1이다. 입력 필드와 단위 계약은 유지한다.
