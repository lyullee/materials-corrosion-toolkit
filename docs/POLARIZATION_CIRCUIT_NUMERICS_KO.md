# 분극과 갈바닉 회로 계산의 수치 범위

`corrosion.stern_geary`와 `corrosion.galvanic_linear`의 1.0.1은 입력 비율을 정확 유리수로 계산한 뒤 필요한 출력만 부동소수점으로 변환한다. 중간 역수·전위 차·직렬 저항 합의 넘침이나 소실이 비영 결과를 0으로 바꾸지 않도록 한다. 필수 비영 출력이 표현 불가능하면 `out_of_scope`이며 부분 수치를 완료 결과로 내보내지 않는다.

Stern–Geary 입력의 양극·음극 Tafel 기울기는 양의 크기이며 단위는 V/decade다. 자연로그 기준 기울기와 혼용하지 않는다. 분극 저항은 노출 면적으로 정규화되고 용액 저항이 상류에서 보정돼야 한다. 입력값만으로 활성화 지배·작은 신호 범위를 입증하거나 옴 강하를 자동 보정하지 않는다. 계수와 전류 밀도는 각각의 정확한 식에서 변환하므로, 극단 수치에서 반올림된 표시 계수로 전류를 다시 계산하면 차이가 날 수 있다.

선형 갈바닉 모델은 같은 전위 기준의 자유 전위, 두 전극의 면적·면적 정규화 분극 저항, 전해질 저항을 사용한다. 선언된 양극·음극 역할이 뒤바뀌면 계산 범위 밖이다. 두 전극의 선형 과전압 한계는 반올림 전 수치로 비교한다. 한계를 벗어났을 때 기존처럼 유한 진단 수치는 반환하지만 상태는 `out_of_scope`다.

두 자유 전위가 같으면 추가 결합 전류는 정확히 0이다. 이는 두 금속의 자기 부식이 없다는 의미가 아니다. 이 계산은 추가 결합 전류만 다루며 질량 전달 지배, 부동태·피막 변화, 실제 용해 전류 분리나 부식 손실을 자동 추정하지 않는다. 조건·전위 기준·분극 자료를 보존한 상위 평가에는 `degradation.galvanic_coupling` 등의 별도 계약을 사용할 수 있다.

검증: `tests/test_polarization_circuit_numeric_range.py`와 기존 물리 계산 회귀, 합계 22개 사례. `artifacts/validation/polarization_circuit_numeric_range.xml`에 기록했다. 극단 수치 사례는 소프트웨어 범위 확인이며 극단적인 물성·면적·기울기의 물리적 적용성을 검증한 것은 아니다. 실제 측정 보정, 반응 범위, 재료·환경 적용성은 별도 근거가 필요하다.
