# 두께 구간별 누적 유지시간

`thermal.piecewise_thickness_soak_duration`는 기준시간에 두께 구간별 기여 시간을 더한 후 최소 유지시간을 적용한다. 계약은 `PiecewiseThicknessSoakDuration`이다. 구성품·절차 식별자, 지배두께(m), 최소 지원 두께, 기준시간(s), 최소시간(s) 및 `ThicknessSoakBand` 배열을 받는다.

각 구간은 고유 식별자, 상한 두께(m), 0 이상의 시간 계수(s/m)를 가진다. 첫 구간은 두께 0에서 시작하고 다음 구간은 이전 상한에서 시작한다. 마지막 상한이 최대 지원 두께다. 질의 두께가 실제 적용 범위를 벗어나면 외삽하지 않는다. 최소 지원 두께는 적용성 제한이며 누적 계산의 시작점을 바꾸지 않는다.

계산식은 `기준시간 + Σ(해당 구간에 들어가는 두께 × 구간 계수)`다. 이 값과 선언된 최소시간 중 큰 값을 요구시간으로 반환하며, 동률이면 두 조건을 모두 남긴다. 단일 구간으로 가산 기준시간과 선형 계수를 가진 식도 표현할 수 있다.

직접 작성한 예로 기준시간 100초, 첫 0.04 m에 10,000 s/m, 그 이후에 2,000 s/m를 적용하면 두께 0.08 m의 시간은 `100 + 0.04×10000 + 0.04×2000 = 580초`다. 이는 산술 예제로 실제 열처리 권고 계수가 아니다.

입력 계수·지원 범위·절차·권한은 `CorrelationBasis`의 근거와 해시에 연결한다. 구간별 적용 두께·기여시간·합계와 지배 조건을 반환한다. 오버플로 및 양의 기여시간이 0이 되는 언더플로는 `out_of_scope`다. 기준과 계수를 0으로 선언할 수 있으나 이는 물리적으로 유지시간이 필요 없다는 판단을 자동으로 제공하지 않는다.

이 계산은 승인된 일정의 산술 표현이다. 실제 온도 균일성, 오스테나이트화, 입자 성장, 조직·기계적 성질이나 시공 적합성을 예측하지 않는다. 기존 단일 비례·최소시간 모델 `thermal.thickness_soak_duration`도 계속 사용할 수 있다.

`tests/test_piecewise_thickness_soak.py`의 12개 사례는 구간 내부·경계·상한, 보존되는 적용 두께 합계, 최소시간·동률, 지원 범위, 구간 순서, 수치 범위, 해시 변조, 기본 레지스트리 Python/JSON 교환을 확인한다. 독립 실험 검증은 아니다.
