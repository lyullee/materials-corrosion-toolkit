# 기계시험 기능과 절차의 구분

계산 API가 있다는 사실만으로 시험 절차 전체를 구현했다고 판단하지 않는다. 시험편·방향·재료 상태·온도·장비·보정·유효성·사용자 기준과 원자료를 함께 관리한다.

| 대상 | 기존 기능 | 남은 적용 요구 |
|---|---|---|
| 인장 단일점 | `materials.tensile_point` | 원단면적·표점거리·균일 변형 가정 |
| 오프셋 항복점 | `inspection.tensile_offset_yield_curve` | 원시 곡선·탄성 적합 구간·유일 교차·독립 비교 |
| 상온·고온·두께 방향 인장 보고 | `inspection.tensile_offset_yield_campaign` | 방향·온도·변형률 속도·장비 보정·관측값과 사용자 기준 |
| 크리프·피로 | 개별 수명 계산 및 캠페인 API | 시험 제어·검열 자료·파단 판정·절차별 유효성 |
| 전단·접합층 | 평균 전단 및 접합층 평가 API | 시험편별 하중 전달·계면 관찰·수소 노출 조건 |
| 굽힘 | 성형 변형률 계산 | 시험 방향·치구·균열 관찰 및 절차 기준 |
| 압궤·편평·역편평·확관·플랜지 | 개별 시험 절차 연결이 필요 | 치구·변위·유지시간·관찰·제품별 사용자 기준 |
| 내압 증명시험 | 별도 승인된 절차 필요 | 시험 압력에서 허용 운전압력으로 자동 환산하지 않음 |

두께 방향 인장의 단면 수축률과 성형 전후 단면 변화는 같은 계산 형태를 사용할 수 있지만 측정 목적과 물리 단면의 동일성은 별도로 확인한다. 튜브시트 접촉을 전제로 하는 확관 계산을 자유 확관 시험에 적용하지 않는다. 균일 인장·고온 인장·장기 크리프 결과는 서로 대체하지 않는다.

규격 치수·제품 등급별 기준표·시험 합격 기본값은 내장하지 않는다. 허가된 절차와 자료는 사용자 입력 또는 외부 제공자 계약으로 연결한다. 절차 연결이 남은 항목을 코드 완료나 물리 검증 완료로 집계하지 않는다.
