# 분석 종류별 조성 경계 비교

## 허용차 계산과 원래 경계의 역할

`materials.declared_analysis_tolerance_recipe`는 사용자가 제공한 구간별
일차식으로 제품 분석 허용차를 계산한다. `original_specified_limit_mass_fraction`은
측정값이 아니라 원래 규정된 최소 또는 최대 질량분율이다. `boundary_role`로
어느 경계를 계산하는지 명시한다. 양쪽 경계가 다르면 별도로 호출한다.
`branches`에는 각 구간의 양 끝값·포함 여부와 곱셈 계수·가산항을 넣는다.
상수 허용차는 곱셈 계수를 0으로 제공할 수 있다.

정확히 한 구간만 일치해야 한다. 구간 공백·중복에서 첫 항목을 고르거나
외삽하지 않는다. 서비스의 허용차 적용 권한이 없으면 `needs_data`, 결과가
음수·질량분율 범위 밖이거나 비영 값이 소실되면 `out_of_scope`다.
계산 결과를 비교 API의 대응 하한·상한 허용차에 명시적으로 전달한다.
이 API는 제품·등급·원소 이름으로 구간표를 자동 선택하지 않는다.

원소 기호의 다른 표기나 의심스러운 수치·범위는 원래 관측과 근거를 보존하고
공급자가 확인해야 한다. 이름만으로 다른 원소나 합산 원소로 치환하지 않는다.

`materials.declared_chemical_analysis_comparison`은 용탕 분석과 제품 분석을
구분해 사용자가 제공한 원소별 질량분율 경계를 비교한다. 원래 최소·최대값과
하한 아래·상한 위 허용차를 별도로 입력한다. 허용차가 하나라도 비영이면
제품 분석이며 적용 권한을 확인한 요청만 허용한다. 기본 허용차는 0이다.
상용 규격표나 제품별 자동 계수 선정은 포함하지 않는다.

각 원소 경계에는 근거 식별자, 관측에는 측정·시료·방법·원자료 해시가 필요하다.
제품·용탕·재료 상태·지배 요구와 전체 요청 해시는 비교 결과의 계보를 보존한다.
상위 `basis`는 다른 산술 API처럼 전체 입력과 사용 권한 근거를 고정한다.
PMI라는 방법 이름을 실험실 제품 분석과 동등하게 취급하지 않으며,
시료 채취와 분석 종류의 적합성을 별도로 확인해야 한다.

유효 하한은 원래 하한에서 허용차를 뺀 값, 상한은 원래 상한에 허용차를
더한 값이다. 없는 경계를 만들거나 결과를 0·1로 잘라내지 않는다.
허용차 적용 후 질량분율 범위를 벗어나는 요청은 거부한다.
측정값과 확장불확도는 둘 다 제공하거나 둘 다 누락으로 남긴다.

측정 구간 전체가 경계 안이면 `within_declared_interval`, 전체가 바깥이면
`outside_declared_interval`, 경계와 겹치면 `uncertainty_overlap`이다.
기준 경계에 정확히 닿는 값은 포함한다. 같은 원소의 반복 시료는 평균내지
않고 모두 보존하며 요구 원소가 관측되지 않으면 `needs_data`로 반환한다.
제공된 관측에 대응 경계가 없으면 요청 자체를 거부한다.

## 명시적 합산 원소 규칙

`sum_rules`에는 규칙 ID, 관측 ID 목록, 하한·상한과 근거 ID를 입력한다.
관측은 모두 같은 시료에 속하고 서로 다른 원소여야 한다. 없는 관측 ID,
같은 원소의 반복 측정 중복 합산과 다른 시료의 혼합은 거부한다.
개별 원소 허용차를 합산 경계에 자동으로 더하지 않는다. 합산 허용 범위는
사용자가 직접 제공한다. 구성 관측이 누락되면 합도 미확정으로 남긴다.

합산 불확도는 구성 관측의 제공된 확장불확도를 산술 합산한 구간 경계다.
독립성, 공분산, 합의 통계적 신뢰수준을 추정하지 않는다. 필요하면 호출자가
별도 검토한 결합 불확도 모델을 사용해야 한다. 합산 결과와 개별 원소 결과는
분리하므로 개별 원소가 모두 경계 안이어도 합산 규칙 위반을 확인할 수 있다.

API 버전 0.1.1은 `sum_rules`를 추가한다. 빈 목록도 정규화된 전체 요청에
포함되므로 이전 입력을 재사용할 때 전체 요청 해시와 근거 해시를 재생성한다.

`computed`는 비교를 수행했다는 상태다. 재료 승인·규격 적합성·원소 합계
폐쇄·자동 합산 규칙 선정·반올림 허용·다른 서비스 요구의 면제를 의미하지 않는다.
이러한 요구에는 별도 규칙과 근거가 필요하다. 개별 경계의 유리수 비교는
부동소수점 덧셈에 의한 경계 판정 변화를 줄이지만 입력 측정의 정확도를
높이지 않는다.

## 0.1.2 선형 조성 조건

`linear_rules`에 `ChemicalAnalysisLinearRule`을 제공하면 `constant_offset + sum(coefficient * measured_mass_fraction)`를 사용자 경계와 비교한다. 예를 들어 사용자가 작성한 `X - 2Y >= 0` 조건을 명시적 측정 ID 두 개로 표현할 수 있다. 고정 규격 계수나 조건 자동 선택은 제공하지 않는다. 계수는 무차원이며 값·상수·경계는 질량 분율 입력에 맞춘 무차원 선형 표현이다. 결과가 물리적인 한 원소의 질량 분율인 것은 아니다.

한 규칙의 측정은 같은 시료·서로 다른 원소여야 한다. 불확도 구간의 반폭은 `sum(abs(coefficient) * expanded_uncertainty_mass_fraction)`로 계산한다. 이는 주어진 구간의 보수적 산술이며 독립성·공통 통계적 포함 확률을 가정하지 않는다. 단순 합계 규칙의 의미는 유지한다. 제품 분석 허용차는 원소별 한계에만 적용하며 선형 조건의 경계를 자동 완화하지 않는다.

미보고 측정은 선형 결과도 `unknown`으로 남고 계산 상태는 `needs_data`다. 비영 결과 또는 구간이 수치로 표현 불가능하면 부분 비교 결과를 반환하지 않고 `out_of_scope`다. 계수·상수·경계·측정 대응은 입력 해시에 포함된다. 새 기본 필드 `linear_rules`가 추가됐으므로 이전 버전의 입력과 근거 해시는 현행 계약의 전체 기본값을 포함해 다시 정규화해야 한다. 근거 해시를 자동으로 수정하지 않는다.

검증: 원소·합계·선형·허용차 및 Python/JSON 교환 관련 38개 사례(`artifacts/validation/chemical_analysis_linear_rules.xml`). 조성 조건의 일치는 상 안정성·탄화물 분포·내식성·규격 수락의 보증이 아니다.
