# 침식·마모·마찰 계산의 대응 범위

기존 지원에는 Archard 마모, 보정된 손실률의 구간 적분, 침식과 부식의 상승작용 분해, 분할된 관측을 이용한 멱법칙 보정, 캐비테이션 압력 여유 및 단상 원관의 정상 유동 계산이 있다. 공급된 관측·계수에 대한 연산과 입자 궤적·재료 손실 기구의 직접 예측을 구분해야 한다.

다음 계산의 전용 API를 추가했다.

- `flow.homogeneous_no_slip_mixture_density`: 무슬립 조건에서 상별 질량유량과 밀도를 결합한 혼합밀도. 실제 상분율이나 슬립을 예측하는 기능은 아니다.
- `flow.declared_inverse_sqrt_density_velocity`: 사용자가 SI 단위로 선언한 계수와 밀도의 역제곱근을 이용하는 속도 지표. 표준 계수나 허용 속도를 자동 부여하지 않는다.
- `degradation.device_pressure_drop_cavitation_index`: 입구 절대압과 증기압의 차이를 장치의 양의 압력 강하로 나눈 캐비테이션 지표. 기존 동압 기준 캐비테이션 수와 분모가 다르다.

## 입력과 결과

세 요청은 `CorrelationBasis`로 전체 입력의 해시, 근거·개정·권한 및 단위·적용성 검토를 연결한다. Python에서는 기본 레지스트리의 `run`, JSON에서는 `run_json`을 사용한다. 계산 완료와 승인 여부는 구분한다.

`HomogeneousNoSlipMixtureDensity`는 물리 범위·조건 식별자와 `NoSlipPhaseFlow` 목록을 받는다. 각 상에는 고유 식별자, 비음의 질량유량(kg/s), 양의 밀도(kg/m³)가 필요하다. 총 질량유량은 양수여야 한다. 밀도는 `sum(mass_flow) / sum(mass_flow / density)`로 계산하며, 유량이 0인 상도 기록에 남긴다. 비율을 유리수로 구성해 큰 유량 합계가 넘쳐도 표현 가능한 밀도를 보존한다. 출력 유량의 `null`은 수치 범위 이탈을 뜻하며 0으로 대체하지 않는다.

`DeclaredInverseSqrtDensityVelocity`는 물리 범위, 계수 근거, 비음의 `coefficient_SI`, 정확한 단위 표기 `m/s*sqrt(kg/m^3)` 및 양의 혼합밀도를 받는다. `velocity_descriptor_m_s = coefficient_SI / sqrt(mixture_density_kg_m3)`를 반환한다. 관용 단위 계수를 SI 계수로 간주하지 않는다. 양의 결과가 언더플로로 0이 되거나 결과가 넘치면 보류한다. 실제 계수가 0이면 결과도 0이다.

`DevicePressureDropCavitationIndex`는 장치·조건·입출구 압력 위치·증기압 근거 식별자와 양의 입구 절대압·출구 절대압·증기압(Pa)을 받는다. `(inlet - vapor) / (inlet - outlet)`를 계산한다. 장치 압력 강하가 0 이하이면 `out_of_scope`이며 압력 강하와 증기압 여유는 남긴다. 증기압 여유가 음수여도 부호를 보존한다. 발현 문턱이나 장치 회복계수는 제공하지 않는다.

이 입구압 기준 정의는 [BERMAD 제조사 기술자료의 대안 지표 설명](https://www.bermad.com/app/uploads/WW_700-SIGMA_Engineering_English_6-2020_v22B.pdf)으로 독립 확인했다. 출구압을 분자에 사용하는 다른 정의와는 1만큼 차이가 나므로 이름만으로 결과를 교환하지 않는다. 제조사 문장·한계값·도표는 포함하지 않았다.

Darcy와 Fanning 마찰계수는 동일한 값이 아니다. 벽 전단응력 연결 전에 계수 정의와 압력 강하 관계를 일치시켜야 한다. 기존 단상 원관 API의 Colebrook 해석은 다상 유동이나 입자 충돌 해석을 제공하지 않는다. 밀도와 속도 제곱의 곱은 그 자체로 마모량·침식률이 아니며, 산소 배관의 발화 안전성이나 캐비테이션 손상을 판정하지 않는다.

규격 목차의 항목명은 계산법 정의와 구분한다. 참조 규격에 이름이 있다는 이유로 해당 물리 해석을 구현 완료로 보지 않으며, 실제 방법·조건·판본·사용 권한을 연결하는 과제를 유지한다.

## 검증

자체 작성한 질량·체적 수지, 단일 유동상과 유량 0의 상, 큰 합계의 밀도 보존, 중복 상·영 총유량 거부, 속도 배율·단위·수치 범위, 캐비테이션 지표의 양·영·음 부호, 압력 강하 범위, 입력 해시 변경과 세 API의 Python/JSON 일치를 확인했다. 관련 21개 테스트가 통과했다. 실험적 침식·캐비테이션 손상 검증이나 공정 허용 기준의 검증 실적은 아니다.
