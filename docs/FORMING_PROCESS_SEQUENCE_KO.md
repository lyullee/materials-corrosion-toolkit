# 다단계 성형 공정 조건 API

`fabrication.forming_process_sequence`은 재료·상태가 일치하는 사용자 계획 하나와 공정 이력을 비교한다. `FormingProcessSequence`를 `matintegrity.models.forming_qualification`에서 가져와 기본 레지스트리의 Python 또는 JSON API로 실행한다. 실행 자산·위치와 요청 자산·위치가 일치해야 한다.

계획에는 공정 횟수 범위, 전체 및 마지막 공정의 온도 범위, 단일·누적 공정 시간, 필요한 경우 공정 사이 냉각 기준을 넣는다. 공정별 시작·종료 시간, 관측 온도 범위와 종료 온도를 넣으며 모든 기록은 하나의 명시적 시계를 사용한다. 시간은 s, 온도는 K다. 작업 시간의 합은 비작업 냉각·대기 시간을 포함하지 않는다. 온도 범위는 해당 성형 작업 구간을 뜻하며 가열 전 과정을 자동 포함하지 않는다.

중간 냉각이 요구되면 앞 공정 종료 이후, 다음 공정 시작 이전에 기준보다 낮은 관측점이 있어야 한다. 양 끝 시각의 관측이나 기준과 같은 온도는 증거로 세지 않는다. 관측점이 없거나 모두 기준 이상이면 `needs_data`다. 샘플 사이를 보간하거나 관측되지 않은 온도를 추정하지 않는다. 이 방식은 구간 안에서 낮은 온도가 관측됐다는 확인이며 연속 냉각 이력이나 냉각률 검증은 아니다.

처리 면제 후보는 사용자가 제공한 분기들의 논리합이다. 각 분기는 마지막 공정 종료 온도의 하한과 최종 단면 감소율의 상한을 함께 비교한다. 온도 하한의 등호 포함 여부를 명시한다. 최종 단면 감소율은 공정별 감소율을 더하지 않고, 원래 상태와 최종 상태의 단면적에서 별도로 계산·검토해 넣는다. `fabrication.forming_area_reduction` 결과를 사용할 수 있다. 감소율이 없는 요청은 면제 분기를 평가할 수 없으므로 `needs_data`다.

결과는 검토된 계획 해시, 범위를 벗어난 조건, 공정 사이 냉각 증거 ID와 면제 후보 분기 ID를 보존한다. 계산 가능한 경우 `waiver_eligible_under_selected_plan` 또는 `treatment_required_under_selected_plan`을 반환한다. 공정 범위를 벗어나거나 증거가 빠지면 요구 결과는 `undetermined`이고 후보 분기를 비운다. 후보 일치는 실제 열처리 생략 승인, 물성 보장, 규격 적합 판정이 아니다. 면제 분기가 없는 계획은 처리가 필요하다는 사용자 계획으로 해석한다.

이 API와 기존 `fabrication.forming_qualification`은 보완 관계다. 전자는 순서·중간 냉각·조건 분기를, 후자는 선언된 성형 지표·열 구간·시험 증거를 비교한다. 순서 API 결과가 기존 시험 증거나 후열처리 기록을 자동 삭제하거나 대체하지 않는다. 재료별 제한·권한·근거는 호출자가 제공하며 내장된 규격 상수는 없다.

검증은 다단계 정상 경로, 냉각 시각·온도의 경계, 면제 온도의 등호 정책, 단면 감소율 누락·초과, 횟수·시간·마지막 온도 초과, 중복·겹친 기록 거부, 재료·문맥 불일치 및 Python/JSON 동일성으로 구성한다.
