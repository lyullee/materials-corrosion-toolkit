# 열전도도 기반 예열 상관식

`welding.conductivity_preheat_correlation`는 사용자가 보정한 역열전도도 형태의 온도 상관식을 계산한다. 계산값은 `고상선 온도 - 계수 / 열전도도`다. 고상선은 K, 열전도도는 W/(m·K), 계수는 W/m로 지정한다. 계수를 실제 용접 입열이나 열유속으로 자동 해석하지 않는다.

필수 입력은 재료 상태·상관식 식별자, 고상선 온도, 열전도도와 그 기준 온도, 양의 사용자 계수, 고상선·열전도도의 적용 범위다. 열전도도는 해당 상태·온도·방향에 적합한 단일 유효값으로 사용자가 선정해야 한다. 요청 전체를 `CorrelationBasis`의 해시·사용 권한·적용성·단위 근거에 연결한다. 특정 합금의 계수·열전도도·예열 추천표는 제공하지 않는다.

두 물성이 적용 범위를 벗어나면 외삽하지 않는다. 비율과 온도 차는 정확 유리수로 결합한 뒤 출력하며, 결과가 양의 절대온도가 아니거나 필수 비영 출력이 표현 불가능하면 `out_of_scope`다. 성공 시 `temperature_offset_K`와 `correlation_preheat_temperature_K`를 반환한다. 후자는 사용자 경험식의 산술 결과이며 승인된 예열 지시가 아니다.

계산값이 주변 온도보다 낮아도 주변 온도로 올리거나 냉각을 지시하지 않는다. 별도 절차에서 주변 온도·상한 온도·온도 분포·치수·입열·용가재·구속·표면 상태를 검토해야 한다. 이 상관식으로 균열 확률·기공·용융·용접성·규격 수락을 정하지 않는다. 더 상세한 열전달·응력 모델을 대체하거나 제조사의 절차 적합성을 입증하지 않는다.

수치 확인에는 임의로 작성한 계수와 물성을 사용했다. 기존 온도 간격별 속도 배수 회귀를 포함한 19개 검사는 SI 산술·적용 범위·실행 계약을 확인하며 실제 용접 실험의 검증을 대신하지 않는다.
