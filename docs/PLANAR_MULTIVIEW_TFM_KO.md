# 평면 경계의 굴절·반사 다중 뷰 TFM

## 지원 경로와 API

`inspection.planar_multiview_fmc_tfm`은 `PlanarMultiviewFmcTfm`을 받는다. 기존 FMC 입력의 실물·출처·시계·좌표·원자료/샘플 해시와 완전한 송수신 쌍을 그대로 보존한다. 여기에 상부 매질의 상태·종파 속도 근거, 명시된 `interface_z_m` 평면의 근거, 뷰 목록을 제공한다.

탐촉자 요소는 경계 위쪽(`z < interface_z`), 영상점은 재료 내부(`z > interface_z`)에 있어야 한다. 상부 매질은 종파, 재료 내부의 각 경로는 사용자가 정한 종파 또는 전단파 속도를 사용한다. 전단파를 쓰면 양의 속도와 그 근거가 필요하고, 현재 등방성 모델에서는 전단파 속도가 종파보다 작아야 한다.

`PlanarTfmView`는 고유 `view_id`, 송신·수신의 재료 모드와 각각의 뒷면 반사 여부를 명시한다. 같은 프레임에서 LL·LS·SL·SS 시간 경로와 송신/수신 각각의 직접·반사 경로를 요청할 수 있다. 이것은 여러 독립 시편이나 관측을 생성한 것이 아니라 동일한 RF 프레임의 지연 경로별 영상이다.

반사 뷰에는 `backwall_z_m`을 제공하며 모든 영상점보다 깊은 평행 평면이어야 한다. 현재는 각 경로에서 한 번의 같은 모드 정반사를 지원한다. 반사 지점에서의 모드 변환·진폭·편광은 계산하지 않는다.

## 경로 계산

요소와 영상점의 수평 거리 `rho`를 상부 경로의 수평 거리 `a`, 하부 경로의 수평 거리 `rho-a`로 나눈다. 양쪽 깊이를 `h1`, `h2`, 속도를 `c1`, `c2`라 하면 전파 시간은 `hypot(h1,a)/c1 + hypot(h2,rho-a)/c2`다. 이 시간을 최소화하는 분할을 괄호 이분법으로 찾는다.

정지 조건은 `sin(theta1)/c1 = sin(theta2)/c2`다. 계산에서는 속도를 큰 속도로 정규화한 잔차를 사용한다. `ray_fraction_tolerance`는 수평 분할 비율의 괄호 폭, `maximum_normalized_snell_residual`은 정규화한 Snell 잔차의 한계이며, `maximum_ray_iterations`가 반복 예산이다. 정상 입사에서는 깊이/속도의 합을 직접 계산한다. 잔차 한계나 반복 예산을 만족하지 못하면 미수렴 경로로 영상을 만들지 않는다.

같은 모드의 평면 뒷면 반사는 영상점을 뒷면 건너로 반사시킨 가상점을 이용한다. 송신·수신 경로의 반사 여부는 독립적이다. 같은 모드·반사 조합의 전파 시간은 여러 뷰에서 한 번 계산해 재사용한다. 이후 부호 있는 RF의 보간·합산은 직접 경로 API와 같은 공통 커널을 사용한다.

경로·뷰를 분리하는 방식과 Fermat 경로의 사용은 [arim의 경로·뷰 설명](https://ndtatbristol.github.io/arim/user/core/path.html) 및 [광선 추적 설명](https://ndtatbristol.github.io/arim/user/core/ray_tracing.html)으로 독립 검토했다. 이 API는 평행 평면에 한정한 별도 구현이다. arim은 의존성에 추가하지 않았다.

## 결과와 보류 조건

`views`에 입력 순서대로 뷰 식별자·모드·반사 여부·영상이 반환된다. `ray_summaries`는 각 모드/반사 조합의 전파 시간 범위·최대 반복 횟수·괄호 폭·정규화 잔차를 제공한다. 실물·출처·시계·좌표·샘플 해시의 연결도 보존한다.

계산 예산은 모든 뷰의 영상점×trace 수의 합에 적용한다. 어느 한 경로나 뷰라도 시계 지원 범위·수치 범위를 벗어나면 전체 뷰 결과를 보류한다. 먼저 계산된 뷰만 성공 결과로 내보내지 않으며 진폭을 영 채움·끝값 고정으로 보완하지 않는다.

이 결과는 무가중 기하학적 시간 집속이다. 실제 종파/전단파 변환의 전달 계수, 편광·요소 지향성·에너지, 감쇠·음향 임피던스·결함 산란은 예측하지 않는다. 곡면 경계·여러 번의 반사·모드가 바뀌는 반사·비등방성·탐지/크기 평가·POD·검사 자격은 별도 대응이 남아 있다. 큰 FMC 프레임의 바이너리/청크 입출력과 가속 백엔드도 아직 미완료다.

## 검증 기록

기존의 직접 경로 17개와 추가 경로/뷰 16개를 포함한 33개 테스트 및 정적 검사가 통과했다. 자체 작성한 3–4–5 굴절 경로의 교점·시간·Snell 잔차, 정상 입사, 같은 속도의 직선 경로 환원, 송수신별 반사 지연, LL/LS/SL/SS 지연, 전체 뷰 예산·시계 범위 이탈, 반공간/뒷면 조건·미수렴, 기존 직접 경로 평가기의 다른 전파 계약 거부와 Python/JSON 교환을 확인했다. 새로운 실험 검증 33개를 수행한 의미는 아니며 arim과의 수치 교차 검증도 수행하지 않았다.
