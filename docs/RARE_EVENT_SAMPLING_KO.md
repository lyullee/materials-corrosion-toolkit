# 희귀사건 중요도 샘플링

## 목적과 범위

`reliability.gaussian_mean_shift_importance_sampling`은 표준정규 잠재공간에서 평균만 이동한
제안분포로 생성한 표본과 외부 결정론 평가자가 계산한 사건 지시값을 결합한다. 부식·균열·파열,
FTA 상위사건 또는 다른 모듈의 한계상태를 같은 계산 계약에 연결할 수 있다. 이 모듈은 물리모델,
확률분포 적합기, 제안분포 최적화기 또는 결과모형을 대신하지 않는다.

목표분포는 독립 표준정규 잠재벡터 `Z ~ N(0, I)`이고 제안분포는
`Q = N(mu, I)`다. 제안표본 `z_i`의 정확한 목표/제안 우도비는 다음과 같다.

```text
log w_i = -mu dot z_i + 0.5 * ||mu||^2
P_hat = (1/n) * sum_i w_i I_i
```

`I_i`는 선언한 물리 범위·기간·생존조건 안의 최초 사건이면 1, 아니면 0이다. 계산기는 이
비정규화 산술평균을 주 추정값으로 사용한다. 가중치를 자르거나 평균 1로 강제하지 않는다.
자기정규화 값은 유한표본 진단으로만 별도 보고한다.

## 입력 계약

다음 정체성을 반드시 함께 보존한다.

- 자산, 위치, 물리 범위, 시간 기준, 기간 시작·종료와 생존조건
- 사건 ID·정의와 `conditional_first_failure_in_period` 확률 의미
- 잠재변수 ID 순서, 제안 평균이동 벡터, 고유 표본 ID와 표본 행
- 설계 ID·내용 SHA-256, 난수 생성기 ID·리비전
- 잠재변수에서 물리입력으로 가는 매핑 ID·리비전·설정 SHA-256
- 평가자 ID·리비전·설정 SHA-256과 정렬된 사건 지시값
- 제안분포 생성, 정렬, 매핑, 사건 정의와 결정론 평가자에 대한 명시적 검토 선언

잠재변수의 독립성은 물리변수의 독립성을 뜻하지 않는다. 상관·비정규 주변분포는 별도 검토된
잠재 매핑 안에서 구현해야 한다. 하나의 표본 ID에 대응하는 입력과 지시값을 삭제·재정렬하거나
평가 실패를 `False`로 바꾸면 안 된다.

## 출력과 해석

주요 출력은 기간 조건부 최초사건 확률 추정값, 로그 추정값, 표본 표준오차, 정규근사 구간,
가중치 평균, 전체 가중치 ESS, 사건 가중치 ESS와 최대 정규화 가중치다. 전체 ESS가 낮거나 가중치
평균이 1에서 크게 벗어나면 제안분포가 목표분포의 중요한 영역을 충분히 나타내지 못했을 수 있다.
사건 ESS는 확률 추정에 실제 기여한 사건 표본의 가중치 집중도를 보여준다.

정규근사 구간은 Monte Carlo 반복에 따른 수치 불확실성만 다룬다. 다음은 포함하지 않는다.

- 물리 입력분포와 상관구조의 추정 불확실성
- 잠재 매핑과 한계상태의 모델형식 오차
- 부식·균열·하중·검사 자료의 측정 및 표본집단 불확실성
- FTA 논리구조·공통원인·시간의존성 또는 결과 크기 불확실성
- 규격 적합성, 허용위험 또는 검사주기 판정

제안표본에서 사건이 한 번도 나오지 않으면 점추정 0은 보존하지만 정규구간은 만들지 않는다.
이는 위험이 0이라는 증거가 아니다. 유한표본 비편향 추정값이 1을 넘으면 원시 추정값은 보존하되
확률 출력은 비워 제안분포 재설계나 표본 확대가 필요함을 드러낸다. binary64로 양의 값을 표현할
수 없으면 로그 추정값만 사용한다.

## 검증과 재현

```powershell
.venv\Scripts\python.exe scripts\validate_importance_sampling.py
.venv\Scripts\python.exe -m pytest -q tests\test_importance_sampling.py
```

검증은 `Z ~ N(0,1)`에서 `Z > 4`인 작성 합성사건을 사용한다. 정확값
`3.167124183311998e-05`와 `N(4,1)` 제안분포의 32,768개 고정 seed 표본 추정값을 비교한다.
허용조건은 사전에 선언한 추정 표준오차의 6배 이내다. 결과는
`validation/gaussian_mean_shift_importance_sampling.json`에 기록한다. 이는 우도비 산술의
수학 검증이며 물리 고장확률, 최적 제안분포 또는 희귀사건 성능의 독립 검증이 아니다.

## 후속 확장

현재 `reliability.rare_event_sampling`은 부분 구현 상태다. 다음 단계는 외부 평가자와 대용량
설계/평가 batch를 분리하는 스트리밍 계약, 적응형 제안분포, 다중모드 혼합 제안, subset
simulation, 반복 독립 설계 기반 오차 진단과 실제 부식·파괴 한계상태의 보정/보류 검증이다.
이후 FTA·공동사건·동적 신뢰성 모듈에는 동일 자산·범위·기간·생존조건을 확인한 사건만 전달한다.
