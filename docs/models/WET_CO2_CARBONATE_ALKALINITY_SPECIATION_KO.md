# 습윤 CO₂ 탄산 알칼리도 평형 종분포

## 목적과 연결

`integration.wet_co2_carbonate_alkalinity_speciation`은 caller가 제공한 한 시점의 중성 용존 `CO2*` 농도와 총 알칼리도, 조건부 해리상수로 탄산염계 종농도와 pH를 계산한다. 앞선 [`wet_co2_finite_liquid_transfer_history`](WET_CO2_FINITE_LIQUID_TRANSFER_HISTORY_KO.md)가 내보낸 농도 이력의 개별 knot을 선택해 요청에 연결할 수 있다. 자동 시간 연동, 유량 연동, 부식률 계산은 하지 않는다.

USGS의 [탄산 종분포 기술 메모](https://water.usgs.gov/water-resources/memos/memo.php?id=2098)는 pH 및 알칼리도에 대한 탄산계 종분포 산정에서 물과 탄산계 평형 및 수산화물 기여를 고려하는 방법을 설명한다. 이 모듈은 해당 공개 기술 근거를 참고해 질량작용식과 알칼리도 수지를 독립적으로 구성했으며 원문 문장, 표, 그림 또는 계산 예제를 포함하지 않는다.

## 계산식

입력 상수는 활동도 계수가 반영된 **조건부 농도 상수**이며, 이 모듈은 농도 활동도 근사를 사용한다. 기호 `C0`는 caller가 정의한 중성 `CO2*` 농도, `H`는 mol/m³ 단위 수소 농도다.

```text
[HCO3−] = K1 C0 / H
[CO3²−] = K2 [HCO3−] / H
[OH−] = Kw / H
Alk_calc = [HCO3−] + 2[CO3²−] + [OH−] − H
```

사용자가 제공한 pH 범위에서 `Alk_calc − Alk_input = 0`을 이분법으로 푼다. pH는 `−log10([H+] / 1000 mol m⁻³)`로 계산해 mol/L 표준 농도에 대응시킨다. 농도 단위는 mol/m³이고 알칼리도는 mol/m³ charge equivalent다. 조건부 K1·K2·Kw는 요청에 기록한 provider/revision/digest와 용액 조건에 맞는 값을 caller가 제공해야 한다.

## 입력 및 출력

- 온도, 중성 `CO2*`, 총 알칼리도, `K1`, `K2`, `Kw`, 검색 pH 구간
- 조건부 상수 provider 정보, 설정·결과 digest, 상수 레코드 ID 및 Evidence
- 탄산계 종 범위, 상수 convention, 이상 농도 근사와 사용 권한 review flag
- pH, `CO2*`, 중탄산염, 탄산염, 수산화물, 수소 이온 농도 및 알칼리도 잔차

온도는 추적성을 위해 받지만 이 모듈에서 상관식으로 상수를 계산하지 않는다. 플래그와 출처 digest는 물성의 정확성을 자동으로 보증하지 않는다. 입력 pH 범위 안에 근이 없거나 수치 범위를 벗어나면 외삽하지 않고 `out_of_scope`를 돌려준다.

## 제한 및 적용 범위

- 알칼리도에 기여하는 종이 `HCO3−`, `CO3²−`, `OH−`, `H+`뿐이라고 둔다. 암모니아, 인산염, 붕산염, 규산염, 유기산 등이 의미 있게 기여하면 이 계산을 단독 적용하지 않는다.
- 이상 농도 활동도 근사에 맞는 조건부 상수만 허용된다. 고염도 용액에서 무한희석 상수를 그대로 쓰거나 이온쌍·복합체를 무시한 결과를 자동 보정하지 않는다.
- 단일 고정 `CO2*`와 알칼리도 평형 상태다. 기–액 전달, 액상 재고 변화, 비평형 반응속도, 광물 포화/침전은 다루지 않는다.
- 결과는 pH/종분포 입력으로만 사용할 수 있으며 금속 용출, 부식률, 수명 또는 위험도를 의미하지 않는다.

## 재배포와 검증

모듈 코드는 독립 작성했으며 외부 문헌의 표현이나 표·측정값을 복제하지 않았다. 코드·상수 제공자의 별도 라이선스와 재배포 조건은 사용자가 확인해야 한다. 이 구현은 별도 수치 검증과 화학 데이터 검증이 수행되기 전 상태다.
