# 포화 액체의 기화량으로 열유입 계산

`inspection.boil_off_calorimetry`는 포화 액체 욕조에서 빠져나오는 증기의 질량 유량을 잠열 수지와 연결한다. 일정 압력, 포화 상태, 별도 에너지 항의 처리 및 유량 측정 위치를 사용자가 검토해야 계산한다.

액면이 낮아지는 강체 용기는 발생한 증기의 일부가 감소한 액체 체적을 채운다. 따라서 기화 질량 유량은 `배출 유량 / (1 - 증기 밀도 / 액체 밀도)`이며, 총 열유입은 이 값에 기화 엔탈피 차를 곱한다. 포화 액체를 보충해 액면을 유지하는 모드는 이 보정계수가 1이다. 두 모드는 사용자가 명시적으로 선택한다.

입력 물성은 같은 유체·압력에서 얻은 포화 액체/증기 한 쌍이다. 입력 기록 해시는 물성·공급자 버전·revision을 묶으며, 변조된 기록은 거부한다. `matintegrity.thermo.boil_off_saturation_state_from_coolprop(fluid="Nitrogen", pressure_Pa=101325.0)`로 순수 유체의 HEOS 물성을 만들 수 있다. CoolProp는 이 함수를 호출할 때만 불러온다. 혼합물·초임계 상태·상 분리가 없는 상태는 지원하지 않는다.

별도로 알려진 가열량을 빼면 잔여 열유입을 얻는다. 음수 잔여값도 보존한다. 외부에서 데워진 가스의 체적 유량은 그 측정 위치의 기준 상태로 먼저 질량 유량으로 바꿔야 한다. 이 계산으로 진공 누설량, 단열재 손상, 안전한 보관 시간, 방출 장치 용량이나 합격 여부를 추정하지 않는다.

독립 근거: [CERN의 극저온 열·질량 수지 설명, 2.2절](https://www.cryogenicsociety.org/assets/docs/lebrun_intro_to_cryogenics.pdf), [CoolProp 포화 상태 API](https://coolprop.org/coolprop/HighLevelAPI). 설명과 코드는 새로 작성했으며 물성표를 포함하지 않는다.
