# 다중 볼트·가스켓 평행 축방향 평형

## 목적

`fabrication.gasket_multi_bolt_sector_equilibrium`는 사용자가 제공한 볼트별 초기 체결력·축강성·인장 유효면적과 가스켓 구역별 압축력 곡선으로, 공통 축방향 개구를 갖는 다중 볼트 조립체의 knot별 평형을 계산한다. 하나의 등가 스프링으로 전체 조립체를 뭉개지 않고 각 체결점과 가스켓 구역의 불균일성을 유지한다.

이 모델은 모델 제공자가 만든 플랜지 해석이나 누설 시험을 대신하지 않는다. 모든 물성·곡선·치수는 caller가 제공하고 출처를 연결한다.

## 계산 관계

각 입력 시각에서 미지 공통 개구량을 `u`라 둔다. 볼트 `i`의 자유 길이 변화 `ΔLᵇᵢ`를 반영한 장력은

`Fᵇᵢ = max(0, Pᵢ + kᵢ (u − ΔLᵇᵢ))`

이다. `Pᵢ`는 기준 시각의 개별 초기 체결력이고 `kᵢ`와 인장 유효면적은 caller 입력이다. 음의 볼트력은 허용하지 않는다.

가스켓 구역 `j`의 자유 두께 변화 `Δtⱼ`를 포함한 압축량은

`cⱼ = cⱼ,0 + Δtⱼ − u`

이다. `cⱼ ≤ 0`이면 그 구역은 접촉을 잃고 압축 반력이 0이다. `cⱼ > 0`이면 caller가 준 force-compression 점들을 직선 구간으로만 보간한다. 제공 곡선 밖의 압축은 외삽하지 않는다.

평형 잔차는

`R(u) = Σᵢ Fᵇᵢ − Σⱼ Fᵍⱼ − Fₑₓₜ`

이며 caller가 설정한 개구 범위 안에서 유계 이분법으로 `R(u)=0`을 푼다. 볼트와 가스켓 응답이 단조라는 계약 아래 평형은 단조이며, 제공 범위 안에 해가 없거나 잔차 허용오차에 도달하지 못하면 상태를 `out_of_scope`로 돌린다. 출력에는 볼트별 명목 축응력 `Fᵇᵢ/Aᵢ`와 구역별 평균 접촉압력 `Fᵍⱼ/Aⱼ`도 기록한다.

## 입력과 근거

- 각 볼트 ID, 초기 체결력 (N), 축강성 (N/m), 인장 유효면적 (m²), 근거 source ID
- 각 가스켓 구역 ID, 접촉면적 (m²), 초기 압축량, 단조 압축력 곡선과 그 근거 source ID
- 엄격히 증가하는 시간 knot별 외력, 볼트 자유 길이 변화, 가스켓 자유 두께 변화
- 0초 기준 조립 상태: 외력과 자유 변화는 0이어야 하며, 볼트 초기 체결력 합과 가스켓 초기 반력 합이 caller 허용오차 안에서 닫혀야 한다.
- 최소/최대 공통 개구, 힘·변위 허용오차, 이분법 반복 한도
- 균일 축 개구·선형 볼트·압축 전용 가스켓·quasi-static knot 해석·계산권한 검토와 근거 `Evidence`

`specifications()`가 `ModelRegistry`에 등록할 `ModelSpec`을 제공한다. Pydantic 계약 `GasketMultiBoltSectorEquilibrium`을 `ModelRegistry.run` 또는 registry JSON 실행 경로에 전달한다.

## 해석 한계

이 계산은 각 load knot에서 독립적인 정적 평형을 구하며 knot 사이의 하중 경로를 재구성하지 않는다. 플랜지 휨, 구역 간 탄성 결합, 비대칭 접촉, 볼트 굽힘·전단·나사산 응력, creep/relaxation, 히스테리시스, 외부 유한요소 응답, 누설률, 씰 합격, 코드 적합성, 재료 qualification을 산출하지 않는다. 출력된 평균 접촉압력은 local pressure field가 아니다. 명목 볼트 축응력은 나사산 뿌리 또는 국부 응력이 아니다.

평형이 계산됐다는 사실은 실제 체결 상태나 씰 성능을 입증하지 않는다. caller는 하중·면적·강성·곡선의 조건 적합성, 단위·부호, 근거 이용권한과 별도의 실험/solver 검증을 확인해야 한다.
