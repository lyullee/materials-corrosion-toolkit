# 사용자 배관 클래스 확인

`design.piping_class_assessment`는 사용자가 제공한 클래스 정의와 실제 부품 기록을 비교한다. 공개 패키지에 재료 선정표·압력 등급표·규격 한계를 포함하지 않는다.

클래스 ID·개정, 허용 서비스 목록, 물리적 배관 범위, 부품 종류별 허용 재료 상태 ID·최소 부식여유(m)·필수 속성 및 압력–온도 곡선을 입력한다. 필수 속성은 사용자 문자열 키/값으로 정의하므로 열처리, 트림 재료, 제작 방식 등을 추가할 수 있다. 재료 상태 이름은 정확하게 비교하며 별칭이나 재질 동등성을 추정하지 않는다.

압력–온도 곡선은 기존 `PressureTemperatureEnvelope` 계약을 사용한다. 모든 압력은 `gauge_reference_id`로 선언한 같은 게이지 기준의 Pa, 온도는 K다. 사용자가 검토한 구간별 선형 보간만 적용하며 온도 범위 밖에서는 외삽하지 않는다. `rating_label`은 사용자 식별 문자열로 보존하며 숫자를 압력으로 해석하지 않는다.

모든 규칙·부품·설계점을 `CorrelationBasis`의 전체 입력 해시와 이용 허가·단위·적용 검토에 연결한다. 부품 ID는 유일해야 하며 모든 부품은 선언한 물리적 범위에 속해야 한다. 실행 컨텍스트의 asset/location도 입력과 일치해야 한다.

출력의 `declared_class_outcome`은 사용자 정의에 대한 `satisfied`, `not_satisfied`, `unknown` 중 하나다. 필수 부품·재료·부식여유·속성이 빠지면 `needs_data`가 되며 알려진 불일치도 함께 보존한다. 미지원 서비스나 온도 범위는 `out_of_scope`다. 이 결과로 실제 부식 내성, 벽 두께 강도, 용접 적합성, 규격 승인 또는 구매 승인을 확정하지 않는다.
