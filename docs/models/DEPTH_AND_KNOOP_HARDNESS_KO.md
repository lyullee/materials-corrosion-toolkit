# 깊이 기반 경도와 Knoop 기하 계산

`testing.rockwell_depth`는 같은 예비 하중 기준에서 측정한 두 깊이의 차를 사용한다. 호출자가 지정한 척도 상수에 따라 `H = N - (h_final-h_initial)/S`를 계산한다. 척도 이름만으로 하중·압자·상수를 선택하지 않는다. 적용 검토가 없으면 `needs_data`, 깊이가 역전되면 원래 부호를 보존하고 `out_of_scope`를 반환한다.

`testing.knoop`는 힘(N), 긴 대각선(m), 압자의 두 모서리 각도(deg)를 받는다. 이상적인 마름모의 짧은 대각선을 각도 비로 구하고, 투영 면적으로 힘을 나눠 Pa와 관용 HK 값을 계산한다. 입력 각도는 반드시 장축 방향이 더 커야 한다. 짧은 대각선 출력은 기하 계산값이며 측정값이 아니다.

두 API 모두 시험 장비 교정, 유지 시간, 표면 상태, 유효 측정 범위, 곡률 보정, 재료 간 환산 및 합격 판정을 수행하지 않는다. 규격 표와 경도 변환표를 배포하지 않는다.

독립 구현 근거: [NIST Rockwell 측정 안내](https://doi.org/10.6028/NBS.SP.960-5), [NIST Knoop SRM 2828 기하식](https://tsapps.nist.gov/srmext/certificates/2828.pdf). 공개 자료의 식 원리를 사용하고 설명과 코드는 새로 작성했다.
