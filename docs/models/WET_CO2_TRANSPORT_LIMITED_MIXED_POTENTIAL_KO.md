# 습윤 CO₂ 반응물 막수송 제한 혼합전위 모델

## 목적

이 API는 caller가 제공한 탄산계 수용액 경계 농도와 검토된 Butler–Volmer 반응 집합을 결합한다. 각 반응의 순 전류만 계산하는 대신, 전극 반응에서 소비되는 종에 대해 액막 확산 공급 상한을 적용한 뒤 순전류가 0이 되는 전위를 찾는다. 계산 대상 종은 경계 레코드에 명시된 종으로 한정한다.

모델 식별자는 `integration.wet_co2_film_transport_limited_mixed_potential`이다. Registry, catalog, public schema, source basis, API 색인 및 implementation-scope 추적에 등록되어 있다. 계산·독립 검증은 아직 하지 않았다.

## 사용 API

모듈: `matintegrity.wet_co2_transport_limited_mixed_potential`

- `WetCo2ReactantFilmRecord`: 종별 확산계수, 막 두께, 최소 계면 농도, 공급자 및 Evidence.
- `WetCo2TransportLimitedMixedPotentialRequest`: 정확한 `CarbonateTransportBoundary`, 그 digest, 반응 집합, 종별 막 입력 및 검토 조건.
- `evaluate_wet_co2_transport_limited_mixed_potential(request)`: 반응물 공급 제한을 포함한 혼합전위 계산.

각 Butler–Volmer 입력은 `matintegrity.electrode_kinetics.ButlerVolmerReaction`을 그대로 사용한다. 반응온도는 경계 온도와 정확히 일치해야 한다. 그 경계는 먼저 고정 fugacity 또는 수소 보정 탄산계 계산 및 caller 검토 파티션을 거쳐 만들어야 한다.

## 계산 방법

반응물 종 `i`의 벌크 농도를 `Cᵢ,b`, 최소 계면 농도를 `Cᵢ,s,min`, 유효 확산계수를 `Dᵢ`, 정지 막 두께를 `δᵢ`라 하면 종당 공급 한계는 다음이다.

`Jᵢ,max = (Dᵢ / δᵢ) (Cᵢ,b − Cᵢ,s,min)`

시험 전위에서 기존 Butler–Volmer API로 각 반응의 양·음 부분전류를 계산한다. 정반응 계수 `νᵢ < 0`인 종은 정방향 양극 부분반응에서 소비되고, `νᵢ > 0`인 종은 역방향 음극 부분반응에서 소비된다. 반응 진행속도 환산은 `j/(nF)`를 사용한다. 같은 종을 소비하는 여러 부분반응의 요구량 합이 막 공급 한계를 넘으면, 해당 소비 분기들을 하나의 공통 비율로 축소한다. 하나의 분기가 여러 제한 종을 소비하는 경우 적용 가능한 비율 중 가장 작은 값을 사용한다. 제한 후 반응 전류의 합에 대해 보장된 전위 구간에서 이분법을 수행한다.

## 입력 계약과 단위

| 입력 | 단위 | 조건 |
|---|---|---|
| 경계 종 농도 | mol/m³ | 출처 경계와 digest 고정 |
| 확산계수 `D` | m²/s | caller 제공, 양수 |
| 막 두께 `δ` | m | caller 제공, 양수 |
| 최소 계면 농도 | mol/m³ | 0 이상, 벌크보다 크지 않음 |
| 전류밀도 | A/m² | caller의 보정된 BV 법칙 |
| 온도 | K | 모든 반응과 경계에서 정확히 동일 |
| 전위 | V | 공통 보정 범위 내에서만 계산 |
| 종 플럭스 | mol/(m²·s) | 전극 면적 기준 |

막 자료의 Evidence `source_id`는 자료 공급자 ID와 동일해야 한다. 공급자 revision, source record ID와 Evidence 전체 digest를 결과에 보존한다. 반응의 보정 digest는 caller 입력이며, 결과에는 반응별로 기록한다. 이 모듈은 인터넷에서 파라미터나 상수를 조회하거나 내장하지 않는다.

## 범위 및 가정

- 평면·정상·선형 액막 모델이다. 확산계수와 막 두께가 반응 중 일정하다고 본다.
- 농도 구배는 벌크 농도와 caller가 지정한 최소 계면 농도로 표현한다.
- 반응 동역학은 caller의 보정된 Butler–Volmer 매개변수에만 의존한다. CO₂ 분압으로 교환전류, 평형전위, 전자수, 반응 방향을 추론하지 않는다.
- 공급 제한은 소비 분기 전류에 비례 축소를 적용하는 제한속도 폐쇄식이다. 종별 농도장, 완전한 Nernst–Planck 방정식 또는 확산-반응 PDE를 풀지 않는다.
- 계산은 하나의 경계와 온도에 대한 점 계산이다. 시간 변화, 경계 사이 보간, 다상 반응, scale 내부 확산, 침전 및 이동 경계를 계산하지 않는다.
- 탄산 경계에 없는 전하 보상 이온·착물은 생성하지 않는다. 전기적 중성, 전체 용액 조성, pH의 반응 피드백은 보장하지 않는다.
- 음극 및 양극의 분기 전류를 개별 제한하므로 결과는 순전류가 아니라 조정된 부분전류도 함께 제공한다.

## 결과 해석과 실패 상태

계산 결과에는 혼합전위, 전류 잔차, 조정된 반응별 양·음 부분전류, 종별 플럭스 및 막 공급 진단이 포함된다. 공통 보정 전위 구간이 없거나 영전류가 그 구간에서 bracket되지 않으면 `out_of_scope`로 종료한다. 검토 플래그가 빠지면 `needs_data`를 반환한다. 이는 실험 검증 또는 재료 적합성 승인 결과가 아니다.

## 출처 및 재사용 경계

이 구현의 구성식은 독립적으로 작성한 Fick형 정상 막 플럭스와 Faraday 전하-물질 환산, 입력으로 받은 기존 Butler–Volmer 반응식을 조합한다. 특정 문서의 문장, 표, 수치 자료는 복사하거나 포함하지 않는다. 코드와 문서의 배포 라이선스는 프로젝트의 별도 LICENSE 선언으로 관리해야 하며, 외부 공급자 데이터는 해당 데이터의 이용허가와 인용조건을 별도로 따라야 한다.
