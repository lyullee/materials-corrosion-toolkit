# 유한 기상 수증기–벽면 lumped 열·응축 연성 이력

## 계산 목적

`integration.wet_co2_lumped_wall_thermal_condensation_history`는 단일 벽 patch의 온도, 기상 수증기 몰수, 액상 물 면적재고를 동시에 적분한다. 이전의 기상막 액막 모델은 벽 포화 fugacity나 벽 온도를 caller가 고정 상태로 제공했다. 여기서는 벽 온도가 바뀔 때 caller 포화 fugacity 표를 다시 조회하고, 응축 잠열과 외부 열유속이 온도를 바꾸는 피드백을 계산한다.

## 방정식

각 interval에서 상수인 gas 조건을 사용해 `p_w = n_w R T_g / V_g`, `f_w = phi_w p_w`를 계산한다. caller가 제공한 온도–포화 fugacity 표를 벽 온도에서 구간 선형 보간해 `f_w,sat(T_w)`를 구한다. 기상막 전달은 `N_w = k_g (f_w − f_w,sat)`이며 양의 값은 기체에서 벽으로 이동함을 뜻한다.

단위면적 액막 재고 변화는 `dm''/dt = N_w M_w`이고 기체 몰수 변화는 `dn_w/dt = −A N_w`이다. 벽 에너지식은 `C'' dT_w/dt = q''_external + h_g(T_g−T_w) + L_v N_w M_w`이다. 이에 따라 응축은 잠열을 벽에 더하고 증발은 잠열을 빼며, 액막 재고가 0이면 추가 증발을 차단한다. 이 연성 ODE는 SciPy DOP853으로 풀이하고 구간 끝에서 물질·에너지 잔차를 기록한다.

## 입력과 계보

요청은 초기 벽 온도, 기상 수증기 몰수, 액막 면적재고, 단위면적 벽 열용량, 온도별 포화 fugacity 표와 Evidence, 정확히 연속된 interval들을 받는다. 각 구간은 기상 온도·체적·fugacity 계수·전달계수·면적·기체측 열전달계수·외부 열유속·잠열·액상 밀도 및 provider digest를 명시한다.

포화표는 온도와 fugacity가 모두 엄격히 증가하는 유한 표여야 한다. 초기 및 계산 중 벽 온도는 표의 닫힌 지원구간 안에 있어야 하며 외삽하지 않는다. 표 출처 ID와 SHA-256 Evidence가 일치해야 한다. SciPy는 선택적 런타임 의존성이다. 사용할 수 없으면 계산 상태를 `needs_data`로 반환한다.

## 적용 경계

벽은 하나의 균일 온도와 일정한 단위면적 열용량으로 나타내며 각 구간 내부에는 gas 온도·체적·외부 열유속·전달계수·잠열이 일정하다. 이상기체 성분 부분압력과 일정 fugacity coefficient를 전제로 하며, 포화표는 호출자가 검토한 자료를 제공해야 한다.

이 API는 관두께 방향 열전도/열응력, 다층 wall, 압력·유속장, 상변화 물성의 시간변화, 벽 표면 염수·MEG 활동도, 액막 배수·방울 성장, 응축과 CO₂ 용해·탄산 평형의 동시 반응, 스케일 성장, 부식률을 풀지 않는다. caller 입력을 사용해 열과 물질수지가 닫힌다고 해서 모델이 물리적으로 검증되거나 부식 수명이 산출되는 것은 아니다.

## 데이터·검증 상태

포화 fugacity, 전달계수, 열용량, 열전달계수, 잠열, 밀도는 전부 caller supplied이며 특정 공정용 값을 내장하지 않는다. 점별 값과 출처 파일은 패키지에 포함하지 않고, API에는 출처 ID/digest/Evidence만 연결한다. 합성 수지 검증, 단위·수렴 검토, 독립 wall-temperature/condensation 실험 검증은 별도의 후속 단계다.
