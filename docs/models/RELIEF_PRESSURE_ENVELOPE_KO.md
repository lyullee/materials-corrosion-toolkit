# 사용자 압력 한계 비교

`design.relief_pressure_envelope`는 사용자 규칙에서 지정한 설정 압력 한계와 순간 최고 압력 한계를 계산한다. 모든 압력은 같은 기준점의 게이지 압력(Pa)이어야 하며 `gauge_reference_id`로 기준점을 식별한다. 절대압을 그대로 넣으면 안 된다.

설정 압력 한계는 장치가 보호하는 설비의 허용 게이지 압력에 사용자 배수를 곱한다. 최고 압력 한계는 허용 게이지 압력에 추가 여유를 더한다. 추가 여유는 사용자가 지정한 비율 여유와 절대 여유를 `larger_of`, `smaller_of`, `sum` 중 하나로 결합한다. 계수·결합 방식·적용 시나리오에 기본 규격값을 제공하지 않는다.

입력 전체를 `CorrelationBasis`의 해시와 허가·적용 검토에 연결한다. 두 압력 여유와 선언된 한계 내/초과 결과를 출력한다. 이는 제공된 규칙에 대한 비교이며 장치 용량, 유체 방출량, 배압, 설치 적합성 및 법규 합격을 평가하지 않는다. 규격 표를 포함하지 않는다.
