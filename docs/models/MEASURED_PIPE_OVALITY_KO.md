# 측정 지름으로 계산하는 관 타원도

`fabrication.measured_pipe_ovality`는 동일 단면에서 측정한 최대·최소 지름의 차이를 명시한 기준 지름으로 나눈다. 입력 길이는 m이며 결과에는 지름 차이, 사용한 기준 지름, 타원도 분율·백분율과 분모의 의미가 포함된다.

`reference_basis="nominal"`이면 `nominal_diameter_m`를 반드시 제공한다. `reference_basis="mean_measured"`이면 최대·최소 측정 지름의 산술평균을 분모로 사용하고 공칭지름 입력은 허용하지 않는다. 두 정의의 숫자는 일반적으로 다르므로 데이터 교환 시 `reference_basis`를 보존해야 한다.

양수 지름이 필요하며 최대 지름이 최소 지름보다 작으면 입력을 거부한다. 완전한 원형 단면은 0을 반환한다. 허용 공차·검사 비율·표본 확대·후속 열처리 또는 적합성 판정은 사용자 규칙과 별도 절차로 평가한다.

`examples/engineering_correlations.py`에 합성 사용 예가 있다. Python과 JSON registry 경로에서 같은 계산값·단위·입력 해시가 유지되는 것을 검증했다. 수학 검증에는 분모에 따른 차이와 잘못된 측정 순서·누락된 공칭지름의 거부가 포함된다. 측정 장비·절차·단면 등록의 타당성은 이 계산으로 입증하지 않는다.
