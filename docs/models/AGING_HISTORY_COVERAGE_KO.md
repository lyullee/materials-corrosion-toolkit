# 금속 열화의 등가 노출 이력 범위

`degradation.metallurgical_aging_exposure`는 사용자에게서 받은 시간 구간별 등가 시간 배율을 적분한다. 배율은 해당 재료·열화 기구·온도·공급자에 대해 따로 확보해야 하며 패키지가 보편적인 취화 법칙을 선택하지 않는다.

1.0.1에서는 첫 구간의 시작부터 마지막 구간의 끝까지 관측 공백을 확인한다. `history_span_s`, `uncovered_duration_s`, `uncovered_intervals_s`를 출력하고 내부 공백이 있으면 `needs_data`를 반환한다. 누락 구간을 노출 0으로 가정하거나 `within_declared_equivalent_exposure`를 출력하지 않는다. 검토 플래그만으로 관측 공백을 덮을 수 없다.

관측 공백이 없다면 기존 배율 가중 시간 합과 선언된 한계에 대한 여유를 계산한다. 동일한 시간 원점 이동은 결과를 바꾸지 않는다. 입력 구간 밖의 설비 이력은 추정하지 않는다. 별도 노출 캠페인은 서로 분리해 계산한다.

출력에는 clock, 재료 상태, 열화 기구 식별자도 보존한다. 등가 시간은 상 분율·인성·강도·손상 확률이나 합격 판정이 아니다. 수정 재현과 회귀 사례는 `tests/test_metallurgical_aging.py`에 있다. 입력 필드 변경은 없다.

## 1.0.2 수치 범위 보완

구간 길이·등가 기여량·총량·한계 차이를 입력 수치의 정확 유리수로 계산한다. 비영 기여량이 반환 범위보다 작거나 총량이 너무 크면 `out_of_scope`이며, 부분 기여량이나 통과 여부를 반환하지 않는다. 0인 검토된 배율은 정확한 0이다. 관련 10개 사례로 기존 누락 구간·적용 범위·식별자 동작과 경계 수치를 확인했다(`artifacts/validation/metallurgical_aging_numeric_range.xml`). 등가 노출은 상 분율·인성·경도·회복·수명의 예측값이 아니다.
