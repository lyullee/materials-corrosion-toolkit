# 사용자 조성 지표 계산

`materials.steel_composition_index`는 J·X·RCS·K 중 하나를 선택하는 별도 호출 경로다. J는 `(Mn+Si)*(P+Sn)`에 사용자 `product_scale`을 적용한다. X는 P/Sb/Sn/As, RCS는 Cr/Mo/V, K는 Pb/Bi/Sb의 가중 합을 계산한다. 모든 경로는 사용자 `normalization`으로 나누고 `constant_offset`을 더한다. 계수 키는 해당 구조와 정확하게 일치해야 하며 사용하지 않는 계수는 거부한다. 계수·정규화·원소 분석값에 기본값을 넣지 않으므로 허가된 적용 식의 값을 명시해야 한다. 아래의 범용 다항식 API와 동일하게 질량 기준·이용 허가·전체 입력 해시를 검토한다.

`materials.composition_index_recipe`는 조성 값의 곱과 거듭제곱으로 이루어진 항을 합산한다. `constant_offset + Σ(coefficient × Π(composition[element] ** power))` 형태이며 임의 Python 식이나 문자열 수식을 실행하지 않는다. 가중 합은 인자가 하나인 항, 두 합의 곱은 전개한 여러 항으로 입력할 수 있다.

조성 입력과 식이 요구하는 조성 기준은 각각 `input_mass_basis`, `recipe_mass_basis`로 지정한다. `mass_fraction`, `mass_percent`, `mass_ppm` 사이의 질량 기준 변환만 수행한다. 몰 분율·체적 농도·부분압으로의 변환은 하지 않는다. 누락된 원소를 0으로 채우거나 잔여분을 철로 채우지 않는다. 사용한 모든 원소는 명시적인 분석값이 있어야 한다.

항 ID는 유일해야 하며, 한 항의 원소는 한 번만 쓰고 필요한 정수 거듭제곱을 명시한다. 값의 합이 선언된 조성 기준의 최대값을 넘으면 거부한다. 계산 중 overflow 또는 조성 변환 underflow는 `out_of_scope`이며 값을 잘라내지 않는다. 음수 지표도 그대로 보존한다.

사용자는 계수·항·조성 기준·지표 ID·출력 단위 해석 전체를 `CorrelationBasis`의 해시와 이용 허가·적용 검토에 연결한다. 출력의 `output_unit`은 사용자 선언이며 registry의 단위 표시는 이를 `caller_declared`로 명시한다. 다른 모듈에 연결할 때 이 단위를 먼저 검토해야 한다.

J/X 계열 조성 지표 및 재열 균열 관련 선형 조성 지표의 수치 계산을 사용자 식으로 표현할 수 있다. 패키지는 이들 경험 계수나 합격 한계를 제공하지 않는다. 지표만으로 취화, 균열, 천이 온도, 잔여 수명 또는 확률을 예측하지 않는다.

실행 예제는 `examples/composition_index_recipe.py`다. 예제의 원소 이름·계수는 합성 자료이며 실제 합금이나 규격 식이 아니다. 조성 지표와 실제 물성 평가의 구분은 [공개 연구](https://doi.org/10.3390/ma10060671)에서 확인할 수 있다. 설명과 계산 코드는 독립적으로 작성했다.

## 0.1.1 수치 범위 보완

질량 기준 변환·거듭제곱·교차항·계수·상수 합산을 입력 부동소수점 값의 정확 유리수로 계산한 뒤 반환값으로 변환한다. 작은 인자의 거듭제곱이 중간에 0이 되더라도 큰 계수와 결합한 최종 항이 표현 가능하면 보존한다. 비영 변환 조성·항·최종 지수가 표현 불가능하면 `out_of_scope`이며, 정확히 0인 계수는 그대로 0이다. 하한 적용식도 같은 계산 함수를 사용하며 원래 조성을 재정규화하지 않는다. 경계 사례와 기존 교환·회귀 합계 32개를 확인했다(`artifacts/validation/composition_recipe_numeric_range.xml`). 이 확인은 조성 지수 산술에 관한 것이며 페라이트 예측·균열·재료 수락 검증이 아니다.
