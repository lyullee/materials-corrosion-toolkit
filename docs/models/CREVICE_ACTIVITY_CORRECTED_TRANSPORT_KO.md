# 간극 비이상 활동도 보정 수송 이력

## 목적

`transport.crevice_activity_corrected_nernst_planck_1d`는 고정된 1차원 간극 격자에서 caller 제공 농도·활동도계수 자료를 사용하는 유한체적 이온 수송 계산기다. 종별 확산 플럭스에는 농도 구배와 `ln(gamma)` 구배를 모두 포함하고, 각 개방 면에서 대류 전류까지 합한 총 전류가 0이 되도록 무차원 전위 기울기를 대수적으로 정한다. 유한 셀 재고를 시간 적분하고 전하·전류·재고 잔차를 반환한다.

## 계산 관계

각 면에서

\[
J_i=-D_i\left(\nabla c_i+\bar c_i\nabla\ln\gamma_i+z_i\bar c_i\nabla\psi\right)
+v c_{i,upwind}.
\]

\(\psi=F\phi/(RT)\)는 무차원 전위다. 0 전류 조건으로 \(\nabla\psi\)를 풀며, 각 셀의 농도 변화율은 좌우 면 플럭스 차이의 유한체적 발산으로 계산한다. 구동되는 경계는 입구(mouth)이며, 끝단(blind tip)은 무플럭스다. 출력 시각 사이의 농도 및 입구 경계는 선형, `ln(gamma)`는 로그 공간 선형 보간을 쓴다.

## 입력과 provenance

각 종에는 전하수, 고정 확산계수, 초기 셀 농도, 시간·셀별 양의 활동도계수, 입구 활동도계수 이력을 제공한다. 모든 시간 knot에는 종별 electroneutral 입구 농도 및 각 면 속도도 필요하다. 활동도 계수 provider ID/revision 및 digest Evidence, 라이선스/허가 Evidence와 사용자의 검토 flag를 보존한다. 모델은 활동도 파라미터 또는 원자료를 포함하거나 감마 값을 계산하지 않는다.

## 경계 및 제한

- 단일 액상, 고정 형상, 반응이 없는 간극 수송만 계산한다. 이동 경계·유동장 계산·복수 상 선택은 하지 않는다.
- 입력된 단일 이온 활동도 표준상태, 표준농도, 활동도계수 상호 일관성은 caller가 검토해야 한다. 이 API는 thermodynamic factor나 다성분 Onsager 교차계수를 만들지 않는다.
- 활동도 공간 구배는 인접 cell 값의 로그 차분으로, 시간 보간은 로그값 선형 보간으로 계산한다. 경계 밖 시간 외삽은 하지 않는다.
- 영전류 조건은 계산영역 내부의 국부 폐쇄이며 외부 전극·회로가 강제하는 전류나 전하 축적 모델이 아니다.
- 질량작용 speciation, 산염기/착물 반응, 상평형, 침전·용해, 표면 반응, 금속 손실, 부식 속도, 수명 또는 위험/합격 판정은 추론하지 않는다.
- solver가 음의 농도 또는 미수렴 상태를 만들면 결과를 `needs_data`로 닫는다. 질량수지·전류 잔차는 이산 수치 진단이며 물리 검증이나 qualification을 뜻하지 않는다.

## 출처와 방법의 성격

원자료, 확산계수, 활동도계수와 경계 이력은 caller가 권리 및 적용 범위를 확인해 제공한다. 계산 방법은 공개 입력을 바탕으로 한 독립 소프트웨어 관계식이며 특정 데이터셋, 상용 전해질 데이터베이스 또는 문헌 문장을 포함하지 않는다. 코드/의미 설명은 프로젝트의 재사용 가능한 method note로 작성했다.

## 검증 상태

API 및 계약만 추가했다. 테스트, 모델 실행, 물리 검증, HPC 계산, package build는 수행하지 않았다. 후속 검증에는 이상용액(γ=1) 극한에서 기존 dilute solver와 비교, 감마 구배 방향 반전, 양/음 유속, 농도 영/음 경계 및 inventory closure, 영전류 잔차, exact knot/order mismatch를 포함해야 한다.
