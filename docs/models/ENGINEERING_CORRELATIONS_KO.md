# 사용자 계수 기반 공학 상관식 API

아래 API는 계수 표를 내장하지 않는다. 사용자가 계수·적용성·이용 근거를 입력하면 산술 계산을 수행한다. 동일한 모델을 사용자 파라미터로 재설정할 수 있으며 규격 승인이나 재료/절차 자격화를 자동 판단하지 않는다.

| API | 계산과 입력 기준 |
|---|---|
| `piping.displacement_stress_allowance` | 저온/고온 허용응력의 사용자 가중합에 주기 계수를 적용한다. `base`와 지속하중 응력을 차감하는 `with_sustained_stress`를 명시적으로 선택한다. 응력 단위는 Pa다. |
| `welding.cooling_time_correlation` | 3D는 열입력 1차·온도차 역수, 2D는 열입력/두께의 제곱·온도차 역수 제곱으로 계산한다. 열입력은 J/m, 두께는 m, 온도는 K다. 계수는 3D `s*m*K/J`, 2D `s*m^4*K^2/J^2`를 사용한다. |
| `welding.flux_moisture_hydrogen` | 결합수/흡습수 질량분율과 수증기 분압 Pa에 사용자가 제공한 선형 계수를 적용한다. 결과는 지정 기준 온도·압력의 H2 부피이며 `m3/kg deposit`와 `ml/100g deposit`를 구분한다. |
| `inspection.coupling_pressure` | 외경·나사 골 지름·항복강도·사용자 강도 계수에 따른 압력을 계산한다. 길이는 m, 강도와 압력은 Pa다. |
| `inspection.thread_connection_pressure` | 탄성계수·지름·테이퍼·체결 회전수·피치를 사용한다. 피치는 반드시 m/turn으로 변환하며 지름도 m로 입력한다. |
| `welding.carbon_equivalent_recipe` | 원소 질량%와 사용자가 선언한 가중합·원소비·역수 항을 계산한다. 필요할 때만 탄소 함량에 따른 tanh 보정항을 적용한다. 각 항의 계수와 적용 근거는 입력값이다. |

탄소당량 recipe는 기존 `welding.carbon_equivalents`의 IIW·Pcm 고정 계산을 대체하지 않는다. 다른 방법은 `method_id`와 산술 항·원소 분석값을 명시한다. 없는 원소를 0으로 채우거나 0 분석값을 분모로 사용하면 입력 검증이 실패한다. 조성 지표를 예열온도·용접성·균열 확률로 자동 변환하지 않는다. 원소비·역수 항의 계수는 원소 입력이 질량%라는 단위 관례에 맞춰야 한다.

모든 요청에는 `CorrelationBasis`가 필요하다. `basis`를 제외한 요청 전체를 `canonical_digest(request_payload)`로 해시한 뒤 `record_sha256`에 넣는다. 동일한 source ID, 해시 및 license ID를 갖는 Evidence를 제공하고 적용성·단위·계산 사용 권한을 확인한다. 이 해시는 계수와 입력의 동일성을 확인하며 물리적 타당성을 검증하지는 않는다.

냉각식의 계수는 선택한 온도 구간·열전달 차원·재료·용접 조건에 유효해야 한다. 2D/3D를 자동 선택하지 않으며 계수의 온도 의존성은 기준 K에서의 값과 K당 기울기로 입력한다. 출력은 상관식 예측으로, 측정 파형에서 냉각시간을 추출하는 API나 Rosenthal 온도장을 계산하는 API와 별도다. 독립적인 공개 수식 근거: Björk et al. (2023), https://doi.org/10.1007/s40194-023-01483-w. 원문의 문장·그림·계수 표는 배포하지 않는다.

음수 응력 허용범위나 음수 수소 예측은 0으로 보정하지 않고 `out_of_scope`로 반환한다. 잘못된 지름 관계·단위·온도 지원 범위·해시 또는 누락된 적용성 검토는 입력 검증에서 거부한다. 나사 연결부 등급별 계수, 반올림, 규격 판본과 승인 판단은 사용자 규칙으로 별도 관리한다.

수학 검증은 `tests/test_engineering_correlations.py`에 있다. 합성 계수의 기준값, 차원별 열입력 배율, 형상 배율 불변성, 단위 환산 및 계약 거부 사례를 확인하며 실제 재료에 대한 경험식 적합이나 qualification을 뜻하지 않는다.
