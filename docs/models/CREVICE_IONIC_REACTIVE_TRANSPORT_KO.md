# 이온 반응성 틈새 수송 API

## 목적

`integration.crevice_ionic_reactive_transport_1d`는 고정 단면의 1차원 틈새에서 이동성 이온의 희석 Nernst–Planck 수송, 사용자가 지정하는 면 속도 이류, 그리고 균일상 가역 질량작용 반응을 하나의 시간 적분 상태로 함께 계산한다. 전기장 구배는 각 면의 이온 전류가 0이 되도록 국소적으로 닫는다. 수송 모델 공급자 및 반응 속도 입력은 호출자가 근거와 함께 제공한다.

## 입력 구성

- 공간은 길이, 단면적, 셀 수로 정의되는 균일 격자이다. 셀 순서는 틈새 입구에서 막힌 끝 방향이다.
- 각 종에는 고유 ID, 정수 전하수, 양의 확산계수, 셀별 초기 농도 및 원소 조성을 준다. 초기 농도와 입구 농도는 모든 셀과 시간 매듭에서 전기적 중성을 만족해야 한다.
- 시간은 엄격히 증가하는 출력 매듭으로 주며, 입구 농도와 셀 면 축방향 속도는 해당 매듭에 정렬한다. 두 매듭 사이 값은 선형 보간한다. 막힌 끝 면의 속도는 전 시간에 0이어야 한다.
- 각 가역 반응은 양쪽의 종 및 양의 정수 화학양론 계수, 정·역 속도상수 시간 이력, 단위, 매개변수 기록 ID와 SHA-256을 갖는다. 네트워크는 전하 및 원소 수지를 보존해야 한다.
- 검토 완료 플래그와 자료·권리 Evidence를 제출해야 한다. 종과 반응 매개변수에 대한 계수, 단위, 유효 범위는 사용자가 독립적으로 검토한다.

## 계산식 및 수치 처리

종별 면 플럭스는 확산, 전기 이동, 상류 셀 농도를 사용한 이류 성분의 합으로 구성한다. 면 전위 구배는 해당 면의 전하 플럭스 합이 0이 되도록 계산한다. 셀 농도는 플럭스 발산과 순 반응률을 합친 유한체적 수지로 진화하며, 시스템은 SciPy BDF 암시 적분기로 공동 적분된다. 입구 유출입량과 반응 생성/소모량도 누적 상태에 포함하여 종별 유한체적 수지 잔차를 반환한다.

## 출력

`Calculation` 결과에는 각 출력 시점의 종별 셀 농도, 전체 이동 재고, 입구 누적 전달량, 반응 누적 전달량, 셀별 전하 잔차, 면 속도 및 적분 진단값이 들어간다. `needs_data`는 SciPy 부재, 적분 실패, 계산 한도 초과 또는 음의 농도 문제를 나타낸다. `computed`는 입력과 가정에 따른 수치 계산 완료를 뜻할 뿐, 실제 설비 성능이나 부식률의 검증을 뜻하지 않는다.

## 적용 경계

이 API는 입력된 속도장을 계산하는 유동 해석기가 아니다. 기하, 확산계수, 종 목록, 속도장, 입구 이력, 반응망과 속도식은 외부에서 정하고 검토해야 한다. 희석 용액 근사 및 전기적 중성/영전류 폐쇄가 적용 가능한지 확인해야 한다. 활동도 보정, 온도 의존 속도론, pH 추정, 착물 평형, 고체상 생성·용해, 침전, 형상 변화, 벽 반응, 금속 손실, 부식 건전성 판정 및 위험 확률은 범위 밖이다. 특히 계산 결과를 설계 허용치, 수명 또는 위험도로 직접 해석해서는 안 된다.

## 재사용 및 권리 관리

모든 물성치, 속도상수, 운전 이력과 권리 근거는 호출자 제공 자료로 취급한다. 출처별 버전, 라이선스, 식별자와 해시를 기록하고, 코드에는 특정 외부 자료의 표·문장·계수를 내장하지 않는다. 연구 재현 시 입력 계약의 전체 JSON과 반환된 입력 해시를 함께 보존한다.
