# 계산 API 재검토에서 발견한 남은 작업

기준일: 2026-11-01. 아래는 재검토 중 발견한 부분 목록이며 프로젝트 전체의 최종 분모가 아니다.

후속 구현 상태: 아래 산술 기능은 모두 타입 입력과 registry 사양을 갖춘 계산 API로 추가했다. 배관 2형식과 냉각 2차원 등 7항목은 5개 선택형/전용 API로 제공하며 합성 수학 검증 8개가 통과했다. 상세 계약과 단위는 [공학 상관식 안내](models/ENGINEERING_CORRELATIONS_KO.md)에 있다. 아래 표는 공백을 발견했을 당시의 검토 요구를 보존한 기록이다. 전체 기술 범위 검토, 사용자 계수의 물리적 적용성 및 카탈로그 일괄 생성은 별도 잔여 작업이다.

| 계산 기능 | 확인 결과와 다음 작업 |
|---|---|
| 배관 변위응력 허용범위 기본형 | 비교 규칙만으로 산술식을 실행할 수 없다. 사용자 계수와 적용 조건을 명시한 계산 API가 필요하다. |
| 배관 변위응력 허용범위 대체형 | 지속하중 응력을 포함하는 별도 식으로 취급하고 유리한 규칙을 자동 선택하지 않는다. |
| 3D 냉각시간 상관식 | 기존 Rosenthal 온도 예측이나 기록 파형의 냉각구간 추출과 동일시하지 않는다. 계수·단위·지원 범위를 확인한다. |
| 2D 냉각시간 상관식 | 판 두께와 식의 지수·단위 배율을 확인한 뒤 구현한다. |
| 플럭스 수분 기반 수소 추정 | 확산 탈수소 계산과 별개인 경험 상관식이다. 사용자 계수와 적용 근거가 필요하다. |
| 커플링 시험압력 | 외경과 나사 골 지름에 대응하는 전용 형상 계약을 확인한다. |
| 나사 연결부 압력저항 | 연결 형상·체결 길이·강도 계수를 명시한다. |
| 기준 비에너지에 따른 질량환산 | `inspection.reference_energy_mass` 구현 및 5개 수학·입력 검증 통과. 사용자 J/kg 기준에서 kg으로 환산하며 폭풍이나 안전거리를 추정하지 않는다. 카탈로그 일괄 생성은 대기 중이다. |

범용 규칙 API는 기존 값의 비교와 판정을 수행한다. 사용자가 독자 모델을 등록할 수 있다는 사실을 위 계산의 내장 구현 완료 근거로 사용하지 않는다. 규격 계수·재료 데이터·절차 적용성의 근거와 산술 처리의 구현 여부를 따로 추적한다.
