# 압력차 계산과 부품 압력 집계의 연결

`matintegrity.models.pressure_limit_binding`은 사용자 압력–두께 관계의 정방향 용량 결과를 공통 압력 기준을 가진 부품 한계로 연결한다. `bind_pressure_relation_component_limit(relation, reference)`의 반환값은 `PressureLimitBinding`이다.

변환식은 `부품 한계 = 계산 압력차 + 외압의 절대압 − 공통 기준의 절대압`이다. 절대압 출력은 공통 기준 절대압이 0이어야 한다. 게이지 출력은 사용자가 동일한 기준 ID와 절대 기준압을 명시한다. 외압을 대기압과 같다고 가정하지 않는다.

`PressureLimitReferenceContext`에 설비·위치·물리 범위·시나리오·좌표계·부품 표고·압력 기준·외압·공통 기준압과 검토·근거를 넣는다. 원래 관계의 설비·위치가 같아야 하고 정방향 계산이 `computed`여야 한다. 역산에 사용한 설계압력은 용량 상한이 아니므로 거부한다.

연결 객체 전체를 보존하고 집계 입력에는 `binding.component_limit`를 넣는다. 집계 실행 전 `verify_pressure_reference_bindings(aggregation, bindings)`를 호출한다. 이 함수는 부품별 일대일 연결, 수량, 물리 범위, 설비·위치, 시나리오, 좌표계, 압력 기준 ID와 공통 절대 기준압을 대조한다. 명시적인 검증 함수를 호출하지 않은 원시 입력의 물리 연결까지 자동으로 검증하지는 않는다.

원래 계산과 변환 문맥을 함께 해시해 변환된 용량의 입력/결과 해시를 만든다. 연결 객체는 역직렬화 시 계산과 변환을 다시 수행하고 일치 여부를 확인한다. 계산값을 바꾸고 해시만 다시 만들어도 원래 입력과 맞지 않으면 거부한다. 해시는 데이터 일관성을 확인하며 공급자 신뢰성이나 전자서명을 대신하지 않는다.

예: 계산 압력차가 64 Pa, 외압 절대압이 100100 Pa, 공통 기준 절대압이 100000 Pa이면 부품의 게이지 압력 한계는 164 Pa다. 같은 위치에서 절대압 기준으로 변환하면 100164 Pa다. 이 예는 자체 작성한 산술 설명이며 실제 설계 조건이 아니다.

부품의 외압이 달라지는 시나리오, 형상 적용성·다른 하중·외압 안정성·하한 압력·규격 적격성은 별도 검토가 필요하다. 이 연결만으로 압력차의 용량 모델이 규격에 적합해지지는 않는다.
