# 재료별 용접·브레이징·피복 접합의 대응

## 오스테나이트계 용접의 추가 경계

용가재 조성 혼합, PREN과 등가 조성 지표, 페라이트 관측은 서로 다른 결과다.
이들을 내식성·균열 저항·고온 강도·저온 인성의 보증으로 바꾸지 않는다.
FN과 상 분율도 자동 환산하지 않는다. 탄화물의 국부 용해·재석출과
국부 열주기 연결, 칼날선 부식 위치·감수성 예측은 미완료 물리 대응이다.
비교 사진이나 용가재 이름으로 실제 부식률·허용 온도를 생성하지 않는다.

`welding.dilution`과 `welding.dilution_with_uncertainty`는 유리수 중간
질량 수지로 혼합 조성을 계산한다. 총질량만 부동소수점 범위를 넘으면
`total_melted_mass_kg`는 `null`이고 지원 가능한 조성과 질량비는 보존한다.
총질량이 필요한 후속 모듈은 `null`을 별도로 처리해야 한다. 비영 질량비나
조성이 0으로 소실되면 계산 범위 밖으로 반환한다. 공분산 전파는 제공된
조성 공분산과 고정 질량 가중치만 사용하며 용융 질량의 불확도는 추정하지 않는다.
이 산술은 원소 손실·편석·계면 분포·상변태·용접 승인 계산이 아니다.

## 주철 보수

흑연 형상과 기지 조직, 실제 용접부·열영향부 상태를 구분한다. 기존 희석·
냉각 관측·보수 순서 계산은 흑연 용해, 탄화물·마르텐사이트 분율, 기공,
피닝의 응력 완화, 열충격 균열 또는 보수 후 강도·가공성을 예측하지 않는다.
결함 제거·청정도·누설 방지와 보수 허용 여부는 별도 근거가 필요하다.
용가재 이름이나 절차 완료만으로 이러한 성능을 인정하지 않는다.

`welding.repair_welding_history`의 모든 단계 위치는 이력의 위치와
정확히 일치해야 한다. 다른 위치의 검사·제거 기록을 같은 보수의 완료
근거로 사용할 수 없다. 여러 위치를 다루면 위치별 이력을 작성한다.
단계의 물리 하위 범위와 상위 보수 범위 식별자는 서로 다른 역할이다.
재료별 상용 용가재표·전형 경도·고정 예열값을 기본 규칙으로 제공하지 않는다.

## 이종재 이음부

`welding.dilution`과 불확도 계산은 공급된 용융 질량의 조성 혼합이다.
이종재 적합성 API는 사용자가 검토한 재료·층·위치·열처리·서비스 근거를
대조한다. 이들로부터 융합 경계 경도, 탄소 이동, 국부 수소 충전이나
갈바닉 가속을 추정하지 않는다. 자유 열팽창 차 역시 구속 응력·변태응력·
크리프 피로 손상의 대체 계산이 아니다. 이러한 물리 응답의 모델 선정과
실제 경계 위치·열주기·보정 데이터 연결은 남은 과제다.

용가재 선택과 검사 범위는 판본·관할·승인 근거를 별도로 받아야 한다.
피복봉과 나선의 등급을 이름만으로 호환 처리하지 않으며 상용 선택표나
고정 서비스 온도를 내장하지 않는다. 최종 가공면과 실제 분석 깊이를 보존한다.

자유 열팽창 적분은 접선 계수의 구간별 선형 적분 중간값을 유리수로
계산해 중간 오버플로와 상쇄 손실을 줄인다. 최종 적분 또는 길이 변화가
표현 불가능하거나 비영 적분이 0으로 소실되면 `out_of_scope`를 반환한다.
이는 입력 물성의 물리적 타당성이나 구속 이음부 응력을 검증하지 않는다.

## 마르텐사이트·페라이트·석출경화계의 추가 대응

재료 등급과 공급 상태, 용가재, 사용 환경 및 승인 권한을 각각 보존한다.
기존 조성 비교·열이력 지표는 마르텐사이트 분율과 변태응력, 수소 유발 균열,
페라이트계 입자 성장 또는 석출물 진화를 예측하지 않는다. 해당 반응의
계산 모델 선정·보정 데이터·용접 열이력 연결은 미완료 과제다.
합금 계열만으로 예열·후열 면제, 균열 방지, 압력 경계 사용 허용이나
용가재의 내식 적합성을 판정하지 않는다. 조성표의 공란을 측정된 0으로
해석하거나 합산 원소 제한을 개별 원소 제한으로 바꾸지 않는다.
재료별 고정 온도·경도 곡선·상용 용가재 선택표는 내장하지 않는다.

| 요구 | 현재 지원 | 남은 계산·근거 대응 |
|---|---|---|
| 저온 니켈강 용접 | 용가재 적합성·충격 관측·냉각 시간 | 실제 공정·자세·열입력별 강도·인성 근거가 필요하다. 합금 이름만으로 예열·후열 면제나 내균열성을 판정하지 않는다. |
| 구리합금 접합 | 사용자 재료·공정·용가재 적합성 비교 | 제품·재료 상태·서비스에 맞는 승인된 선택 근거와 실제 이음부 성능을 연결한다. |
| 지르코늄 용접 | 용가재·이종재 이음부 증거 | 차폐·청정도·침입형 원소·채취 상태를 보존한다. 표면색으로 오염 농도나 연성을 추정하지 않는다. 오염·취화 계산의 대응은 남아 있다. |
| 브레이징 | 접합 주기·관측·생산 캠페인 증거 비교 | 모세관 충전·젖음·반응층·접합강도 계산은 기존 증거 API가 수행하지 않는다. 간극·액상선·고상선·플럭스와 서비스 근거가 필요하다. |
| 오버레이 | 희석·불확도 계산, 국부 층 이력, 피복 관측 | 전류·이동 속도로부터 희석·침착률을 예측하는 모델은 별도다. 화학 분석은 최종 가공면에 대한 실제 채취 깊이·위치를 보존해야 한다. |
| 폭발 피복 접합 | 접합·결함·형상·재료 관측과 승인 범위 비교 | 실제 접합 형성·계면 상태·후속 열처리 응답을 계산하는 모델과 관측의 연결은 별도 검토 대상이다. |

공정별 전형적인 성능, 재료 조합 목록과 과거 시험값을 보편적인 예측식·승인 기준으로 쓰지 않는다. 이번 작업은 요구 분류이며 새 계산·수치 검증 실적을 추가하지 않는다.

## 단조·라이너·듀플렉스의 추가 대응

단조 재료는 방향·실제 위치·변형·열처리 이력과 물성 관측을 연결해야 한다. 공정명으로 무결함·완전 균질·우수한 저온 인성을 보장하지 않는다. 성형의 기하·순서 API는 재결정·입자 성장 및 물성 예측과 다르다.

금속학적 클래드, 기계적으로 조인 라이너, 느슨한 라이닝의 결합 상태와 역할을 구분한다. 열수압 그립·간섭 접촉, HIP 치밀화·확산, 주조 및 계면 형성 계산은 기존 접합 증거 API가 수행하지 않는다. 고정 비용 순위, 완전 치밀화나 시험 면제를 기본값으로 넣지 않는다.

`welding.duplex_phase_balance`의 관측·근거와 실제 상변태·질소 손실·금속간화합물 형성 예측은 구분한다. 열입력·보호/퍼지 가스·시편별 인성과 내식성은 실제 공정 근거로 확인한다. 충격 에너지와 횡팽창은 다른 관측이며 단위가 모호한 근사식으로 자동 환산하지 않는다.
