# 보존·운송·동절기 보호의 구현 경계

| 요구 | 구현·연결 | 남은 근거 또는 작업 |
|---|---|---|
| 저장 노출·검사 이력 | `fabrication.storage_preservation_history` | 노출 시간은 실제 부식 손실량이 아니다. |
| 방청제·포장·갱신 관측 | `fabrication.storage_preservation` | 제품별 재료 적합성·유효성, 적용 절차, 점검 기준이 필요하다. |
| 운송 관측·임시 지지 | `fabrication.transport_erection` | 화학물질 문서, 표시, 덮개 및 고정장치 설계의 절차별 대응은 추가 검토 대상이다. |
| 질량·무게중심·평면 지지 반력 | `fabrication.equipment_mass_properties`, `fabrication.equipment_two_support_lift` | 인증 중량 및 인양 장비·러그·동적 설계는 별도 근거가 필요하다. |
| 장기 정지·재가동 | 저장 이력 API는 일부 관측만 지원한다. | 감압·탈기·세정·침전물 처리·재가동 절차별 대응이 남아 있다. |
| 동절기 단일상 재고 | `fabrication.winterization_inventory` | 설비별 적용 범위, 물성 상태, 상변화·수화물·정체부 등은 별도 검토가 필요하다. |
| 도료 소요량·관측 손상 | `protection.coating_coverage`, `fabrication.coating_damage_area_inventory` | 재료·환경·온도·보온 조건별 도장계 선정과 성능 근거는 외부 입력이다. |
| 볼트 체결·코팅 | 토크 계산 API 제공 | 코팅 선정, 응력부식균열·수소 손상 적합성은 토크 계산으로 판정하지 않는다. |

## 저온 기동

동절기 API 1.1.0부터 초기 온도가 선언된 하한보다 낮은 단일상 재고를 입력할 수 있다. 실제 시작 시각을 `time_s[0]`에 입력한다. 초기 하한 미달은 `first_minimum_temperature_crossing_s`에 시작 시각으로 남으며, 가열 후 회복되더라도 최소 온도와 음의 최소 여유는 유지한다. 이 필드는 가열 회복 시각이 아니다.

액상·기상 상태와 유효 열용량은 입력자가 검토해야 한다. 온도 하한은 동결점과 같다는 가정이 없으며, 상변화를 겪는 재고를 단일상 모델에 넣으면 안 된다. 온도 회복은 재가동 승인이나 설비 건전성 입증이 아니다.

## 확인 근거

`tests/test_winterization.py`는 정상 냉각 해석해, 하한 도달 시각, 열수지, 무손실 가열, 초기 하한 미달, 작은 온도 증분, 수치 범위 이탈, 검토 누락 및 CoolProp 연결을 확인한다. 이번 실행은 11개 통과했다. 수학적·소프트웨어 확인이며 독립 실험 검증은 아니다. 방청제의 안전성·효율과 보존 가능 기간에 보편 상수를 제공하지 않는다.
