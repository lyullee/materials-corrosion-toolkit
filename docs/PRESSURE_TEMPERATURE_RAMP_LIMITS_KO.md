# 금속 온도·압력의 시간 구간별 변화 속도

`structural.pressure_temperature_ramp_limits`는 검토한 구간 선형 이력에서 온도와 압력의 부호 있는 변화율을 계산한다. 계약은 `PressureTemperatureRampLimits`다. 구성품, 금속 온도 위치, 압력 위치와 시계 기준을 명시하고, 같은 길이의 시간(s)·금속 절대온도(K)·절대압(Pa) 배열을 입력한다. 시작 시각은 0일 필요가 없지만 시간은 엄격히 증가해야 한다.

온도 변화율은 `(다음 금속 온도 - 이전 금속 온도) / 구간 시간`이며 압력도 같은 방식이다. 승온·냉각·승압·감압의 한계는 각각 0 이상의 값으로 입력한다. 한계와 정확히 같은 값은 한계 내로 분류한다. 0 한계는 해당 방향 변화가 허용되지 않음을 뜻한다. 계산 완료 상태와 사용자 한계 초과 결과는 분리한다.

예를 들어 10초 동안 금속 온도가 300 K에서 320 K로, 절대압이 100 kPa에서 300 kPa로 바뀌면 +2 K/s와 +20 kPa/s다. 다음 20초 동안 각각 원래 상태로 돌아오면 -1 K/s와 -10 kPa/s다. 직접 작성한 산술 예제이며 실제 설비의 허용 속도는 아니다.

각 구간은 시작·종료 시각, 두 변화율, 방향별 한계 비교를 반환한다. 초과 구간의 인덱스도 남긴다. 전체 입력·한계·위치·시계 기준은 `CorrelationBasis`의 근거·권한·적용성 검토와 해시에 연결된다. 검토 누락은 `needs_data`, 표현 범위를 벗어난 변화율은 `out_of_scope`다. 0이 아닌 변화가 수치 언더플로로 0이 되면 한계 내 판정을 제공하지 않는다.

구간 선형 해석을 검토하지 않은 단순 샘플에 대해 실제 최대 변화율을 주장하지 않는다. 측정점 사이의 숨은 변동, 온도 센서 지연·공간 차이·압력 보정은 자동으로 해결하지 않는다. 유체 온도를 금속 온도로 대체하지 않으며 게이지압 입력도 직접 받지 않는다.

이 결과는 압력–온도 허용 경계의 준수, 최소 가압 온도, 수소 탈기, 취성파괴 안전 또는 운전 승인을 입증하지 않는다. 정적 경계 비교는 `structural.pressure_temperature_envelope`와 별도의 적용성을 가진다.

`tests/test_pressure_temperature_ramp_limits.py`의 12개 사례가 부호·시계·한계 경계, 네 방향 독립 한계, 정체 이력, 검토 누락, 수치 오버플로·언더플로, 배열·시계 유효성, 해시 변조와 기본 레지스트리 Python/JSON 교환을 확인했다. 독립 실험 검증은 아니다.
