# 상별 점계수 집계

`testing.phase_point_count_summary`는 호출자가 이미 분류한 현미경 격자 점수를 집계한다. 입력은 `PhasePointCountSummary`, 시야별 기록은 `PhasePointCountField`다. 영상에서 상을 자동 분류하거나 점을 생성하지 않는다.

각 시야는 이미지·좌표계·격자 해시, 시편 식별자, 전체 점수, 상별 점수와 미분류 점수를 제공한다. 모든 상의 점수를 명시해야 하며, 관측되지 않은 상은 명시적 0이다. 상별 점수와 미분류 점수의 합은 전체 점수와 일치해야 한다. 같은 이미지 해시·격자 해시는 시야나 좌표계 이름을 바꿔도 중복 입력할 수 없다. 서로 다른 격자의 실제 중복 여부는 호출자가 검토해야 한다.

통합 분율은 각 상의 전체 관측 점수를 전체 시험 점수로 나눈다. 시야별 분율을 동일 가중치로 평균하지 않는다. 격자 점의 동일성과 비중복 검토가 없으면 시야별 기록만 반환하고 통합 결과를 보류한다.

미분류 점이 있으면 `needs_data`다. 미분류를 분모에서 빼거나 특정 상에 자동 할당하지 않는다. 상의 관측 분율은 `count/total`, 식별 범위는 `[count/total, (count+unresolved)/total]`이다. 범위는 상마다 별도로 미분류 점을 전부 포함하거나 배제한 결과이며, 동시에 달성되는 조성 집합이나 통계적 신뢰구간이 아니다.

이 결과는 관측 점 분율이다. 체적 분율 추정에는 표본 설계·절단면·시야 선정·격자·상 구분·대표성의 추가 검토가 필요하다. 시야·점의 독립성, 분산이나 신뢰구간을 자동 가정하지 않는다. FN과 체적 분율을 동일시하거나 자동 변환하지 않으며, 열처리 전후 측정·서로 다른 재료 상태도 자동 통합하지 않는다.

입력 전체는 `basis`의 정규화 해시에 결합된다. 원본 이미지는 입력 경로로 읽거나 공개 배포물에 포함하지 않는다. 출력은 시험 합격, 규격 수락, 균열 방지나 내식성 보증이 아니다.

검증: `tests/test_phase_point_count.py`, `artifacts/validation/phase_point_count.xml`. 가중 집계·미분류·중복·식별자·정수 계수·Python/JSON 교환을 확인한다. 실험적 상 식별이나 체적 분율 추정의 검증은 별도다.
