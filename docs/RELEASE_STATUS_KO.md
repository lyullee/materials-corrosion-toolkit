# 0.1.0a1 공개 상태와 알려진 한계

첫 공개 버전은 연구용 알파 snapshot이다. 등록 API의 존재와 실제 자료를 사용한 물리·실험 검증의 완료 상태를 구분한다. 상위 위험성 평가나 다른 프로젝트의 물리는 이 툴킷의 검증 범위로 세지 않는다.

| 범위 | 기록된 상태 |
|---|---|
| 전체 등록 API | 757개. 물리 계산 외에 자료·계약·교환·기록·워크플로 포함 |
| 공개 입력 스키마 | 757/757개 일치 |
| 핵심 물리 묶음 | 63개 군, 명시적인 개별 실행 감사 대상 232개 API |
| 정상 계산 전수 실행 | 230/232개, 외부 근거 의존 2개 보류 |
| 대표 기준값·항등식 | 79개 시험, 63/63개 군 통과 |
| 추가 물리 일관성 | 57개 시험 통과, 위 묶음과 일부 중복 |
| 공개 전 보강 검사 | 25개 통과 |
| 주 JSON 예제 실행 | 400개 통과 |
| 설치 wheel 수치 검사 | 59개 통과 |
| 기본/전체 설치본 | 2개 모두 소스·카탈로그 해시 일치 |

## 해결하지 않은 항목

- 전체 Ruff 지적 885건이 남아 있다. 마지막 전체 점검에서는 942건이었고 명백한 미정의 변수·외부 누적 변수 선언 문제 등 선택 실행 오류를 수정했다. 남은 항목에는 loop closure·중복 키·중복 정의·unused·서식 지적 등이 섞여 있다. 모두 무해하다고 판단하지 않는다.
- 주 JSON 예제 파일이 모든 API를 포함해야 한다는 검사 1건이 실패한다. 400/757개 포함 상태다. 없는 357개가 코드 미구현이나 모두 미시험이라는 뜻은 아니다. 상세 API 스키마·설명서는 전체에 제공하지만 독립 실행 예제가 전체에 완비된 것은 아니다.
- `corrosion.piecewise_linear_rate_thickness_history`는 실측 초기 두께 근거가 필요하다. 합성값을 실측으로 바꿔 통과시키지 않았다.
- `data.mendeley_atmospheric_corrosion_typed_rows`는 편집 데이터 라이선스와 별개로 기초 관측자료 사용권한 확인이 필요하다. 권한 선언을 임의 생성하지 않았다.
- 대표 물리 계산끼리의 연결 근거는 15/63개 군이다. 결과를 사용자 판정 규칙으로 넘기는 소비 모듈 연결 63/63과 다르다.
- 한계해·수지·회전 불변량을 통과했다고 비선형 전체 결합, 실제 재료 계수, 현장 정확도, 규격 적합성 또는 사고 확률이 검증된 것은 아니다.

## 이력 해석

과거 전체 시험 실행은 15,693개 중 15,665개 통과·25개 실패·3개 건너뜀이었다. 이후 수정 파일의 재실행과 신규 시험을 파일별로 대조한 집계는 15,706개 중 15,702개 통과·1개 실패·3개 건너뜀이었다. 이는 수정 후 전체를 새로 한 번 실행한 결과와 다르다. 이번 공개 준비의 추가 시험도 별도 영수증으로 보관한다. 서로 중복된 시험을 더해 하나의 완료율로 만들지 않는다.

기존 엄격한 `verify.yml`/`scripts/verify.py`는 전체 정책을 유지하며 알려진 미해결 항목 때문에 실패할 수 있다. 알파 배포용 workflow의 기본 설치·선택 시험·패키지 경계 검사가 성공해도 기존 전체 품질 gate를 통과했다고 표시하지 않는다.
