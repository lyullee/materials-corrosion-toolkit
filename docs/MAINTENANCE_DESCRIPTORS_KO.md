# 생산 효과성과 파레토 집계

`maintenance.declared_equipment_effectiveness`는 같은 관측 창의 가동 시간 비율,
기준 속도 대비 실제 가동 속도 비율, 총생산량 대비 적합 생산량 비율과 그 곱을
반환한다. 시간은 초, 생산 속도는 사용자가 명시한 생산량 단위/초다.
관측 창·속도의 산정 방식·재작업/불량 집계와 품질 정의를 사용자가 검토한다.
초과 속도를 1로 잘라내지 않고 `performance_above_declared_reference`로 표시한다.
총생산량이 0이면 품질 비율을 추정하지 않고 `needs_data`로 반환한다.

`maintenance.declared_pareto_summary`는 범주별 건수 또는 건수×건당 비용을
내림차순으로 정렬한다. 비용 모드는 모든 범주의 비용과 공통 단위를 요구한다.
동률은 입력 순서를 유지하고, 합계 0의 점유율·누적 점유율은 `null`이다.
범주·관측 창·원기록 ID와 전체 요청 근거를 보존한다. 건수 원값은 정수로
유지하며 계산 측정값과 비율은 부동소수점으로 반환한다. 통화 환산·범주 합치기·
누락 비용 대입이나 고정 누적 비율을 사용한 우선순위 선정은 수행하지 않는다.

두 API 모두 전체 요청과 사용 권한을 `basis` 해시로 고정한다. 중간 곱과
비율에는 유리수 연산을 사용하고 지원 불가능한 최종 값·비영 비율의 소실은
`out_of_scope`로 반환한다. OEE는 고장확률·수명·안전성 지표가 아니며 파레토
순위는 인과관계·위험 범주·자동 정비 권고를 뜻하지 않는다.

OEE의 자산 ID는 레지스트리 실행 문맥의 자산 ID와 정확히 같아야 한다.
다른 자산의 생산 기록을 현재 평가 결과로 연결하지 않는다.

FMEA/FTA·정비 시스템과 연결할 때는 별도의 자산·고장모드·관측 창·시간 단위·
사건 정의·조건부 확률의 근거가 필요하다. 서열 점수를 확률로 바꾸지 않는다.
같은 사건과 시점에서 고장 누적확률은 신뢰도의 역수가 아니라 1에서 신뢰도를
뺀 값이다. 누적확률, 조건부 구간 확률과 순간 위험률도 별도 양이다.
수리 가능한 자산의 반복 고장 간격과 비수리품의 최초 고장 수명도 구분한다.
상용 정비 프로그램의 점수표·성과율·인증·법규 준수 판정을 내장하지 않는다.
