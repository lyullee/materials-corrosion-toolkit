# 기체–슬래그–금속 열역학 확장 요청

현재 `welding.declared_flux_basicity_ratio`는 조성 기술값만 계산한다.
산소·합금 원소 이동의 예측이 필요한 경우 이를 지수의 고정 회귀식으로
대체하지 말고 별도 열역학 공급자와 연결한다. 이 문서는 구현 완료가 아닌
추가 연구·공급자 개발 요청이다.

필요 입력은 플럭스/와이어/모재의 상태·원소 또는 화합물 기준 조성·질량,
화학식과 원소 수지, 온도·압력·상태 기준, 기체/슬래그/금속 상 목록,
활동도·기준상태·상 모델과 계산 방법이다. 평형 계산과 실제 용접의 구역별
질량 이동·반응속도 가정은 분리해 명시한다. 지수만으로 이를 정하지 않는다.

공급자는 계산 코드·열역학 데이터베이스의 식별자·개정·설정·내용 해시,
계산 및 재배포 권한, 적용 조성·온도·압력 범위를 제공해야 한다. 외부 데이터베이스를
현재 공개 배포물에 포함하지 않는다. 입력/결과의 단위·자산·공정·재료·시편·
관측 창·출처와 근거 해시는 기존 결과 계약과 연결해야 한다.

필요 검증은 원소 수지, 알려진 제한 조성/상태의 비교, 상 활성화·비활성화,
결합 변수 민감도·범위 밖 실패, 독립 계산 또는 원자료와의 대조다. 산소량
측정과 충격인성은 별도 검증 대상이며 경험 지수 일치만으로 통과하지 않는다.
외부 모듈 계약 검증과 전체 공정의 물리 검증도 별도로 기록한다.

방법 검토 출발점은
[염기도와 CALPHAD 비교 연구](https://www.mdpi.com/2075-4701/12/9/1530)다.
해당 논문의 코드·데이터·계수를 포함하거나 보편적인 정확도 우위를 주장하지 않는다.
