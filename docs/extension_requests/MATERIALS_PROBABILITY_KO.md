# 재료 비교와 확률 추정 연동 요청

## ammonia supply risk

검토한 기준 소스는 `f38136ac1c3639d8b6b11b2d1e9745bfbfeec0f9`이다. 기존 재료 비교 점수와 조건부 계수 계산은 스크리닝 기능으로 유지한다. MatIntegrity의 손상 여유·기간별 고장확률과 같은 필드에 저장하지 않는다.

필요하면 사용자가 선언한 평가 공급자를 받아 재료 비교 화면에 별도 결과로 표시하는 경로를 추가한다. 재료·용접·환경·검사 계수와 물리 모델에서 같은 영향을 이중 반영하지 않도록 선택한 모델 경로를 기록한다. 실제 고장 자료로 보정되지 않은 계수를 관측 연간 빈도로 표시하지 않는다.

## QSafety

검토한 기준 소스는 `3e7b3e78f3881a87f99d67554c6ad748fd0737e8`이다. 기존 `RiskDistribution`은 유한 혼합의 가중 확률을 받으므로 적절한 입력을 준비하면 핵심 API 변경 없이 연결할 수 있다.

향후 편의 어댑터를 추가한다면 MatIntegrity의 기간별 사건 플래그, 선언한 표본 가중치, 평가기간·생존 조건·출처 해시를 받게 한다. 연간 빈도를 확률로 오인하거나 여러 시각의 누적 사건을 독립 사건처럼 합산하지 않는다.

기존 HELPR 표본 경로는 저장된 유한 표본에 대한 연구 경로다. 새 손상 솔버를 직접 실행하는 양자 오라클, 데이터 적재 비용, 연속 모집단 사건과의 차이는 별도 평가한다. 이 요청서 작성이나 로컬 계약 검증은 QPU 실행을 뜻하지 않는다.

MatIntegrity의 독립 입력 민감도는 `SobolRequest` → `SobolDesign`/`SobolInputBatch` → `SobolEvaluations` → `SobolReport`로 교환할 수 있다. 분산의 주/총 효과와 수치 적분 구간은 혼합 사건 확률·기간 PoF·연간 빈도와 다른 필드로 수신한다. `precision_status`, 미계산 점, 반복 확인, 원 입력 분포·모델/시간 문맥과 모든 digest를 보존한다. 점 순서는 ID로 대조하고 실패 행을 제거해 새로운 조건부 모집단을 만들지 않는다.

QPU shot이나 stochastic simulator 출력을 연결하려면 먼저 관측 잡음·모델 변동·표본 적분 오차를 분리한 별도 방법이 필요하다. 재현 허용오차를 크게 정해 기존 결정론적 Sobol 조건을 충족한 것으로 처리하지 않는다. 고정한 동일 입력/응답 의미와 평가 비용에서 classical baseline과 비교하는 실제 통합 검사를 추가한다. 현재 로컬 민감도 구현은 원격 QPU 호출이나 그 검증을 포함하지 않는다.

분극 기반 `corrosion.mixed_potential`의 전위와 순전류는 사건 확률이 없다. 수신 모듈은 전위 기준·면적·원 곡선·미검토/다중 평형 상태를 보존하고, 별도 부분 반응·금속 손실·형상 성장·구조 한계·시간 불확실성 모델을 통해서만 기간 사건을 구성한다. 같은 표면의 내부 산화/환원을 포함한 전체 용출과 외부 순전류를 구분하며, 후보 평형점을 독립 고장 경로로 합산하지 않는다. 중첩된 전극/곡선 입력의 민감도는 일반 Python 평가자에서 같은 계약을 실행하고 `SensitivityBatchResult`로 미계산 상태를 전달한다. 원 분극 점을 독립 물리 매개변수로 임의 무작위화하지 않는다.

과도 온도와 두께방향 탄성 열응력 출력 자체에는 사건 확률 의미가 없다. 수신 측은 온도/응력의 위치·시각·형상, 경계 열 부호, 물성·평면 조건·탄성 범위와 수치 상태를 보존한다. 재료 열화·소성/크리프·균열·피로의 시간 모델, 구조 한계와 입력/모델 불확실성이 별도로 연결되기 전에는 FTA 기본사건 확률이나 연간 빈도로 변환하지 않는다. 같은 자료에서 적합된 열계수의 재현 오차를 확률분포나 독립 검증으로 사용하지 않는다.

FAD의 `inside_or_on_declared_boundary`도 이진 확률 사건이나 관측 고장빈도가 아니다. 입력 균열 분포·검사 검출/크기오차·하중 이력·성장·toughness/강도/K/reference-stress/모델 불확실성 및 명시적인 시간 범위를 표본별로 연결한 뒤에만 기간 사건을 구성한다. 곡선 밖 여러 평가점을 독립 FTA 기본사건으로 합산하지 않는다. Crack-arrest 시계열의 행·cycle 수도 독립 시편이나 실패 횟수가 아니다.
## 희귀사건 표본 교환

`reliability.gaussian_mean_shift_importance_sampling`과 연결할 때 수신 저장소는 표준정규 잠재변수
순서, 평균이동 벡터, design/sample ID, 잠재 매핑 ID·리비전·설정 digest, 결정론 평가자
ID·리비전·설정 digest와 Boolean 사건 지시값을 그대로 교환한다. 평가 실패·out-of-scope·누락을
`False`로 변환하지 않는다. 같은 자산·물리범위·기간·생존조건의 최초사건 정의가 아닌 출력은
이 계약에 넣지 않는다. 독립 잠재좌표를 독립 재료변수로 해석하지 않으며 ESS·표본 표준오차와
정규구간을 재료분포·모델형식·실험 불확실성으로 저장하지 않는다. 대용량 교환은 후속 versioned
streaming batch 계약을 추가하고 행 순서 대신 sample ID와 digest로 조인한다.
