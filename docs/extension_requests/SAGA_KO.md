# SAGA-PY 설명 연동 요청

검토한 기준 소스는 `6eb94e00b146e18392e535d227f0c3e5ce1aca10`이다. 이 소스의 수치 HAZOP 경로는 `/api/digital-twin/hazop/evaluate`다. 제거된 과거 경로를 다시 있다고 가정하지 않는다.

`matintegrity.explanation_context.v1`에 포함된 계산 결과·적용 가정·입력 기원·상태·출처 ID·해시를 받는 설명 입력을 추가한다. 기존 HAZOP 입력에 억지로 매핑하기보다 재료 평가의 근거를 보존하는 별도 타입이 적합하다.

설명 계층은 계산값을 다시 판정하거나 누락된 허용응력·검사 POD·규격 한계값을 만들어내지 않는다. `needs_data`, `out_of_scope`, 합성 예제와 실측 자료를 설명에 그대로 표시한다. 실제 검색된 문서와 목록만 존재하는 후보 근거도 구분한다.

재료 성분·경도·공급 예산에서는 `computed`와 별도 `outcome`/`declared_budget_outcome`을 함께 설명한다. `policy_gate`로 중지된 절차의 원인이 미측정인지 요구조건 미충족인지 보존한다. 명칭 조회를 재료 대체 승인으로, 충격에너지 곡선을 파괴인성 또는 허용 사용온도로 바꿔 설명하지 않는다.

인수 시험에는 같은 계산 결과의 일관된 설명, 근거 없는 수치 추가 방지, 미확정 결과를 합격으로 요약하지 않는지, 자산·부위 혼동 방지가 포함된다. 외부 LLM 호출 여부와 모델·프롬프트·입력 해시는 서비스 측에서 별도로 기록한다.
