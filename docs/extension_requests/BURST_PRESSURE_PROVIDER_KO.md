# 파열압 예측 공급자 연동 요청

## 목적

상용 코드, 사용자 계산식, 유한요소 해석 또는 다른 Python 저장소가 만든 배관 실패압 예측을
`structural.burst_pressure_comparison`으로 전달한다. MatIntegrity는 상대 모델의 식·규격표·
허용계수·라이선스 자료를 복사하지 않고 버전 있는 결과와 근거만 수신한다.

## 공급자 출력

각 예측 행은 다음 값을 내보내야 한다.

- 공급자 ID·버전과 전체 설정의 canonical SHA-256
- 관측 ID에 일대일 대응하는 예측 입력 digest
- 재료 상태·배관/결함 형상·하중 case ID
- 예측 실패압 Pa와 `internal_minus_external`, `gauge_internal`, `absolute_internal` 중 압력 기준
- 사용한 solver·식·설정의 판본과 적용범위
- 계산 완료, 범위 밖, 입력 부족을 구분한 상태

관측 시험값은 공급자 저장소에 복사할 필요가 없다. 양쪽이 합의한 관측 ID와 입력 digest로
결과를 결합하고, 비교는 관측 이용 권한이 있는 환경에서 수행한다. 임시 URL·자격정보·상용
테이블 내용은 교환 JSON에 넣지 않는다.

## 인수 조건

1. 같은 공급자 버전·설정·입력은 같은 설정 및 입력 digest를 만든다.
2. 예측압의 기준이 실제 시험압 기준과 정확히 같아야 한다.
3. 평가 자료를 보기 전에 공급자 버전과 설정을 고정한다.
4. calibration source group은 holdout 또는 external-validation에 다시 나타나지 않는다.
5. 한 물리 시편을 여러 행 또는 여러 분할에서 반복하지 않는다.
6. 범위 밖이나 계산 실패를 숫자 예측으로 채우지 않는다.
7. 비교 통계를 규격 합격, 안전계수, 예측구간, 잔여수명 또는 고장확률로 바꾸지 않는다.

현재 공개 `compiled-pipe-burst` 편집본은 물리 시편 ID, 지름·압력 기준과 원 관측 권리 검토가
완료되지 않아 자동 인수 대상이 아니다. 자격화한 자료가 준비되면 공급자 고정 리비전과 함께
실제 end-to-end 검사를 추가한다.
