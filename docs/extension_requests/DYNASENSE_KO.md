# 민감도 분석 연결 요청

조사 기준은 `prism-dynasense`의 `bd46cc46a6791131e414221135a1092f540b87d6`이다. 기존 사고 계산 전용 변수와 결과 선택을 일반적인 Python 평가 callback·파라미터 계약으로 확장하는 것을 요청한다. MatIntegrity에 상대 저장소 구현을 복제하지 않는다.

입력은 이름·분포·SI 단위·유효 범위·의존성 선언·seed와 수치 모델/데이터 해시다. 출력은 선언한 한 개의 여유·수명·기간 확률 등 scalar이며 의미와 단위를 보존한다. `ModelRegistry.run` 또는 `simulate_limit_state` 주변에 순수 평가 함수를 두고 out-of-scope 표본을 0이나 안전한 값으로 대체하지 않는다.

초기에는 검토된 독립 입력의 Sobol 분석을 지원하고, 상관 입력에는 다른 추정기·joint sampler가 필요함을 명시한다. 확률 추정 안에 Monte Carlo가 중첩되면 공통난수·추정기 오차·수렴을 기록한다. 초기 생존 조건으로 표본을 선택할 때 분포가 달라지는 점과 서로 다른 기간의 누적 사건 의존성을 고려한다.

인수 조건은 알려진 가법 모델의 지수 회복, 표본수 증가에 따른 수렴·신뢰구간, callback 실행 실패와 범위 밖 상태의 보존, seed·리비전 재현, 단위·출력 선택 실수의 거절이다. 현재 MatIntegrity의 한계상태 표본평가는 전역 민감도 분석을 자동 구현한 기능이 아니다.
