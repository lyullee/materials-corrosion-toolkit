# 부품 압력 한계의 공통 기준면 환산

API: `structural.component_pressure_reference` 1.0.0. Python 입력 계약은 `matintegrity.models.component_pressure_reference.ComponentPressureReference`다. 기본 레지스트리의 `run`과 `run_json`을 모두 지원한다.

상향 양의 표고에서 부품 i의 국부 압력 상한을 Lᵢ, 표고를 zᵢ, 기준면을 z₀라 하면 기준면 상한은 Lᵢ + ρg(zᵢ − z₀)다. 모든 부품의 환산 상한 중 최솟값을 반환하며 정확히 같은 최솟값을 가진 모든 부품을 보존한다. 정수압 관계의 독립 참고 자료는 [NASA Fluid Pressure](https://www.grc.nasa.gov/www/k-12/WindTunnel/Activities/fluid_pressure.html)다. 설명·코드는 자체 작성했다.

입력에는 설비·위치·물리 범위·좌표계·상태·압력 기준·공통 압력 기준 ID·부품별 온도와 용량 입력/결과 해시·근거를 넣는다. 같은 시나리오 내 모든 부품의 상태 ID가 일치해야 한다. 온도는 부품별로 달라도 되지만 각 용량의 온도 적용성은 별도로 검토해야 한다. 실행 문맥의 설비·위치도 입력과 같아야 한다.

밀도와 중력은 기본값 없이 입력한다. 정지·연결·균일 밀도 유체와 일정 중력, 공통 표고·압력 기준, 부품 목록 완전성, 용량 적용성 검토가 모두 필요하다. 분리 유체·층상 유체·압축성 밀도 변화·유동 손실·동적 하중은 이 계산의 범위 밖이다. CoolProp으로 구한 밀도도 해당 정적 시나리오를 대표하는지 확인해 입력한다.

예: 기준면이 표고 10 m이고 밀도 1000 kg/m³, 중력 10 m/s²일 때 표고 0 m의 부품 상한 1.05 MPa는 기준면 상한 0.95 MPa가 된다. 같은 기준면에 있는 다른 부품의 상한이 1 MPa이면 아래쪽 부품이 지배한다. 이 값들은 산술 설명용이며 실제 설계 자료가 아니다.

계산은 정확 비율 산술로 중간 곱과 합을 결합한다. 표현 불가 결과는 `out_of_scope`, 검토 누락은 `needs_data`다. 양의 절대 기준압력이 존재하지 않으면 값을 보류한다. 게이지 압력의 음수 상한은 부호를 유지하지만 진공 적격성을 의미하지 않는다.

이 기능은 공급된 상한의 집계다. 형상별 용량식, 허용응력 표, 규격 합격, 하한·캐비테이션·외압 안정성, MAWP 인증 또는 고장확률을 계산하지 않는다. 이러한 제한 때문에 집계 결과를 단독 최종 운전 허가로 사용하지 않는다.

검증: 자체 작성한 정수압 부호, 기준면 이동, 동률, 누락 검토, 상태/품목 혼합 거부, 수치 범위, Python/JSON 교환 사례를 사용한다. 독립 실험이나 규격 인증을 대신하지 않는다.
