# 설계 산출물과 적용 근거 관리 범위

## 적용 범위·부품 역할·비금속 근거

지배 문서의 판본과 그 문서가 채택한 참조 판본은 별도 정보다. 모든 참조 문서를 자동으로 최신판으로 바꾸지 않는다. 압력 경계, 구조적으로 압력을 지지하는 부품과 부착물의 역할은 설계·제작·자격 절차별로 구분해야 한다. 단일 역할 이름으로 이음효율·검사·자격 요구를 자동 부여하지 않는다. 이 조건들의 판본별 연결은 남은 과제다.

압력값에는 게이지/절대압, 운전/설계/허용/시험의 역할을 보존한다. 기존 `inspection.pressure_test_load`와 `materials.scaled_strength_minimum`의 산술 지원은 전체 규격 적용 범위나 예외의 자동 선정을 뜻하지 않는다.

비금속은 수지와 적층 구조의 식별자, 화학 환경, 온도별 강도·탄성계수, 시간에 따른 변화와 공급자가 정한 사용 범위의 근거가 필요하다. 원형의 파괴시험에 의한 자격과 설계 규칙·해석 및 인수시험에 의한 자격을 서로 바꾸어 사용하지 않는다. 해당 근거와 방법의 구체적인 연결은 미완료이며 공통 온도·압력 한계나 재료 승인값을 내장하지 않는다.

## 두께 기준과 인증

`fabrication.thickness_budget`은 제조 공차 차감, 가공 잔존율, 부식여유를 이용한 전방 계산을 제공한다. `fabrication.pipe_bend_wall_allowance`는 명시된 잔존율을 순서대로 적용한다. 이 계산으로 제품별 허용 공차, 공칭 게이지, 규격 최소 두께 또는 자격 최대 두께가 자동 선택되지는 않는다. 해당 선택과 조건별 적용 근거 연결은 남은 과제다.

발주 공칭 두께, 최소 공급 두께, 가공 후 실측 두께와 구조 계산에 쓰는 순 두께를 구분해야 한다. 부식여유가 이미 포함된 요구값에 여유를 다시 더하지 않으며, 피복·모재·홈 바닥의 측정 위치를 명시해야 한다. 게이지 한 단계는 고정 길이로 환산하지 않는다.

인증 정보에는 발급자·증서 식별자·보유자·유효기간과 승인된 활동 및 제품 범위가 필요하다. 이를 근거와 연결하는 기능은 추가 대응 과제다. 과거의 인증 목록으로 현재 유효성·검사 면제·갱신 주기를 자동 판정하지 않으며, 계산 결과를 인증으로 표시하지 않는다.

설계 단계는 사용자가 프로젝트에 맞게 정의해야 한다. 단계별 산출물의 식별자·개정·입력 의존성·담당자와 승인 상태를 보존하는 관리 기능은 추가 대응 과제다. 문서가 존재한다는 사실과 계산이 끝났다는 사실, 프로젝트가 배포를 승인했다는 사실은 각각 구분한다.

적용 근거에는 관할, 계약상 지정 판본, 수정 사항, 해석 또는 별도 적용 사례의 식별자, 채택 결정과 사용 권한이 필요하다. 과거 발행 주기를 이용해 현재 적용 판본을 자동 결정하지 않는다. 계산 결과만으로 규정 충족이나 법적 승인을 판단하지 않는다.

이 범위 정리는 관리 기능의 구현 완료를 의미하지 않는다. 열·물질 수지, 장치 크기 결정 또는 응력 해석이 산출물에 포함되어도 해당 해석기의 존재와 적합성은 개별적으로 확인해야 한다. 예산 오차나 공정 기간의 예시는 공통 기본값으로 사용하지 않는다.
