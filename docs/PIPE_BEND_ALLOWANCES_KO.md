# 배관 굽힘 두께 여유와 최소 유지시간

`fabrication.pipe_bend_wall_allowance`는 `PipeBendWallAllowance`를 입력으로 받는다. 명목 벽두께(m)에 사용자가 명명한 보유율들을 순서대로 곱하고 부식여유(m)를 뺀다. 보유율은 0~1이며 손실률이 아니라 남는 비율이다. 예를 들어 보유율 0.9와 0.8은 명목 두께의 0.72를 남긴다. 계수의 적용 기준·순서는 사용자가 검토해야 하며 제조 및 변형 손실이 독립이라는 통계적 가정은 하지 않는다.

필요두께는 사용자가 준 압력 설계 요구와 인접 배관 요구 중 큰 값이다. 결과는 각 계수 적용 후 두께, 여유 차감 후 가용두께, 요구두께와 부호 있는 여유를 보존한다. 양의 가용두께에서 여유가 음수인 경우도 산술은 완료됐으므로 `computed`다. 가용두께가 0 이하이면 `out_of_scope`다. 계산 상태를 제품 허용 판정으로 사용하지 않는다. 이 값은 선택한 여유 시나리오이며 실제 굽힘 후 최소두께 측정을 대신하지 않는다.

`thermal.thickness_soak_duration`는 `ThicknessSoakDuration`를 입력으로 받는다. 지배두께(m)에 사용자 시간 계수(s/m)를 곱한 값과 사용자 최소시간(s) 중 큰 값을 구한다. 동률이면 두 지배 항을 모두 기록한다. 유지시간 계수와 최소시간은 규격·절차에서 사용 권한과 적용성을 확인해 제공해야 한다. 입력값은 0을 허용하지만 양의 곱이 수치 범위를 벗어나거나 0으로 언더플로하면 `out_of_scope`다.

두 타입은 `matintegrity.models.engineering_correlations`에 있다. 기존 상관식 API와 동일하게 `CorrelationBasis`에 기본값·중첩 계약까지 정규화한 전체 요청의 해시, 사용 권한과 근거를 제공한다. Python·JSON 호출은 기본 레지스트리의 해당 모델 ID를 사용한다. 결과는 부품·시나리오 또는 절차 ID와 입력 해시를 보존한다.

유지시간 결과는 실제 온도 이력에서 검토해야 할 목표시간으로 전달할 수 있다. 기존 `welding.heat_treatment_history`의 연속 유지 구간·센서 범위 검토는 별도로 수행한다. 이 API는 가열 완료 시점, 실제 유지시간, 온도 균일성, 물성 변화나 열처리 승인 여부를 계산하지 않는다. 내장된 규격 계수·시간표는 없다.

검증은 순차 보유율·부식여유·인접관 요구, 음의 여유 보존, 가용두께 소진, 중복 계수 ID 거부, 시간의 최소·비례·동률 조건, 수치 범위와 Python/JSON 동일성을 포함한다.
