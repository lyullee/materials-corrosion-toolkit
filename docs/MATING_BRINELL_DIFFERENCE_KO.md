# 맞물림 면의 HBW 경도 차 비교

`testing.mating_brinell_hardness_difference`는 두 면의 보고된 HBW 경도 차와
불확도 구간을 사용자 요구 차이와 비교한다. 각 면의 식별자·물리 범위·재료 상태·
원자료 해시, 시험 방법/개정·시험력·압입자 지름·유지시간·온도를 보존한다.
시험 조건과 척도가 정확히 같아야 하며 HB·HBS 표기를 HBW로 자동 바꾸지 않는다.

`comparison_direction`은 첫째 면이 더 단단해야 하는 경우, 둘째 면이 더
단단해야 하는 경우, 어느 방향이든 차이만 필요한 경우를 구분한다.
최소 차이는 `minimum_declared_difference_HBW`로 직접 제공한다.
규격별 재료 클래스·시험 조건·최소 차이나 경도표를 내장하지 않는다.

각 측정의 제공된 확장불확도를 구간 경계로 사용해 차이 구간을 계산한다.
독립성·공분산·차이의 통계적 신뢰수준은 추정하지 않는다. 방향 무관 비교는
서명 있는 차이 구간 전체를 절댓값으로 변환한다. 구간이 0을 포함하면
절댓값 구간 하한도 0이다. 중심값 차이만으로 임의 통과 처리하지 않는다.

구간 전체가 최소 차이 이상이면 `within_declared_requirement`, 전체가
미달하면 `outside_declared_requirement`, 걸치면 `uncertainty_overlap`이다.
같은 측정면을 두 번 사용하거나 다른 조건을 조용히 혼합하지 않는다.
입력 해시·사용 권한과 면 대응/구간 의미 검토가 필요하다.

이 비교는 사용자 경계의 산술 대조다. 밸브 트림 클래스·짝 재료 순서·갤링·
마모·씰 성능·내식성·생산 승인이나 표면 전체의 경도 분포를 예측하지 않는다.
명목 조합 코드가 실제 부품 재료·공급 상태·판본과 맞는지는 별도 확인한다.
