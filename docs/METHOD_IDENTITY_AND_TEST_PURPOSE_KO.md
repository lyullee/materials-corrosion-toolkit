# 공정 식별과 시험 목적의 구분

용접 공정의 분류 관계는 공정 선택과 자료 정리에 쓰는 정보다. 같은 계열에 속한다는 이유로 공정 ID를 바꾸거나 자격 범위를 공유하지 않는다. `welding.wps_qualification_envelope`는 사용자가 지정한 실제 공정·절차·개정·양쪽 재료 상태·이음과 시험 근거를 비교한다. 분류 도표의 이름이나 약어만으로 입열·결함 확률·용접성·자격 적합성을 계산하지 않는다. 공정 명칭과 약어의 대응 자료를 붙일 때에는 판본·공급자·의미와 근거를 유지한다.

압력시험 계획은 시험 방법과 함께 목적을 정의해야 한다. 구조적 압력 지지 확인, 영구 변형 확인과 누설 검출은 같은 결과가 아니다. 같은 매체를 사용하는 절차라도 목적과 판정 기준이 다를 수 있다. `inspection.pressure_test_eligibility`에 쓰는 방법 ID와 승인된 사용자 봉투는 그 차이를 구분해야 하며, 목적별 요구를 필수 요건 ID와 근거로 연결한다. 서로 다른 목적의 절차를 같은 일반 명칭만으로 연결하지 않는다.

적격성 입력에는 물리 경계·재료 상태·매체·압력 기준·압력 및 온도 범위·격리·저장 에너지와 필요한 선행 요건을 유지한다. 코드가 비교하는 것은 공급된 봉투와 기록의 일치 여부다. 실제 절차의 선정 권한과 완전성·매체 적합성·측정 및 검사 성능은 별도 근거가 필요하다. 표의 정성 비교를 액체의 압축성·저장 에너지 0이나 기체 시험의 일괄 허용 조건으로 바꾸지 않는다.

`inspection.gas_pressure_decay`와 `inspection.vacuum_rise`는 각각 명시한 가스 상태·기하·배경 조건 아래의 물질 수지 계산이다. 기밀성 판정에는 검출 성능·배경·시간·온도·계측·절차 기준이 추가로 필요하다. 누설이 관측되지 않았다는 사실만으로 구조 강도·사용 적합성·잔여 수명·고장확률을 생성하지 않는다.

이 문서는 기존 API의 의미와 입력 근거를 정리한다. 공정 분류표·매체 선정표·검사 한계·절차 허용 기준이나 새로운 수치 모델을 제공하지 않는다.
