# 물성 표 보간과 조회 묶음의 상태

`materials.allowable_property_provider` 1.0.1은 같은 재료·제품·상태·방향·근거 판본과 적용 범위의 사용자 물성 표만 조회한다. 입력 계약과 물성 데이터 사용 권한 요구는 유지한다. 이번 변경은 물성 표의 수치 처리와 묶음 상태를 보완하며 실제 재료 물성을 새로 제공하지 않는다.

공통 `TabulatedProperty`의 선형 보간은 구간 선택 후 두 좌표·두 관측값의 차와 가중합을 정확 유리수로 결합한다. 큰 반대 부호의 관측값이나 넓은 좌표 간격에서 중간 차의 넘침을 피한다. 관측 좌표에서는 원래 값을 그대로 반환한다. 비영 보간 결과가 표현 불가능하면 오류로 처리하며 작은 값을 0으로 대체하지 않는다. PCHIP는 기존 SciPy 방식을 유지하고 비유한 출력은 허용하지 않는다. 선형 보간에 대한 정확 산술 설명을 PCHIP까지 확장해 해석하지 않는다.

하위 표 제공자는 보간·수치 단위 변환이 지원되지 않으면 값을 보류하고 `out_of_scope`로 반환한다. 원점을 공유하는 단위 변환에서 비영 값이 0으로 소실되는 경우도 포함한다. 절편이 있는 온도 변환의 정상적인 0은 보존한다. 정의되지 않은 단위나 차원이 다른 요청은 입력 오류가 될 수 있으므로 단위 유효성은 입력 단계에서도 확인한다.

묶음에 자료 부족 조회가 하나라도 있으면 전체 상태는 `needs_data`다. 자료 부족은 없지만 범위를 벗어난 조회가 있으면 전체는 `out_of_scope`다. 모든 조회가 성공해야 `computed`와 `queries_resolved`를 반환한다. 진단을 위해 각 조회의 값·상태·근거와 상태별 개수는 보존하므로 전체 상태와 조회별 상태를 함께 확인해야 한다.

표의 온도 좌표가 설계 온도·운전 온도·금속 표면 온도 중 무엇을 뜻하는지는 자동 선정하지 않는다. 재료 판본·제품 형태·두께·제조 및 열처리 상태·환경·허용된 사용 목적은 적용 범위 식별자와 사용자 검토로 유지한다. 빈 셀·미상 표기·해당 없음·수치 0을 임의로 합치거나 다른 제품의 값을 옮겨 쓰지 않는다. 보간 가능한 물성 표가 설계 허용 응력·인성 면제·수명·적합성의 근거가 자동으로 되는 것은 아니다.

25개 합성 수치·기존 제공자·자료 계약·Python/JSON 교환 검사는 소프트웨어 동작을 확인한다. 실제 재료 표의 정확성·사용 권한·적용성·독립 실험 검증은 별도다.
