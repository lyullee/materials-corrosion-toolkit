# 압력시험 계산의 지원 범위

`inspection.pressure_test_load`는 사용자가 정한 시험 배율과 허용응력 비율,
게이지 아래의 비음수 고도차에 따른 일정 밀도 수두를 계산한다. 물성·배율·
게이지 위치의 적용성은 호출자가 확인한다. 모든 구성품의 최대 허용 시험압력,
격리 상태나 최소 요구 압력을 자동으로 선정하는 API는 아니다.

`inspection.pipe_membrane_test_pressure`는 외경 기준의 관막응력 산술이다.
공급된 항복강도 비율을 사용하며 규격별 등급 계수·반올림·두꺼운 관의
해석·나사 연결부 성능·시험 승인을 자동 결정하지 않는다. 커플링과 나사
연결부 API도 입력된 치수·계수·단위 관례의 적합성을 별도로 검토해야 한다.

## 기체 팽창 에너지

`inspection.gas_expansion_energy`는 일정한 비열비 Cp/Cv가 1보다 큰
이상기체의 가역 단열 팽창 일을 계산한다. 초기·최종 압력은 모두 절대압이고,
부피는 가압 상태의 초기 부피다. 결과는 경계 팽창 일이며 대기에 하는 일을
제외한 가용 일, 폭발 효율, 충격파 또는 파편 운동에너지와 같다고 보지 않는다.
실제 기체의 상태 변화나 온도에 따른 비열 변화는 이 API의 범위 밖이다.

일정 비열비 모델의 독립 대조 근거는
[ABSA의 AB-522 공식 자료](https://www.absa.ca/media/1508/ab-522_standard_pneumatic_test_procedure_requirements.pdf)다.
해당 자료의 공기·질소용 반올림 지수·고정값이나 승인 한계를 내장하지 않는다.
사용자 비열비를 직접 계산하며 규격 적합성 판정과 구분한다.

`inspection.reference_energy_mass`는 입력 에너지를 사용자가 명시한
기준 비에너지로 나누는 정규화다. 특정 폭약 상수나 안전거리는 내장하지 않는다.
시험 유체·금속 온도, 취성파괴 적합성, 압력 상승·유지·감압 이력,
검사·도장·시험 대체 승인 근거는 별도 관리가 필요하다.

## 수치 처리와 검증

압력 곱과 비율은 유리수 중간 연산으로 최종 값의 표현 가능성을 판단한다.
팽창은 압력비의 직접 오버플로를 피하고 가까운 압력에서 `log1p`와
`expm1`을 사용한다. 같아진 압력의 일은 정확히 0이다. 지원 불가능한
최종 압력·부피·일이나 비영 결과의 소실은 `out_of_scope`로 반환한다.

작성한 사례는 비열비 2의 해석해, 같은 압력, 가까운 압력, 극단 압력비,
수두 합산과 중간 곱셈 상쇄를 포함한다. 이는 실측 시험이나 안전거리,
시험 패키지의 승인·구조 건전성 검증을 대신하지 않는다.
