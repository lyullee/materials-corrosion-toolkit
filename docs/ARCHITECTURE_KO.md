# 구조와 후속 연구 작업

## 구성 경계

`contracts.py`는 값·결과·근거·사건의 계약, `registry.py`는 버전 있는 모델 등록과 실행, `models/`는 계산을 담당한다. `data.py`와 `signals.py`는 원자료를 단위·한정값·결측을 보존해 읽는다. `providers.py`는 사용자 재료 표의 조건·판본을 대조한다. `composition.py`는 명시된 파라미터와 결과 연결, `rules.py`는 사용자 요구값 비교, `uncertainty.py`는 한계상태 표본평가, `adapters.py`는 다른 프로젝트와 교환할 중립 객체를 제공한다.

```mermaid
flowchart LR
    A[운전·재료·검사 데이터] --> B[단위·품질·출처 계약]
    B --> C[사용자 물성·파라미터 공급자]
    B --> D[손상·응력·수명 모델]
    C --> D
    D --> E[워크플로·한계상태·검사 갱신]
    E --> F[기간 확률·근거·모니터링 계약]
    F --> G[독립적인 위험성·공정·설명 모듈]
```

계산 모듈은 암묵적으로 네트워크·LLM·양자 장치·설비 제어를 호출하지 않는다. 실행 결과는 입력 스냅샷, 모델 버전, 단위, 문맥, 근거, 의존성 버전, 입력 해시를 보존한다. 입력 해시는 실행 시간이 아니라 요청의 내용으로 만든다. 외부 실험 검증과 코드 버전 검증은 다른 근거다.

## 현재 구현 현황과 한계

2026-10-31 현재 저장소 카탈로그에는 695개 capability가 있으며 계산기 420개, 교환·확장 인터페이스 174개, 부분 구현 101개로 나뉜다. 공개 계약 schema는 887개다. 이는 추적·범위 지표이며 기술 분야 전체의 구현 완료, 실험 자격화, 라이선스 승인 또는 타 저장소와의 실제 통합을 뜻하지 않는다. 이전 문서의 전체 진행률 78% 및 코딩 진행률 80–85%는 재현 가능한 분모와 완료 기준이 없어 철회했다. 전체 범위별 증거와 잔여 작업은 `data/catalogs/objective_progress.json`, `STATUS_KO.md`, `CONTINUATION_KO.md`와 capability 카탈로그를 확인한다. 서로 다른 항목 수를 평균하여 전체 진행률을 만들지 않는다.

부분 구현은 더 좁은 계산·자료 계약과 미지원 범위를 함께 기록한다. 예를 들어 사용자 공급 FAD 평가점은 자격 있는 K/reference-stress 해와 실제 규격 전체가 아니며, 내압 시험의 하중상태·종료 사건 계약은 국부 노치 응력이나 다축 피로수명 기준이 아니다. 대기부식 1년 평균손실 모델은 source-group 전이 기준을 충족하지 못해 기본 예측을 차단하며 국부·다년 부식 전체가 아니다. 습식 CO2 편집 자료는 단위·원출처·데이터 유형이 없어 원값 감사 인터페이스만 부분 구현했다. 캐비테이션 정압 여유는 기포핵·붕괴·침식 손상모델이 아니며, 공동 사건 상태합과 시간 불변·구간별 상수 CTMC는 실제 공통원인율·노화·연속 시간가변·semi-Markov 동적 신뢰성 전체가 아니다. 임계확률 검사시점 선택, 단일기간 행동 기대손실 비교와 검사결과별 고정 처분나무는 사용자 공급 forecast·분기·비용의 유한 후보만 계산하며 실제 검사효과 보정·순차 관측·다기간 자원 최적화 전체가 아니다. Gaussian 평균이동 중요도 샘플링은 정확 우도비와 진단을 제공하지만 적응형·다중모드·subset 희귀사건 해석 전체가 아니다. 1D 과도 열전도와 탄성 단면 응력도 복잡 형상·비선형 열응력 전체가 아니다. 각 미구현·부분 범위는 능력 카탈로그와 후속 작업에서 추적하고 실제 자료·권한 확보에 따라 우선순위를 조정한다.

## 다음 구현 순서

고정된 한 다기간 정책의 완전 유한 경로 기대값과 외부 평가 정책들의 확률·자원 hard constraint 우선
비교는 실행 계산기로 제공한다. 다만 실제 자료 기반 상태·관측·전이 식별, 상세 자원일정과 전역
최적화는 미구현 범위에 남는다.

검토된 유한 초기·관측·고정규칙·전이 확률표의 비영 경로 전개도 실행 계산기로 제공한다. 실제
자료에서 상태·관측·전이를 식별·보정하는 기능과 경험적 자격화는 별도 미구현 범위다.

## 세션 없이 이어가기

`STATUS_KO.md` → `PLAN_KO.md` → 데이터·능력·근거 카탈로그 → 이 문서 순서로 읽는다. 사용자 요구가 바뀌면 계획과 카탈로그를 먼저 갱신한다. `scripts/verify.py`로 코드·카탈로그·모델 문서·테스트를 재생성하고, 데이터 취득 후 `inspect_open_data.py`로 조사 결과를 갱신한다. 배포는 `RELEASE_KO.md`의 경계와 검사를 따른다. 새 모델은 단지 등록 예제가 통과했다는 이유로 실험 검증 완료 상태로 올리지 않는다.

정적 감육 용량은 공급자와 결합된 계산 구성요소다. 파열압 비교기는 검토된 실제 시편과 같은 압력 기준의 고정 공급자 예측만 비교하고 source-group 누설을 거절한다. 실험 파열압 편집 자료의 색상·미확정 문헌·권리·시편·압력/지름 기준을 유지하고, 검증된 공급자 없이 규격 적합성으로 승격하지 않는다. 내압·외압의 차압과 절대 내압도 별도로 교환한다.
