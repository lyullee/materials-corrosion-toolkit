# 측정 프로파일의 조도 지표

`inspection.surface_profile_roughness`는 `matintegrity.models.fabrication_surface.SurfaceProfileRoughness`를 받는다. 위치와 높이는 m 단위 배열이며 위치가 엄격히 증가해야 한다. 원자료의 정렬·결측 보정·필터링·형상 제거를 자동 수행하지 않는다. 호출자가 처리 근거·측정 방향과 구간별 선형 해석을 검토해야 하며, 검토가 없으면 `needs_data`다.

요청에는 자산·위치·프로파일·물리 시험편·좌표계·측정 방향 ID, 처리 근거와 증거를 보존한다. 배열의 숫자를 float로 정규화한 뒤 `profile_digest`를 `canonical_digest({"position_m": 위치배열, "height_m": 높이배열})`로 계산한다. 실행 자산·위치도 일치해야 한다.

길이로 가중한 평균 높이를 먼저 빼고 구간별 선형 함수를 적분한다. Ra는 높이 절댓값의 길이 평균, Rq는 높이 제곱 길이 평균의 제곱근이다. 구간 안에서 높이가 0을 지나는 경우 절댓값 적분을 나누어 계산한다. 따라서 표본 수로 단순 평균하거나 절댓값 끝점만 사다리꼴 적분하는 방식과 다를 수 있다. 불균일 위치 간격도 실제 길이 가중치로 반영한다.

Rp·Rv·Rt 출력은 이 전체 평가 프로파일의 최대 봉우리 높이·최대 골 깊이·전체 높이 차다. 표준별 구간 평균 지표와 자동으로 동일시하지 않는다. Rz·등급 번호·고정 Ra/Rq 환산값을 제공하지 않는다. 필터·컷오프·평가 방향·장비 교정·불확실성과 표면 허용 기준은 별도 근거가 필요하다. 정의와 측정 조건의 참고 자료는 [NIST 조도·단차 교정 설명](https://www.nist.gov/publications/nist-surface-roughness-and-step-height-calibrations-measurement-conditions-and-sources)이다. 이 API가 NIST 교정을 재현하거나 표준 적합성을 보증하는 것은 아니다.

높이와 구간 가중치를 정규화해 큰 값의 제곱으로 생기는 중간 오버플로를 줄인다. 유한한 길이·양의 구간 가중치·결과를 표현할 수 없으면 `out_of_scope`다. 평균선 제거는 높이 원점 이동이며 기울기나 파형을 제거하는 필터가 아니다.

관련 기존 API `protection.coating_coverage` 1.0.1은 건조 도막 부피, 습윤 두께, 전달 손실을 포함한 습윤 재료 소요량이 양의 유한 값인지 확인한다. 표현 범위를 벗어나거나 양수가 0으로 언더플로하면 적용 범위 밖이다. 큰 입력이라도 결과가 유한하면 계산한다. 입력 계약은 같다.

검증은 알려진 삼각형 적분, 구간 내부 부호 전환, 불균일 간격, 선형 구간 세분화·위치 이동 불변성, 일정 높이의 0 조도, 처리 검토·해시·순서 검사, 수치 범위, 도막 부피 보존과 두 API의 Python/JSON 동일성을 포함한다.
