# 임의 길이 창의 지시 누적 길이

`inspection.indication_window_accumulation`은 검토된 공통 1차원 좌표에 투영된 지시 구간을 대상으로, 검사 범위 안의 고정 길이 창에서 누적 길이의 최댓값을 계산한다. 계약은 `IndicationWindowAccumulation`, 개별 구간은 `ProjectedIndicationInterval`이다.

좌표는 명시한 원점으로부터의 거리(m)이며 검사 범위는 `[0, examined_length_m]`이다. 각 지시는 고유 식별자·시작·끝·관측 해시를 가진다. 지시는 검사 범위를 벗어날 수 없으며 창 길이는 검사 범위 이하여야 한다. 현재 요청당 최대 512개 지시를 지원한다. 순환 이음부의 자동 감김이나 좌표 정합은 제공하지 않는다.

`overlap_semantics`는 반드시 선택한다.

- `sum_indication_overlap`: 겹친 지시도 각각의 창 내부 길이를 합산한다. 결과가 창 길이보다 클 수 있다.
- `union_covered_length`: 겹친 좌표 영역을 한 번만 센다. 서로 다른 지시를 같은 물리 결함으로 판정한 뜻은 아니다.

각 구간과 창의 교차 길이는 창 시작 위치에 대한 구간 선형 함수다. 기울기가 바뀌는 위치는 구간 양 끝점과 그 끝점에서 창 길이를 뺀 위치다. 이를 유효 창 시작 범위로 제한하고 양 경계를 추가해 최댓값을 찾는다. 이웃한 최대값 경계 사이에서는 같은 최대값이 유지되므로 최대 창 시작 위치를 점 또는 범위로 반환한다.

결과는 최대 누적 길이, 최대값이 생기는 창 시작 범위, 가장 이른 대표 창, 그 창과 겹친 원래 지시별 길이를 포함한다. 합집합 모드에서도 대표 지시별 교차 길이는 원래 지시를 추적하기 위한 값이므로 그 합이 합집합 최댓값과 같을 필요는 없다.

검사 범위의 빈틈, 투영·실물 식별, 겹침 의미는 호출자가 검토해야 한다. 미검토는 `needs_data`, 창이 좌표 척도에서 구분되지 않거나 합계가 수치 범위를 벗어나면 `out_of_scope`다. 전체 입력과 선택한 의미는 `CorrelationBasis`의 근거·권한·적용성 검토와 해시에 연결된다.

지시가 없으면 관측 목록의 누적 길이는 0이다. 결함이 없거나 검출 능력이 입증됐다는 의미는 아니다. 불확도 확장, 지시 병합·동일 결함 판정, 표준 창 길이·허용값·합격은 자동으로 적용하지 않는다.

`tests/test_indication_window_accumulation.py`의 12개 사례가 내부 최대값, 겹침 의미, 최대 평탄 구간, 빈 목록, 전체 창·접촉 구간, 검토 누락, 범위·중복 식별자, 수치 범위, 해시 변조와 기본 레지스트리 Python/JSON 교환을 확인했다. 독립 실험 검증은 아니다.
