# 두께별 변화율 한계와 선언된 수소 지표

## 두께에 따른 변화율 한계

`thermal.thickness_scaled_rate_limit`의 계약은 `ThicknessScaledRateLimit`이다. 명시된 두께 지원 범위 안에서 다음 한계를 계산한다.

`한계 = min(기준 변화율 × 기준 두께 / 지배두께, 변화율 상한)`

방향은 가열·냉각 중 지정한다. 금속 온도가 활성 온도보다 큰 때 또는 크거나 같은 때 중 적용 조건을 선택한다. 비활성 상태는 `rule_active=false`, `maximum_rate_K_s=null`이며 다른 변화율이 허용된다는 뜻이 아니다. 계수·두께·상한·절차·활성 조건·권한은 전체 입력 해시에 연결된다.

계산은 지배 후보와 동률을 보존한다. 정확한 이진 입력값의 유리수 비율을 내부적으로 비교해 미사용 후보의 오버플로로 유한 상한을 잃지 않는다. 상한 적용 전 값이 표현 범위를 벗어나면 해당 보조값은 null과 별도 표현 가능 여부로 표시한다. 양의 최종 한계가 0으로 언더플로하면 계산을 보류한다. 선언된 0 상한은 별개로 0 한계를 표현할 수 있다.

직접 작성한 예로 기준 두께 0.04 m·기준 변화율 0.5 K/s·상한 1 K/s를 사용하면 두께 0.08 m에서 0.25 K/s다. 실제 절차 계수나 권고가 아니다. 이 API는 규격 계수·변태 온도·열처리 적합성을 생성하지 않는다.

## 수소 기준을 명시한 로그 지표

`welding.declared_hydrogen_susceptibility_index`의 계약은 `DeclaredHydrogenSusceptibilityIndex`다. 사용자 계수로 다음 지표를 계산한다.

`상수항 + 조성 계수 × 조성 지표 + 로그 계수 × log10(수소값 / 수소 기준값)`

수소값과 기준값은 같은 의미·단위의 양의 값이어야 한다. `hydrogen_input_kind`는 실제 측정량 또는 선언된 범주값이다. 범주값은 단위 `1`을 사용하며 측정 가스 함량으로 변환하지 않는다. 실제 물리적 의미는 `hydrogen_definition_id`와 입력 근거로 고정한다. 조성 지표 정의·질량 백분율 기준도 명시한다.

극단 비율은 두 로그의 차로 계산하며, 1에 가까운 비율은 `log1p` 형태로 작은 차이를 보존한다. 부호 있는 지표와 조성·수소 기여를 각각 반환한다. 비유한 지표는 보류한다. 기본 계수·등급·예열 기준·균열 확률은 제공하지 않으며 실제 수소량이 누락됐다고 0 또는 범주값을 대신 넣지 않는다.

## 검증

`tests/test_weld_rate_and_hydrogen_descriptors.py`의 19개 사례는 두께·상한·동률, 온도 활성 경계·비활성, 지원 범위·0 한계, 비율 오버플로·언더플로, 부호 있는 지표·1 근처와 극단 로그 비율, 범주 단위·0 입력, 해시 변조와 두 API의 기본 레지스트리 Python/JSON 교환을 확인했다. 직접 작성한 수학·소프트웨어 사례이며 독립 재료 실험 검증은 아니다.
