# Faraday 손실 계산 API

`corrosion.faraday`는 호출자가 지정한 용해 전류 밀도, 전류 효율, 몰질량, 유효 전자수, 밀도와 시간으로 평균 용해 속도 및 침투량을 계산한다. 입력 계약은 `FaradayLoss`다. 전류 밀도는 A/m², 몰질량은 kg/mol, 밀도는 kg/m³, 시간은 s이며 출력은 m/s와 m이다.

측정된 순전류에서 양극 용해 전류를 자동 분리하지 않는다. 전류 효율과 유효 전자수는 호출자가 해당 재료·반응·환경에 맞게 제공해야 한다. 막 형성, 다른 전극 반응, 국부 면적 변화나 피트 형상을 자동 추론하지 않는다. 출력은 국부 부식률, 수명 또는 수락 판정이 아니다.

0.1.1에서는 분자·분모의 곱과 비율을 입력 수치의 정확 유리수로 계산한다. 중간 곱이 넘치거나 소실돼도 최종 결과가 표현 가능하면 보존한다. 필요한 비영 출력이 표현 불가능하면 `out_of_scope`이며 일부 출력만 완료 결과로 반환하지 않는다. 호출자가 명시한 전류 또는 효율 0은 정확한 0이다. 누락값은 0으로 대체하지 않는다. 전류 효율은 0 이상 1 이하다.

질량 손실 쿠폰 API와 유한 수치 변환 함수를 공유한다. 관련 Faraday·쿠폰 회귀 및 Python/JSON 교환 합계 20개 사례가 `artifacts/validation/faraday_and_coupon_numeric_range.xml`에 기록돼 있다. 극단 수치 사례는 소프트웨어 산술 확인이며 해당 극단 물성이 현실적으로 유효하다는 뜻은 아니다.
