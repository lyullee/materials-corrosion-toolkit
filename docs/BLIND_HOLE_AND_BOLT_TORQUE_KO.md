# 지시용 구멍과 볼트 토크 계산

세 API는 `matintegrity.models.engineering_correlations`의 타입을 사용한다. `CorrelationBasis`에 정규화된 전체 요청 해시, 적용성·단위 검토와 계산 사용 권한을 제공하고 기본 레지스트리의 Python 또는 JSON 경로로 실행한다. 규격 치수·토크표·기본 마찰계수는 포함하지 않는다.

`inspection.blind_indicator_hole_ligament`의 입력 타입은 `BlindIndicatorHoleLigament`다. 동일 위치·방향의 벽두께와 구멍 깊이(m), 별도로 정의된 기준 요구두께(m), 부품·위치·구멍 ID를 받는다. 벽두께에서 깊이를 뺀 잔여 리가먼트, 실제 벽 대비 잔여 비율, 기준 요구두께 대비 깊이 비율을 구한다. 기준 요구두께와 실제 벽두께를 서로 대체하지 않는다. 관통·과깊이는 `out_of_scope`이며 부호 있는 잔여두께를 남긴다. 역할·위치 검토가 없으면 `needs_data`다. 벤트홀, 압력 허용, 유해 서비스의 사용 가능 여부, 실제 누설·부식속도·수명은 판단하지 않는다.

`fabrication.friction_resolved_bolt_torque`의 입력 타입은 `FrictionResolvedBoltTorque`다. 목표 축력(N), 유효 평균 받침면 지름·나사 피치지름(m), 1회전당 리드(m), 나사산 반각(rad), 받침면·나사산 마찰계수를 받는다. 나사산을 따라 하중을 올리는 토크와 받침면 마찰 토크를 따로 계산해 합한다. 반각은 전체 산각의 절반이다. 리드는 다중 나사에서 피치와 다르므로 자동으로 같다고 두지 않는다. 마찰·리드 조합의 분모가 0 이하이거나 수치 범위를 넘으면 적용 범위 밖이다.

나사 마찰과 받침면 마찰을 분리하는 수학적 배경은 [NASA RP-1228](https://ntrs.nasa.gov/citations/19900009424)의 대체 토크식과 정의를 참고한다. 여기서는 고정된 지름 비례값을 쓰지 않고 유효 받침면 지름을 직접 받는다. 이 기하·마찰 해석은 경험적 너트계수 API `fabrication.bolt_preload`와 입력 근거가 다르며, 마찰값을 측정·검토하지 않으면 자동으로 더 정확해지는 것은 아니다.

`fabrication.bolt_reference_torque_scaling`의 입력 타입은 `BoltReferenceTorqueScaling`다. 사용자 기준 토크에 목표/기준 인장응력 비율을 곱한다. 같은 유효 인장면적·나사·받침면·윤활 조건이 유지됐다는 검토가 필요하다. 기준 기록 해시와 공통 조건 ID를 보존한다. 코팅·윤활·재체결 상태가 달라진 조건을 그대로 비례 환산하지 않는다. 양의 비율·토크가 표현 범위를 벗어나거나 0으로 언더플로하면 적용 범위 밖이다.

토크 결과는 정적 입력에 대한 산술이다. 토크 도구 정확도, 실제 축력 산포, 비틀림 항복, 나사산 손상, 체결 순서에 의한 상호작용이나 제품 허용 판정을 제공하지 않는다. 조건에 맞는 실측 또는 검증된 공급자 데이터를 사용한다.

검증에는 구멍 잔여두께·관통·과깊이, 서로 다른 기준두께, 각나사와 받침면 토크, 비영 반각의 독립 마찰각 표현, 무마찰 1회전 일과 축방향 일의 일치, 여러 리드, 특이 분모·범위 초과, 기준 토크 증감·0 목표 및 세 API의 Python/JSON 동일성을 포함한다.
