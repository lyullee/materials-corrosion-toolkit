# 압력–온도 한계 보간의 수치 범위

`structural.pressure_temperature_envelope` 1.0.1은 사용자가 공급한 양의 압력 한계와 온도 절점을 선형 보간한다. 압력은 같은 기준으로 제공해야 하며 절점 밖으로 외삽하지 않는다.

정확 비율 산술로 보간·여유·이용률을 계산해 큰 한계 차이에서 작은 끝점 값이 소실되는 문제를 방지한다. 최종 결과 중 하나라도 유한한 비영 부동소수점으로 표현할 수 없으면 묶음 정량 결과를 반환하지 않고 `out_of_scope`로 보류한다.

이 기능은 부품 형상·재료 허용응력·접합 효율·부식 후 두께에서 압력 용량을 산정하지 않는다. 정수두 기준면 변경과 지배 부품 선정도 별도의 명시적 계산이 필요하다.
