# FMC의 직접 경로 TFM 재구성

평면 경계에서 굴절·같은 모드의 뒷면 반사·송수신 모드별 뷰를 계산하는 별도 API는 `inspection.planar_multiview_fmc_tfm`이며 `PLANAR_MULTIVIEW_TFM_KO.md`에 기록했다. 아래 범위와 입력은 직접 경로 API에 관한 것이다.

## 계산 범위

`inspection.homogeneous_fmc_tfm`은 `HomogeneousFmcTfm`으로 주어진 실제 시간 신호를 영상점에 집속해 더한다. 기존 PAUT 취득 요약과 달리 부호 있는 RF 신호에서 영상 진폭을 직접 계산한다. 현재 전파 모델은 하나의 균질·등방성 매질 안에서 직접 진행하는 종파다. 각 요소와 영상점은 동일한 명시적 좌표계를 사용해야 한다.

영상점 `r`에서 송신 요소 `i`, 수신 요소 `j`의 신호를 읽는 시간은 `excitation_origin + distance(i,r)/c + distance(j,r)/c`다. 모든 송수신 신호를 그 시간에서 선형 보간한 뒤 `coherent_sum` 또는 `coherent_mean`으로 집계한다. 부호를 보존하며 절댓값·포락선·강도·로그 압축을 자동 적용하지 않는다.

TFM의 지연 합산 정의와 접촉 검사 범위는 [arim 공식 문서](https://ndtatbristol.github.io/arim/user/im/tfm.html)로 독립 확인했다. 이 구현은 NumPy 기반의 제한된 참조 계산이며 arim 코드를 복사하거나 해당 라이브러리를 의존성으로 추가하지 않았다. arim의 다중 경로·접촉/침수 영상 기능은 별도의 확장·비교 검증 대상으로 남긴다. 속도나 정확도가 arim보다 우수하다는 주장은 하지 않는다.

## 입력 계약

| 입력 | 보존하는 의미 |
|---|---|
| 실물·범위·출처 | `physical_specimen_id`, `physical_scope_id`, `source_group_id` |
| 취득·재료·탐촉자 | `acquisition_id`, `material_condition_id`, `probe_id` |
| 좌표·시계 | `coordinate_frame_id`, `sample_clock_id`, 명시된 `time_s` |
| 시간 원점·음속 | `time_zero_basis_id`, `excitation_time_origin_s`, `velocity_basis_id`, 양의 음속(m/s) |
| 원자료 | 호출자가 제공하는 `raw_record_sha256`, 진폭 단위, 각 trace의 정규화된 샘플 해시 |
| 요소 | 고유 `element_id`와 3차원 위치(m) |
| 신호 | 고유 `trace_id`, 명시적 송신·수신 요소 ID, 공통 시계에 정렬된 부호 있는 샘플 |
| 영상점 | 고유 `point_id`와 3차원 위치(m) |
| 사용 근거 | 전체 정규화 입력·계수·권한·단위·적용성을 연결한 `CorrelationBasis` |

모든 순서 있는 요소 쌍에 정확히 한 신호가 있어야 한다. 행렬 모양·파일 이름·행 순서에서 송수신 역할이나 FMC/HMC 종류를 추론하지 않는다. 누락된 쌍을 대칭 복사하지 않으며 이미 존재하는 쌍을 중복해 가중하지 않는다. trace 입력 순서와 각 쌍·샘플 해시는 출력에 남는다.

`samples_sha256`는 검증된 부동소수점 샘플 튜플의 `canonical_digest`다. 파일 원시 바이트 해시와 같은 개념이 아니다. 원자료 파일 해시는 호출자가 제공하며, 이 API는 파일을 열어 원본 바이트를 다시 확인하지 않는다. 원본과 파생 입력의 연결·권한·조건 검토를 함께 보관해야 한다.

기본 레지스트리의 `run` 및 `run_json`으로 호출한다. Python에서는 요소·영상점·trace 계약을 구성한 뒤 전체 정규화 요청의 해시를 계산한다. 시계·샘플·음속·좌표를 변경하면 전체 해시를 다시 검토해야 한다.

## 수치 지원과 출력

현재 JSON/Python 프레임은 요소 64개, 신호 4,096개, trace당 샘플 32,768개, 영상점 4,096개 이내이며 전체 프레임 샘플 수는 5백만 개로 제한한다. `maximum_point_trace_evaluations`는 호출자 계산 예산으로 기본 1백만, 최대 1천만이다. 이는 물리적 검출 한계가 아니라 메모리·실행 범위다. 더 큰 FMC 프레임의 바이너리·청크 입출력과 가속 백엔드는 미완료다.

요청한 모든 영상점에서 모든 송수신 지연이 관측된 공통 시계 범위에 들어와야 한다. 범위를 벗어나면 전체 영상을 보류하고 문제가 된 trace와 영상점 ID를 반환한다. 끝값 고정·영 채움·일부 신호 제외로 영상을 만들지 않는다. 정확한 마지막 샘플 시각은 지원한다.

결과 `image`는 입력 영상점 순서의 위치·ID·부호 있는 `coherent_amplitude`를 제공한다. 진폭의 의미와 단위는 입력을 따르며 압력·반사계수·결함 크기로 자동 보정하지 않는다. 평균은 신호 수로 명시적으로 정규화한다. 합산·보간의 비유한 결과나 평균 기여값의 언더플로는 보류한다.

## 검증과 남은 대응

자체 작성한 3–4–5 거리의 합성 점 반사체를 이용해 초점·비초점, 합·평균, 시간 보간·원점 이동, 음의 RF, 마지막 샘플, 범위 이탈·예산, 누락/중복 쌍·해시 변조, 극단 진폭과 Python/JSON 교환을 확인한다. 합성 점 반사체 검증은 수치 연산의 확인이며 실물 결함 검증이나 검출확률 평가가 아니다.

관련 17개 테스트와 정적 검사가 통과했다. 실물 시편·출처 그룹·송수신별 샘플 해시의 결과 보존도 확인했다. 이를 전체 TFM 기법이나 실제 검사 캠페인의 검증 완료로 보지 않는다.

웨지·굴절·다중 반사·모드 변환·비등방성·근접장·요소 지향성·감쇠/기하 보정·가중 집속·포락선·결함 검출/크기 평가·검출확률·규격 대체 승인은 구현 범위 밖이며 별도 대응이 남아 있다. 증강 영상·처리된 지시 표를 원시 FMC 신호로 취급하지 않는다.
