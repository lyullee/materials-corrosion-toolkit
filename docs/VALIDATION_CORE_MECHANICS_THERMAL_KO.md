# 기존 구조·재료·열 계산의 묶음 확인

2026-11-01 로컬 수학·API 검증 기록이다. 새 모델 수가 아니라 기존 구현의 범위와 계산 근거를 확인한 작업이다.

| 확인 대상 | 기준 |
|---|---|
| 두꺼운 원통 | 동일 내·외압에서 균일한 압축 응력과 0인 편차 응력 |
| 평면 응력 | 독립 행렬 고유값 계산과 3차원 편차 응력 불변량 |
| 열 구속 | 자유 경계, 가열·냉각 부호 및 대칭성 |
| 선형 탄성 균열 | 길이 축척, 임계 깊이에서의 여유, 무하중의 미정 임계 깊이 |
| 인장 변환 | 균일 변형 가정의 체적·힘 수지, 미검토 시 진응력 출력 보류 |
| 연성 비교 | 증가한 연성을 음수 손실로 보존 |
| 전하–손실 변환 | SI 전하/몰 기준과 질량–체적 수지 |
| 원통 열전달 | 동일한 열저항 3개의 직렬 해와 가열/냉각 부호 |
| 집중 열용량 | 초기 상태, 시간상수 및 사용자 Biot 범위 |
| 열처리 이력 | 센서별 유효 시간 교집합, 시간 원점 이동, 이탈 구간 및 시간 축척 |
| 냉각 구간 | 온도 평탄부에서 선언된 분기와 최초 진입 시각 보존 |
| 압력–온도 한계 | 지원 구간 보간, 경계값, 단위·자료 검토 및 외삽 거부 |

기계·재료 묶음 11개, 열 이력·압력 곡선 묶음 13개, 기존 API의 Python/JSON 교환 12개가 통과했다. 이번 묶음 36개를 포함한 재검토 범위의 누적 관련 테스트는 186개다. 동일 사례의 재실행은 다시 더하지 않는다.

열처리 유지 시간 계산에서 고정된 1e-9초 비교 허용오차가 짧은 온도 이탈 구간을 지워 연속 유지 시간으로 합칠 수 있는 문제를 재현했다. `welding.heat_treatment_history` 버전 1.0.1은 기록 경계의 시각을 그대로 사용하고 정확하게 맞닿은 창만 합친다. 작은/큰 시간 축척에서도 이탈 구간을 보존하는 회귀 사례가 통과했다. 입력 필드 변경은 없다.

검증 파일은 `tests/test_reassessment_mechanics_materials.py`, `tests/test_reassessment_thermal_histories.py`, `tests/test_pressure_temperature_envelope.py`, `tests/test_reviewed_core_api_exchange.py`다. 실행 예제 `examples/reviewed_core_calculations.py`는 물성·규격 데이터가 아닌 합성 입력을 제공한다.

이 계산들은 입력 가정 안의 수학적 결과다. WRC 노즐 국부 응력, 규격별 응력 분류·허용치, 실제 균열 형상 해, 재료 물성·전류 효율, 시험 유효성, 열처리 절차 합격 및 실험 qualification을 이 결과로 대체하지 않는다. 본 검토만으로 상위 기술 분야 전체를 완료 처리하지 않는다.
