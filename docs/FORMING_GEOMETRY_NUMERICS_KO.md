# 성형 기하 진변형률의 수치 경계

`fabrication.forming_geometry_history` 1.0.1은 안쪽 반경이 0인 진변형률 요청을 예외로 중단하지 않고 `out_of_scope`로 반환한다. 압축 진변형률은 정의역 경계에서 발산하므로 해당 출력은 `null`이며 원인을 기록한다. 공학 변형률 계약은 유지한다.

양수인 매우 작은 반경은 로그 비율로 계산하여 공학 변형률이 부동소수점에서 1로 반올림되어도 유한한 압축 진변형률을 보존한다. 이는 명시된 중립축과 원호 기하의 산술 처리이며 실제 성형 공정의 물리 검증이나 허용 판정은 아니다.

검증: `tests/test_forming_geometry_history.py`의 기존 네 사례와 반경 0 및 1e-30 m 경계 두 사례를 실행했다. 여섯 사례가 통과했으며 경계 출력은 비유한 JSON 숫자를 포함하지 않는다. 입력 스키마 변경은 없다.
