# 조성 비율과 역수 인자

`materials.composition_index_recipe`와 `materials.floored_composition_index_recipe` 0.1.2는 각 원소 인자의 정수 지수로 -4부터 -1, 1부터 4를 받는다. 0승은 받지 않으며 상수는 기존 상수항으로 지정한다. 예를 들어 사용자 원소 A와 B의 비율은 계수 1, A의 지수 1, B의 지수 -1인 단일 항으로 표현한다. 보고되지 않은 탄소나 잔여 원소를 추가할 필요가 없다.

모든 원소는 명시적으로 측정값을 제공해야 한다. 분모의 유효 함량이 0이면 계수가 0이어도 정의되지 않은 식으로 처리하고 `out_of_scope`를 반환한다. 하한 적용 API에서는 사용자가 명시한 양의 하한을 적용한 뒤 역수를 계산할 수 있다. 원래 관측값과 적용 하한은 결과에 별도로 남으며, 하한이 실제 합금의 조성을 바꾸거나 누락 측정값을 대신하지 않는다.

단위 변환과 거듭제곱·항의 결합은 정확 유리수로 수행한다. 중간 역수만으로는 표현 범위를 넘더라도 완성된 항이 표현 가능하면 계산한다. 각 항과 최종 결과 등 필수 출력이 표현 불가능하면 부분 계산값을 제공하지 않는다. 같은 질량 기준으로 변환한 두 함량의 단순 비율은 기준에 무관하지만, 지수 합이 0이 아닌 항과 계수의 단위는 사용자가 맞춰야 한다.

같은 조성 인자를 상속하는 `materials.composition_temperature_correlation`은 1.0.1에서 이 표현을 지원한다. 기존 조성 적용 범위·보정 모집단·온도 의미·양의 Kelvin 검사는 그대로 적용한다. 분모가 0인 지점이 적용 범위 안에 있더라도 그 지점에서 식이 유효해지는 것은 아니다.

이 기능은 사용자 식의 산술 평가다. 원소별 경험 계수, 함량 비율의 수락 경계, 내식성·용접성·경화능 예측은 내장하지 않는다. 기존 양의 지수 요청의 입력 형태는 유지되며 새 음의 지수 요청에는 해당 버전의 스키마를 사용한다.
