# 사용자 지정 압력–두께 관계

`structural.declared_pressure_thickness_relation` 1.0.0은 사용자 승인 관계 `P = k S E t / (L + c t)`를 계산한다. `pressure_from_thickness`에서는 유효 두께로 압력차를 구하고, `thickness_from_pressure`에서는 `t = P L / (k S E − c P)`로 역산한다. 압력은 Pa, 두께와 길이는 m, 응력은 Pa이며 k·E·c는 무차원이다.

계수·길이 정의에는 기본값이 없다. 사용자가 형상, 내측/외측 치수 기준, 재료 상태, 온도, 허용응력, 접합 효율, 분자 계수와 부호 있는 두께 계수를 제공한다. 이 관계로 표현할 수 없는 형상·하중·비선형식은 별도 모델이 필요하다. 명명된 규격이나 모든 용기 형상의 구현을 주장하지 않는다.

유효 두께는 이미 해당 시나리오의 공차·부식·성형 감소 등을 반영한 입력이다. 공제 항목을 자동 선택하거나 더하지 않는다. 역산 결과 역시 공제를 더하기 전 유효 두께이며 구매 공칭 두께가 아니다. 압력은 동일한 시나리오에서 정의한 내외 압력차다.

압력과 두께 모두 사용자 적용 범위 안에 있어야 한다. 정방향 및 역방향 분모가 비양수이면 `out_of_scope`다. 수치 계산은 정확 비율 산술로 결합하고 표현 불가 결과를 보류한다. 물리 적용성·유효 두께·하중 검토가 빠지면 `needs_data`다.

입력 전체와 계수를 CorrelationBasis의 해시·사용 권한·근거로 고정한다. 설비·위치는 RunContext와 같아야 한다. 단순히 계수 숫자를 제공하는 것만으로 규격 적합성이나 재료 적격성이 입증되지 않는다.

다른 하중, 국부 불연속, 좌굴, 외압 안정성, 피로·크리프, 규격 수락 및 인증은 별도다. 결과를 `structural.component_pressure_reference`에 연결할 때는 압력차에서 공통 절대/게이지 압력으로의 외압 기준 변환을 명시적으로 수행해야 한다. 두 결과의 압력 의미를 같다고 가정하지 않는다.

자체 작성 관계 예: k=2, S=100 Pa, E=0.8, L=4 m, c=0.5, t=2 m이면 P=64 Pa다. 같은 계수에서 P=64 Pa를 역산하면 t=2 m다. 실제 장비 또는 규격 예제가 아니다.

공통 압력 기준으로의 명시적 연결은 [압력 한계 연결 설명](PRESSURE_LIMIT_BINDING_KO.md)을 따른다.
