# 검사·시험의 지원 범위와 남은 대응

## 일반 NDE와 인수 기준의 추가 대조

MT/PT의 가시·형광 방식, 자화 방향·표면 상태·소모재·관찰 조건 및 검사자 자격은 취득 기록과 실제 검출 성능을 연결하는 별도 근거다. 제품 홍보의 감도·시간·신뢰성 설명이나 방법 비교표의 정성 표기를 보편적 검출확률·검출 한계로 사용하지 않는다. 방사선원·관전압·물질 두께의 예시도 자동 장비 선정표로 내장하지 않는다.

GWUT·PEC·이동 RT·스마트 피그·도막 두께 검사의 기록과 비교 기능이 있다는 사실을 벽 두께의 정량 역해석 완료로 보지 않는다. 방법별 장비·모드·교정·관측 위치·시계가 필요하다. GWUT 반사를 이용해 원소 조성을 직접 측정했다고 판단하지 않는다.

검사 범위는 각 부품의 검사 길이·면적·체적 비율인지, 전체 부품 수 중 선택 비율인지 구분한다. 전수·무작위·스폿·추가 검사, 용접사 및 제품군별 분모, 의심 부위 포함과 확대 규칙의 판본별 연결은 남은 과제다. 전수 검사 명칭만으로 모든 방향·전체 체적·탐지 성능을 보증하지 않는다.

현재 `inspection.homogeneous_fmc_tfm`은 직접 종파 FMC 영상 재구성을 제공한다. 구체적 범위는 `FMC_TFM_RECONSTRUCTION_KO.md`에 기록했다. PAUT 취득·TOFD 기하·TFM 재구성과 실제 검출/크기 평가·RT 대체 자격은 각각 구분한다.

`inspection.planar_multiview_fmc_tfm`은 평면 경계 굴절과 같은 모드의 뒷면 반사를 포함한 지연 경로별 영상을 추가한다. `PLANAR_MULTIVIEW_TFM_KO.md`의 매질·모드·형상·예산 조건을 따르며 일반 형상·에너지 전달·검출/크기 검증이나 검사 대체 승인을 제공하지 않는다.

표면 지시와 RT 지시의 치수·관련성·배열·정렬·군집·분리 거리는 승인된 판본의 근거로 연결해야 한다. `inspection.indication_window_accumulation`의 투영 구간 누적 계산은 RT 지시 지름의 합이나 2차원 정렬·군집 규칙 전체를 자동 구현하지 않는다. 인쇄된 판정 그림을 복제하거나 임의 배율로 재구성하지 않는다.

| 검사 책임·승인 | 검사 기록 | 역할별 의무와 자격·승인 권한은 프로젝트·적용 기준별로 대응해야 한다. |
| 파괴시험 | 인장·충격·파괴인성 전용 API | 소재 시험, 열이력 모사 시험, 생산 시험의 실제 시편·목적을 구분한다. 전체 시험군 완료를 뜻하지 않는다. |

검사법 비교표의 정성적 검출 설명을 보편적인 검출 확률로 사용하지 않는다. 제품 크기에 정규화된 값, 농도, 시간 구간과 유량은 의미가 다른 양이므로 단위 문자열만 바꾸어 변환하지 않는다. 방법별 실제 관측과 독립 검증이 확보될 때 해당 물리 기능의 완료를 판단한다.

이번 문서는 요구 분류 기록이며 새 계산 또는 수치 검증 실적을 추가하지 않는다.

## 자격·상시 계측의 추가 대응

제조자·검사자의 역할, 자격, 입회, 승인 범위와 기록 보존은 개별 검사 기록의 존재만으로 충족되지 않는다. UT의 기하·취득 계산은 방사선 검사를 대체할 수 있는 자격을 자동으로 부여하지 않는다. 참조 반사체·직진/경사 빔·실제 크기 평가와 절차·인력 근거를 연결해야 한다.

TML은 동일한 실물 위치·형상·방향·시점이 추적돼야 한다. 과거의 검사법 비교 비율을 다른 자산의 검출 확률로 옮기지 않는다. 열화상·중성자·펄스 와전류·이동 검사 장치의 정량 해석은 방법별 계산·교정과 별도로 연결해야 한다.

전열관 형상 스캔은 미세조직 복제를 대체하지 않는다. 스쿱 채취 시편의 결과는 실제 채취 위치·방향·형상과 승인된 시험 축소 방법을 보존해야 한다. 변형률 브리지의 전기·온도 교정과 센서 방향·다축 해석도 구분한다. 한 방향 변형률만으로 전체 주응력이나 피로 심각도를 정하지 않는다.
