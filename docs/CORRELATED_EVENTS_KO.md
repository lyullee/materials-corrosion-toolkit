# 공동 사건분포와 상위사건 확률

## 목적과 범위

`reliability.joint_event_probability`는 동일 자산·물리 범위·기간·생존 조건을 공유하는 이진
사건들의 완전한 공동분포를 받는다. 각 상태에 대해 개별 사건 발생 여부, 상태확률과 상위사건
진리값을 사용자가 제공한다. 계산기는 상위사건의 기간 조건부 확률을 상태확률의 합으로
계산한다. FTA, event tree 또는 별도 시나리오 모델이 만든 공동 상태표를 받을 수 있지만,
그 논리나 확률을 이 계산기가 추정하지는 않는다.

입력은 사건 ID·정의, 상위사건 ID·정의, 자산·부위·물리 범위, 기간, 조건부 기준,
공급자·판본·원본 SHA-256, 의존성 근거와 공통원인 그룹 ID를 보존한다. 최대 12개 사건과
`2^n`개의 모든 이진 상태를 요구한다. 확률 0인 상태도 생략하지 않는다. 상태가 빠지거나
중복되고, 합이 선언 허용오차 안에서 1이 아니면 거절한다. 완전성 또는 분포 검토 선언이
없으면 결과를 만들지 않고 `needs_data`로 중지한다.

## 계산 결과

상위사건 확률 외에 다음 진단을 반환한다.

- 사건별 주변확률
- 모든 사건 쌍의 동시발생확률과 공분산
- 분산이 양수일 때의 이진 phi 계수; 퇴화 주변분포에서는 `null`
- 같은 주변확률과 상위사건 진리표에 독립성을 가정한 비교 확률
- 실제 공동분포 확률과 독립 비교값의 차이

독립 비교값은 대안 확률모델이나 보수성 판정이 아니다. OR 논리에서는 양의 동시발생이
독립 비교보다 합집합 확률을 낮출 수 있고, AND 논리에서는 반대 효과가 날 수 있다. 쌍별
phi 계수는 고차 의존성이나 공통원인의 인과 구조를 완전히 설명하지 않는다.

`probability_event`로 변환할 때 원 공동분포의 기간과 정확히 같은 시작·종료 시각을 요구한다.
결과는 `conditional_first_failure_in_period` 의미로만 전달되며 반복사건 빈도나 관측 연간율로
자동 변환하지 않는다. 일정 위험률 등가는 별도 명시적 근사다.

## 검증과 남은 과제

`reliability.binary_event_pair_calibration`은 두 사건의 calibration/holdout 이진 관측으로 weighted 2×2 표와 phi를 만들고 holdout category log score와 Brier score를 보고한다. Physical sequence, source group과 independence group은 partition을 넘을 수 없다. 명시적 symmetric pseudocount는 호출자 근거가 있을 때만 적용하며 0확률 holdout cell은 clipping하지 않는다. 이 경험 빈도는 미래기간 확률, 공통원인 인과모형 또는 FTA 기초사건 확률이 아니다.

두 사건의 작성된 정확 분포로 주변확률, 동시확률, 공분산, phi, OR 상위사건 확률과 독립
비교값을 손계산과 대조한다. 누락·중복 상태, 정규화 오류, 퇴화 주변분포, context·기간 불일치도
검사한다. 재현 기록은 `scripts/validate_joint_event_probability.py`와
`validation/joint_event_probability_math.json`이다.

이 검증은 실제 공통원인 빈도, 사건 간 인과성, 시간 변화, 수리·교체, 희귀사건 추정 오차를
검증하지 않는다. 다음 단계는 고정된 실제 공급자 리비전에서 공동분포를 받고, 표본 불확실성,
고차 상관, 동적 상태전이와 PRISM 같은 소비자의 중복계상 방지까지 통합 검사하는 것이다.
