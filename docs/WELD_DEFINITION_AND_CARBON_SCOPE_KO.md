# 용접 기능·폐합 이음과 조성 지표의 대응

밀봉 기능, 설계 하중을 전달하는 강도, 용접의 연속성, 용입은 서로 다른 요구다. 공정 이름이나 이음 분류만으로 강도·자격·열처리 면제를 결정하지 않는다. 클래드 제거·보충의 국부 층 기하는 기존 API로 일부 지원하지만 실제 공간 형상, 노즐·이음 경계, 오염 검증과 좁은 간극의 추적 제어는 별도 대응이 필요하다.

폐합 용접은 실제 용접·계통 위치, 인접 구간의 시험 이력, 공정 중·최종 검사, 자격과 시험 면제의 권한을 연결해야 한다. 일반 검사·용접 기록이 있다는 사실만으로 이 연결이 완료되지 않는다.

`welding.carbon_equivalent_recipe`는 사용자 계수로 조성의 비율·역수 및 탄소 의존 비선형 항을 계산한다. 0 분모를 거부하고 분석 누락을 0으로 채우지 않는다. 따라서 같은 연산을 새 모델로 중복 구현하지 않는다. 조성 지표는 실제 용접성·예열 온도·내균열성 승인이 아니다.

추가한 계산 API는 두 가지다.

- `thermal.thickness_scaled_rate_limit`: 두께에 역비례하면서 상한을 갖는 열처리 변화율 한계. 기준 두께·계수·온도 활성 조건과 실제 적용 범위를 명시한다.
- `welding.declared_hydrogen_susceptibility_index`: 조성 항과 수소의 로그 항을 결합하는 선언된 지표. 측정량·범주값, 기준값·단위·해석을 고정하며 규격 분류나 예열 판단은 자동으로 제공하지 않는다.

두 API의 사용·검증은 THICKNESS_RATE_AND_HYDROGEN_INDEX_KO.md에 기록했다. 이 문서의 나머지 범위 분류는 새 물리 검증 실적을 뜻하지 않는다.
