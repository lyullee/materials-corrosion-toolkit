# Findley 임계면 응력 지표

`fatigue.critical_plane_findley_parameter`는 사용자가 제공한 닫힌 Cauchy 응력 이력과 유한한 임계면 후보에 대해 Findley형 응력 지표를 계산한다. 각 면에서 입력된 면내 전단 견인 벡터들의 모든 쌍별 거리를 구하고, 가장 큰 거리의 절반을 이 구현의 이산 전단 진폭으로 사용한다. 이후 입력된 Findley 계수와 관측 최대 법선응력을 결합하고, 사용자가 지정한 동일 재료상태의 기준 강도 및 기준 수명 한 점과 비교한다.

원 논문은 결합 비틀림·축하중 또는 굽힘에서 평균응력이 금속 피로에 미치는 영향을 다룬다. 이 프로젝트의 계산은 해당 연구의 원문이나 표를 재현하지 않고, 공개적으로 알려진 임계면 지표를 독립적인 입력·계산 계약으로 구현한다. 문헌 서지: W. N. Findley, 1959, [DOI 10.1115/1.4008327](https://doi.org/10.1115/1.4008327).

## 입력과 결과

- 응력 텐서는 Pa 단위 대칭 성분 순서 `xx,yy,zz,xy,yz,zx`이며 최소 세 샘플을 요구한다. 첫·마지막 응력 상태의 차이가 입력된 폐합 한계를 넘으면 계산하지 않는다.
- 면 법선과 면내 방향은 사용자가 정한 직교 단위벡터다. 후보 면의 유한 표본만 평가하며, 전체 방향 공간의 최대값을 보장하지 않는다.
- `findley_coefficient`, 기준 강도, 기준 수명은 같은 재료상태에 대해 사용자가 제공하고 근거·해시·검토 게이트로 고정한다. 합성 예제의 값은 배선 예시일 뿐 재료 권장값이 아니다.
- 출력은 후보 면별 지표, 지배 면, 기준 강도 대비 비율과 여유, 입력 및 근거 digest를 포함한다.

## 해석 한계

전단 진폭은 이 구현에서 명시한 유한 시료의 최대 쌍별 유클리드 거리 절반으로 구성된다. 이는 연속 시간 이력이나 제공되지 않은 면 방향을 제한하지 않는다. 기준 강도 대비 비율은 한 기준 수명에서의 결정론적 비교이며 피로수명, 누적손상, 합격판정, 파손확률, 신뢰도 또는 재료 적격성을 산출하지 않는다. 계수·강도 보정의 유효성은 별도의 재료별 시험과 검토가 필요하다.

## Python API

레지스트리 경로는 `ModelRegistry.run("fatigue.critical_plane_findley_parameter", request, context)`이고 JSON 경로는 `ModelRegistry.run_json(model_id, inputs_json, context)`다. 요청 스키마에는 응력 출처, calibration 출처, 권리 정보, 기준 재료상태, cycle 정의, 후보 면 및 검토 플래그가 포함된다. 계산량은 `maximum_shear_pair_evaluations`로 제한한다.
