# 남은 납품 작업의 분류

현재 전체 완료율은 미확정이다. 기능 수, 파일 존재 여부, 테스트 수를 필수 모델의 완료율로 환산하지 않는다.

| 작업 구분 | 현재 항목 수 | 처리 기준 |
|---|---:|---|
| 기존 추적 목록의 데이터 검증 대기 | 52 | 계산 구현과 실험·보정 데이터 확보를 구분한다. |
| 기존 추적 목록의 공급자 의존 | 48 | 사용자가 제공하는 규칙·계수·권한·적용성 근거를 명시한다. |
| 필수 요구와의 대응 확인 대기 | 1 | 확장 계산을 자동으로 필수 모델에 편입하지 않는다. |
| 상세 요구 검토에서 확인된 코드 미완성 | 3 | 기존 추적 목록과 별도 분모로 계산한다. |

현재 검토한 계산 부분집합에서 미해결로 기록된 계산 공백은 0개다. 전체 프로젝트에 코드 공백이 없다는 의미는 아니다.

작업 순서는 요구별 계산 대응 확인, 필수 코드 구현, 문서·카탈로그 동기화, 독립 수치 검증이다. 데이터나 공급자 응답을 기다리는 동안 독립 계산 구현을 계속한다. 외부 모듈 연동은 API·단위·식별자·상태 전달을 확인하며, 결합된 전체 시스템의 물리 검증은 납품 기준에 포함하지 않는다.

재생성 도구와 상세 검토 증거는 배포 경계 밖에서 관리한다. 공개 상태 수치는 `data/catalogs/delivery_progress.json`을 기준으로 한다.

다단계 성형의 중간 냉각 관측과 조건 분기는 `fabrication.forming_process_sequence`로 구현했다. 지배두께의 선택식 계산은 `fabrication.governing_thickness_recipe`로 구현했다. 재료별 계획·면제 권한과 규격별 형상 선택은 공급자가 제공한다. 이음부 게이지 기준은 전용 구현·연결 여부를 더 확인해야 한다. 범용 비교 규칙이나 사용자 입력 필드가 있다는 이유로 해당 기능을 구현 완료로 계산하지 않는다.

범위 기록은 기술 항목 부분 검토 207개와 추출된 상위 제목의 구조 분류 26개로 구분한다. 구조 분류는 물리 검토나 구현 완료가 아니다. 본문 구간의 근거가 명시되지 않은 기록과 부분 검토 뒤의 잔여 본문·그림·부록 검토도 남아 있다. 항목 수나 문서 줄 수를 코드 완료율로 환산하지 않는다.
