# 관 팽창과 굽힘 전 두께 계산

두 API 모두 `matintegrity.models.engineering_correlations`의 타입을 사용하며 기본 레지스트리의 Python/JSON 경로로 실행한다. `CorrelationBasis`에 정규화된 전체 입력의 해시와 계산 사용 권한·단위·적용성 근거를 제공한다. 허용 감소율이나 재료별 계수 표는 포함하지 않는다.

`fabrication.tube_expansion_wall_reduction`의 입력 타입은 `TubeExpansionWallReduction`이다. 초기 외경·내경, 구멍 지름, 팽창 후 내경을 m로 받는다. 최종 외면이 구멍에 접촉한다는 검토가 있어야 한다. 초기 벽두께는 초기 외경과 내경 차의 절반, 팽창 후 벽두께는 구멍 지름과 최종 내경 차의 절반이다. 이 벽두께 차를 초기 벽두께로 나눠 감소율을 산출한다. 따라서 초기 간극을 메우는 변위는 벽 감소로 세지 않는다. 음의 감소율은 그대로 보존한다. 접촉을 확인하지 못하면 `needs_data`, 양의 벽을 남기지 않는 치수는 입력 오류다.

`fabrication.tube_bend_preform_thickness`의 입력 타입은 `TubeBendPreformThickness`다. 직선부 최소 벽두께, 관 외경, 평균 굽힘 반경과 사용자가 제공한 곡률 여유 계수를 받는다. 직선부 두께에 `1 + 계수 × 외경 / 평균반경`을 곱해 굽힘 전 요구두께를 구한다. 계수는 무차원이다. 평균반경은 관 외부 반경보다 커야 하며 결과가 유한한 양의 내경을 남기지 않으면 `out_of_scope`다. 계수가 0이면 직선부 두께와 같다.

두 계산은 각각 평균 치수에 의한 벽 변화와 단일 여유식이다. 원주·축방향 국부 두께 분포, 잔류응력, 실제 팽창 접촉역학, 접합 강도·누설, 열처리 필요성·제품 허용 판정을 제공하지 않는다. 원자료 평균을 독립 측정이나 국부 최소두께로 바꾸어 해석하지 않는다. 관·구멍 식별자와 입력 해시는 결과에 보존된다.

검증은 간극만 해소한 경우의 0 감소율, 알려진 10% 감소율, 음수 보존, 접촉 근거 누락, 불가능한 치수 거부, 세 가지 길이 배율에서의 일관성, 0 계수, 불가능한 요구 내경 및 두 API의 Python/JSON 동일성으로 구성한다.
