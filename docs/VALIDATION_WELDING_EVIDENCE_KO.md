# 용접 절차·생산 시험·소모재의 연결 확인

2026-11-01 로컬 검토 기록이다. 제공된 사용자 기준·시험 자료를 연결하는 기존 API를 재사용했다. WPS/PQR 또는 용접 규격 자체의 qualification을 완료한 기록은 아니다.

생산 시험 캠페인 1.0.1은 최소·최대 집계의 측정 구간을 각 입력 구간의 최소·최대 끝값으로 계산한다. 평균의 표준오차를 최소·최대에 적용하던 처리를 수정했다. 결과는 비대칭 구간일 수 있다. 이 구간 연산 자체로 동시 통계적 신뢰수준을 주장하지 않는다. 평균 집계의 기존 산포·측정 불확실성 조합은 유지하며 그 가정의 검토가 필요하다.

서로 다른 출처 ID가 있어도 같은 독립성 그룹으로 선언되면 독립 출처 최소 조건을 충족한 것으로 처리하지 않는다. 제공되지 않은 독립성을 이름이나 행 개수에서 추정하지 않는다.

확인 파일은 `tests/test_wps_qualification.py`, `tests/test_welding_production_test.py`, `tests/test_production_weld_test_campaign.py`, `tests/test_temper_bead.py`, `tests/test_welding_consumable.py`, `tests/test_welding_evidence_api_exchange.py`다. 절차·생산 증거 9개, 템퍼 비드·소모재 9개, 생산 캠페인 6개, Python/JSON 교환 5개로 이번 29개가 통과했다. 재검토 범위의 누적 관련 테스트는 327개다.

조건 일치·단위·시험 기록·용접 절차 범위·자재 ID·판정과 해시 전달을 확인했다. 규격 계수·변수 범위·합격 표를 내장하지 않았으며 실제 용접부 강도·취성·잔여 수명·확률이나 규격 승인을 추정하지 않는다.
