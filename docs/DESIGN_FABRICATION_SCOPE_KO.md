# 설계 시나리오·제작 순서·용접성의 대응

| 요구 | 현재 지원 | 남은 대응 |
|---|---|---|
| 설계 최소 금속 온도 | 취성 근거·압력–온도 경계·열전도 계산 | 실제 금속 온도와 승인된 설계 경계를 구분한다. MDMT는 충격시험의 DBTT/FATT와 자동으로 같아지지 않는다. |
| 신재료 적용 근거 | 재료 증명서·인장·충격시험의 식별·대조 | 실제 heat/lot·제품·두께·열처리·온도별 자료와 승인된 자격 절차가 필요하다. 응력–변형률 곡선은 피로 S–N 곡선이 아니다. |
| 가압 온도·변화 속도 | 개별 운전점의 경계 비교와 `structural.pressure_temperature_ramp_limits`의 변화 속도 계산 | 구간 선형 이력과 사용자 방향별 한계에 한정한다. 경계 자체의 수소·취성 근거와 운전 승인은 별도다. |
| 제작 계획·검사 계획 | 개별 용접·열처리·검사 기록 | 승인 역할, 공급 범위, 변경·편차 처리와 검사 계획의 단계별 대응이 필요하다. |
| 제작·조립 순서 | 성형 순서, 질량·무게중심·평면 인양 반력, 시험 부하 | 전체 용접선 배치 최적화, 풍·지진·과도·노즐·지지 부하는 각각 적용 가능한 계산과 연결해야 한다. |
| 용접성 | 냉각 시간 상관식과 용가재 적합성 비교 | 공정별 점수를 확률로 해석하지 않는다. 첫 패스 냉각과 다층 용접의 열 축적은 다르다. |
| 용접 불연속 | 관측 지시·적용성 비교 | 불연속 이름만으로 발생 원인이나 합격을 확정하지 않는다. 현장 관측과 절차별 근거를 연결한다. |

문서·표·그림은 제작 이력과 요구의 출처를 설명할 수 있지만, 그 존재만으로 대응 계산과 검증이 완료된 것은 아니다. 이번 문서는 요구 분류 기록이며 새 수치 검증 실적을 추가하지 않는다.
