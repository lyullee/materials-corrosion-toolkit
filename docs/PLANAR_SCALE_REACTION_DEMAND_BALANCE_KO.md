# 확산 공급과 반응 소비의 평면 scale 수지

`PlanarScaleReactionDemandBalance`는 단일 종 확산 공급과 사용자가 제공한 표면 반응 소비를 같은 두께 방정식에서 계산한다. `planar_scale_reaction_demand_balance()`로 호출한다. 예제 `examples/planar_scale_reaction_demand_balance.py`는 합성 입력만 구성하며 계산하지 않는다.

면적 기준은 고정된 평면의 실제 반응 면적이다. 유효 확산계수 D, 계면 전달계수 k, reservoir와 반응면의 비음 농도 구동차 Δc, 수송종/고체 몰비 ν, 고체 몰부피 Vm, 고체 소비 flux q를 선언한다. 구간 내 계수와 온도는 일정하다.

`Jdiff = D*Δc/(L+D/k)`이며 `dL/dt = Vm*(Jdiff/ν-q)`다. 즉 `a=D/k`, `A=Vm*D*Δc/ν`, `B=Vm*q`이면 `L'=A/(L+a)-B`다. q는 이미 계산되거나 관측된 반응의 고체 소비량/면적/시간이다. 이 방정식은 공급과 소비를 직접 두께 변화에 결합하지만 전극 전위 또는 반응 전류를 계산하지 않는다.

전류 입력은 부호 있는 단일 **부분 전류밀도**다. 소비 방향이 양 또는 음인지 명시하고, 전자/반응 extent와 소비 고체/extent를 제공한다. 소비 방향과 반대 전류는 거부한다. `q=abs(i)*고체몰비/(전자몰비*F)`이며 `F=96485.33212331001 C/mol`을 사용한다. 순전류·혼합전위 총전류에서 소비량을 추정하지 않는다. 양·음 방향을 자동으로 성장/용해로 바꾸지 않는다. 몰 flux 직접 입력과 전류 입력은 구간마다 정확히 하나만 허용한다.

B=0 또는 A=0에서는 폐형식을 사용한다. A와 B가 모두 양이면 `y=L+a`, `e=A/B`, `d=e-y0`, `y=y0+d*u`를 두고 `t=(y0*u+e*(-log(1-u)-u))/B`의 단조식을 이분 탐색한다. 작은 u에서는 log remainder 급수를 사용해 차감 오차를 줄인다. 반복 budget와 두께·시간 허용오차는 요청에 기록한다. 계산 오차의 보장이나 검증 결과를 뜻하지 않는다.

e<a인 소비 우세 상태에서는 두께 0의 사건 시각을 먼저 계산한다. 해당 시각이 구간 안이면 그 지점에서 종료하며 음의 두께나 이후 기판 노출을 계산하지 않는다. 이미 두께가 0이고 순성장이 양이 아니면 `scale_absent`로 즉시 종료한다. `full_requested_history_completed`를 반드시 확인한다. Event까지 계산한 결과의 computed 상태를 전체 요청 이력 완료로 해석하지 않는다.

결과는 소비 고체, 공급 고체 환산량, 수송 reactant 및 순 고체 변화의 면적당 몰 수지를 분리한다. 공급 적분은 계산된 순 변화와 소비량의 합으로 복원하므로 독립적인 보존 검증이 아니다. 물리 대상·시계·상·반응 ID, 요청과 provider record 해시를 유지한다. Evidence에는 같은 공급자/record 해시와 이용조건 식별자가 필요하다. 이용조건 ID 존재만으로 공개 재배포 권한을 인정하지 않는다.

핵생성, 다공성, 비정상 확산, 전기장, 다종 전하 수지, 농도차의 speciation 유도, 유한 reservoir, 부착/박리, 계면 전위, 혼합전위, 전류 피드백, 기판 부식, 보호효과와 규격 적합성은 범위 밖이다. 모든 계수의 온도 적용범위는 caller가 제공한다. 테스트·수치 계산·패키징은 수행하지 않았다. 후속 검증은 A=0/B=0 한계, 평형두께, 성장/수축 양쪽의 평형 비통과, 소진 event, 작은 u와 수치 극한, 일정 구간 분할 불변성 및 독립 수치적분 비교를 포함해야 한다.

코드 재검토에서 확인한 수치 지원범위: A=B=0이면 두께를 직접 보존하여 불필요한 제곱 연산을 피한다. B=0 성장의 이차식·분모가 overflow이거나 양의 성장량이 0/감소로 잘못 표현되면 out_of_scope다. Faraday charge/extent가 유한하지 않거나 비영 부분 전류가 수치 underflow로 0 몰 flux가 되면 거부한다. A와 B가 양인데 평형 좌표 A/B가 0으로 underflow되는 경우도 중단한다. 양의 초기 두께에서 계산된 소진 시간이 0으로 underflow되거나 소진 전 두께가 0으로 반올림되는 경우도 완료된 소진으로 오인하지 않도록 거부한다. 이는 극한 수치의 정확도를 입증하지 않으며 실패를 계산 완료로 반환하지 않도록 제한하는 조치다. 추가 검증에는 큰 a에서의 B=0 분모 overflow, 무구동의 큰 초기두께 보존, 거대한 전자 화학양론, 미소 비영 전류, A/B와 양의 소진 시간 underflow를 포함한다.

양의 구간 시간에서 비영 변화가 float 두께 간격 아래로 소실되면 중단한다. 구체적으로 B=0/A>0의 최종 두께가 초기값과 같거나, A=0/B>0의 소진 전 최종값이 초기값과 같거나, A>0/B>0이고 A/B-(L0+a)!=0인 역산 경로의 최종값이 초기값과 같으면 out_of_scope다. 정확한 무구동 A=B=0과 좌표상 평형 A/B==L0+a는 일정 두께 처리를 유지한다. 내부 진전 함수의 시간 0도 원 두께를 보존한다. 공개 interval 계약은 여전히 양의 시간만 허용한다. 작은 변화를 임의의 최소 증분으로 올리거나 0 변화로 완료 처리하지 않는다.

HPC edge 검증에는 무소비 성장 L0=1,a=1,A=1e-30,B=0,dt=1과 무공급 수축 L0=1,a=1,A=0,B=1e-30,dt=1에서 변화 소실을 거부하는지 포함한다. 둘 다 양수인 경우에는 엄격한 역산 tolerance에서 비평형 진전량이 큰 L0의 float spacing보다 작은 조합을 사용한다. 예를 들어 L0=1e16,a=1,A=1e16+2,B=1,dt=1e-30에 작은 time/thickness tolerance를 적용하고, 해당 값이 표현하는 부동소수점 평형 좌표가 실제 비평형인지 검증 측에서 확인한다. 대조군으로 A=B=0, A=B*(L0+a) 및 내부 dt=0의 일정 두께 처리를 확인한다. 이 사례들은 미실행 검증 계획이다.
