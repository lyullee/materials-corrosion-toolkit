# Security and responsible use

This research alpha is not a certified safety system. Do not use a `computed` result as an authorization to operate equipment or a substitute for a qualified assessment.

Inputs may identify files and external providers. Only read files you are authorized to use; do not execute provider code obtained from untrusted archives. Never put API tokens, private keys, passwords, raw research assets or sensitive operational records in the repository or a public issue.

For a suspected vulnerability, use the repository's private vulnerability reporting option if it is available. If unavailable, open a minimal issue requesting a private reporting channel without including secrets, sensitive data or a working exploit. Avoid posting an operational asset's measurements or identifiers publicly.

The prepublication scanner checks selected high-confidence credential patterns and release boundaries. It is not an exhaustive security assessment. Known engineering and quality limitations are in `docs/RELEASE_STATUS_KO.md`.
